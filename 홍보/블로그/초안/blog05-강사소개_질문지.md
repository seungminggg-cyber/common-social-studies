# blog05 강사 소개 — 강사님께 물어볼 것 (답을 받으면 글로 씀)

표시광고법 때문에 **확인할 수 있는 사실만** 씁니다. "1위·최다·100%·출제위원 출신"처럼 근거 없는 말은 쓰지 않습니다.
학원 이름은 강사님이 허락한 범위(예: "○○학원 출강")만 쓰고, 학원 홍보가 들어가면 글 **첫 부분**에 관계를 밝힙니다(추천·보증 심사지침).
답은 채팅으로 짧게 주셔도 되고, 저장소에는 학원 이름·개인 사정을 적지 않습니다.

1. 통합사회(또는 사회 과목)를 가르친 지 몇 년 되셨나요? 주로 맡는 학년은?
2. 수업 방식을 한 문장으로 말하면? (예: "개념은 질문으로, 문제는 자료로")
3. 학생들이 수업에서 가장 좋아하는 것 / 강사님이 꼭 강조하는 것 한 가지
4. 직접 만든 교재 소개를 어디까지 써도 될까요? (MINIMAP 개념서, MINIMAX 문제집, MAXIMIN 모의고사 — 이름·쪽수·문항 수 정도)
5. 블로그에 학원 이름을 써도 되나요? 된다면 어떤 형식으로? (학원 확인 필요)
6. 얼굴 사진을 넣어도 되나요? (촬영은 12/12 이후 가능)

## 글 뼈대 (답을 받은 뒤 채움)
- 제목: 통합사회 승민T 소개 | 고1 통합사회·2028 수능 통합사회 수업 방식과 교재
- 결론 먼저: 누구를 / 무엇을 / 어떻게 가르치는지 세 줄
- 1. 가르치는 과목과 학년 (1번 답)
- 2. 수업 방식 (2·3번 답 + 블로그 글 01~04 링크)
- 3. 직접 만든 교재 (4번 답, 교재 사진 그림)
- 4. 이 블로그에서 다룰 것 (시험 분석·한 장 정리·공부법)
- 마치며: 카카오톡 채널 링크 (모집 안내는 하지 않음)
