# 디자인 채팅 진행 기록

## 2026-11-28 1차 — 덜어 낸 디자인 견본
강사 피드백: "실제 디자이너처럼 세련되고 깔끔하게, 잡다하지 않게."

### 진단 (예전 cn01·blog01)
- 한 장에 꾸밈 부품이 6~8종(아이콘, 따옴표 상자, 테두리 이름표 칩, 회색 상자, 경고·전구 상자, 번호 네모, ✕ 표시) → 시선이 흩어짐.
- 민트를 장마다 4~6곳(제목 글자, 형광펜, 아이콘, 칩 줄, 안내 상자, 넘겨 보기)에 씀 → 강조가 강조로 안 보임.
- 쪽마다 맨 위 단원 표시 + 맨 아래 쪽 번호·'넘겨 보기'가 반복 → 위아래 띠가 소음.
- 표지에 아이콘 네 칸 + 민트 띠 + 형광펜 → 세 가지가 동시에 주인공.
- 제목 시작 높이가 장마다 다름(번호 네모형, 머리말형).

### 바꾼 것
- `lib/brand.css` 새로 씀: 색 7개, 글자 크기 7단계, 여백 5단계, 판형 3개(.slide/.thumb/.screen), 부품 5개(.run 머리줄, .head 제목 덩어리, .rows 목록 줄, .aside 덧붙임, .source 출처). 예전 부품은 blog01 호환용으로만 남김.
- `build.mjs`: H.run / H.head / H.rows / H.aside 부품 함수, 넘침 검사를 '아래 여백 침범'까지 보도록.
- cn01 10장 새 디자인 + 말투(~함/~임, '이렇게 생각하면 틀린다' 삭제, 함정은 질문→답 모양).
- 비교 그림: `디자인/비교_전후.png`, 전체: `디자인/cn01_새디자인_10장.png`.
