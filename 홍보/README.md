# 홍보물 (통합사회 승민T 개인 채널)

개인 채널(인스타그램 카드뉴스, 네이버 블로그 그림 등)에 올릴 그림을 코드로 만든다.
전략 보고서: `reports/강사 개인 브랜딩 홍보 채널 전략.md`

## 만들기
```bash
(cd textbook && npm install)   # 글꼴(Pretendard)·아이콘(Tabler)을 여기서 가져다 씀 — 한 번만
node 홍보/build.mjs            # content/ 안의 모든 조각
node 홍보/build.mjs cn01       # 이름이 cn01로 시작하는 조각만
```
결과는 `홍보/out/<조각 이름>/`: 장마다 PNG(`01-표지.png` …), 복사용 글(`캡션.txt`, `글_복사용.txt`), 블로그는 `미리보기.png`.
글꼴을 못 불러오거나 글자가 쪽 번호 줄과 겹치면 빌드가 알려 준다.

## 조각 (content/)
| 파일 | 채널 | 내용 |
|---|---|---|
| `cn01-네가지관점.js` | 인스타그램 카드뉴스 10장 (1080×1350) | 통합사회1 통합적 관점: 네 가지 관점 한 장 정리 |
| `blog01-고1통합사회수능.js` | 네이버 블로그 그림 5장 + 글 | 예비 고1 학부모용 "고1 통합사회, 이제 수능 과목입니다" |

## 디자인 규칙 (`lib/brand.css`)
- 색: 남색 바탕 + 민트 강조(승민T → seungmint) + 산호색(틀린 것). 대단원 색은 개념서 시안 H와 같음.
- 글꼴: Pretendard(SIL OFL, 상업 이용 가능). 로마 숫자 Ⅰ~Ⅴ 글자는 Pretendard에 없으므로 I·II·III 영문자로 쓴다.
- 상징: 모서리 하나를 잘라 낸 네모(`.cut`) — 개념서와 같은 모양.

## 내용 원칙
- 개념 내용은 개념서(MINIMAP)를 짧게 다시 쓴다. 평가원·교육청 문항 원문은 넣지 않는다(예시문항은 분류 숫자만).
- 예비 고1 대상 글에는 '선행·미리·앞서' 같은 말을 쓰지 않는다(선행교육규제법 제8조④).
- 학원 모집 글(반·수강료·시간표)을 올릴 때는 교습비를 표시한다(학원법 제15조). 정보 글과 모집 글을 나눈다.
- 숫자에는 출처를 단다(그림 아래 '자료:' 줄).
