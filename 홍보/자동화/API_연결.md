# API 연결 안내서 — Claude가 대신 올릴 수 있게 하는 한 번짜리 준비

**계정을 다 만든 뒤에** 한다([계정_만들기.md](계정_만들기.md)). 모두 **PC**에서 하는 게 편하다.

| 순서 | 무엇 | 시간 | 언제 |
|---|---|---|---|
| A | 유튜브: Google Cloud 프로젝트 + 업로드 허락 | 40분 | 영상 올리기 전(12/12 촬영 시작 전후) |
| B | 인스타그램: Meta 개발자 앱 + 토큰 | 30분 | 카드뉴스 자동 게시를 시작할 때 |
| C | 스레드: 같은 방식 | 20분 | 2~3개월 뒤 스레드를 시작할 때 |

'API'는 사람 대신 프로그램이 '올리기' 버튼을 누를 수 있게 플랫폼이 공식으로 열어 둔 통로다. 이 준비는 **본인 계정만** 쓰는 방식이라 플랫폼의 앱 심사가 필요 없고, 돈도 들지 않는다.

---

## 열쇠(키·토큰)를 다루는 규칙 — 꼭 읽기

1. **열쇠는 채팅에 붙여넣지 않는다.** 채팅 기록에 남는다.
2. 열쇠를 넣을 때가 되면 Claude가 **'열쇠 입력 카드'**를 띄운다. 그 카드 칸에 붙여넣고 저장한다. Claude는 값을 볼 수 없고, 이 클라우드 환경이 해당 주소로 가는 요청에만 열쇠를 붙여 준다.
3. 카드가 안 뜨면: 이 세션 제목 줄의 **클라우드 환경 메뉴 → 편집**에서
   - **네트워크 비밀값**(또는 'API credentials') 칸에 넣는다. (주소·머리글은 Claude가 알려 줌)
   - 유튜브 '갱신 토큰'만은 **환경 변수** 칸에 `YT_REFRESH_TOKEN` 이름으로 넣는다(아래 A-5).
4. 열쇠는 이 저장소(공개)에도, 코드에도 적지 않는다. 기록 파일에는 **저장한 날짜만** 남긴다.
5. 열쇠가 새어 나간 것 같으면 바로 Claude에게 말한다 → 플랫폼 화면에서 열쇠를 취소하고 새로 받는다.

> 이 클라우드 환경은 지금 인터넷 주소 제한이 없어서(2026-11-28 확인) 따로 허용 주소를 추가할 필요가 없다.

## A. 유튜브 (PC, 약 40분)

필요한 것: 유튜브 채널을 만든 구글 계정, 유튜브 휴대폰 인증 완료.

### A-1. 프로젝트 만들기 (5분)
1. console.cloud.google.com → 유튜브 채널을 만든 **같은 구글 계정**으로 로그인. 처음이면 약관 동의(결제 정보는 넣지 않아도 됨).
2. 위 왼쪽 프로젝트 선택 → **새 프로젝트** → 이름 `seungmint-promo` → 만들기.

### A-2. API 두 개 켜기 (5분)
- 왼쪽 ☰ → **API 및 서비스 → 라이브러리** → 검색해서 각각 **사용** 누르기
  - `YouTube Data API v3` (업로드)
  - `YouTube Analytics API` (주간 성과 보고)

### A-3. 허락 화면 만들기 — **'개인(Personal)'으로** (10분)
1. ☰ → **Google Auth Platform** → **시작하기**
   - 앱 이름: `승민T 게시 도구`, 지원 이메일: 본인
   - **대상(Audience)**: **개인(Personal)** 고르기 ← 중요
2. **데이터 액세스(Data Access)** → 범위 추가 → 아래 세 개를 찾아 체크(또는 '직접 입력' 칸에 붙여넣기) → 저장
   ```
   https://www.googleapis.com/auth/youtube.upload
   https://www.googleapis.com/auth/youtube.readonly
   https://www.googleapis.com/auth/yt-analytics.readonly
   ```

**왜 '개인'인가**: Google 공식 도움말에 따르면 '개인' 방식은 **앱을 만든 그 구글 계정 하나만** 쓸 수 있는 대신, 앱 심사가 필요 없고, '확인되지 않은 앱' 경고도 안 나오며, **7일 만에 허락이 끊기는 규칙도 없다**. 강사 한 사람이 쓰기에 딱 맞다.

> ⚠ '개인'은 한 번 고르면 바꿀 수 없다.
> 만약 '개인'이 목록에 없거나, 뒤 A-5에서 브랜드 계정 채널이 선택되지 않으면: 새 프로젝트를 만들어 **외부(External)**를 고르고 → 대상 화면에서 **앱 게시(프로덕션으로 푸시)**를 누른다. 이때 허락 화면에 'Google에서 확인하지 않은 앱' 경고가 뜨는데, 본인이 만든 앱이므로 **고급 → (앱 이름)(으)로 이동**을 누르면 된다.
> **'테스트' 상태로 두면 안 된다** — 7일마다 허락이 끊긴다.

### A-4. 클라이언트(프로그램 신분증) 만들기 (5분)
1. **Google Auth Platform → 클라이언트 → 클라이언트 만들기**
2. 애플리케이션 유형: **웹 애플리케이션**, 이름: `playground`
3. **승인된 리디렉션 URI**에 추가: `https://developers.google.com/oauthplayground`
4. **만들기** → '클라이언트 ID'와 '클라이언트 보안 비밀번호'가 나온다.
   - ⚠ **보안 비밀번호는 이 창에서만 보일 수 있다.** 창을 닫기 전에 **JSON 다운로드**를 눌러 PC에 저장해 둔다(채팅에 올리지 않음).

### A-5. 업로드 허락 받기 — OAuth Playground (10분)
1. developers.google.com/oauthplayground 열기
2. 오른쪽 위 ⚙(톱니) → **Use your own OAuth credentials** 체크 → A-4의 ID·비밀번호 붙여넣기. **Access type: Offline** 확인.
3. 왼쪽 **Step 1** 아래 입력칸에 A-3의 세 줄을 한 줄씩(띄어쓰기로 구분) 붙여넣기 → **Authorize APIs**
4. 구글 계정 선택 → **채널 선택 화면이 나오면 '통합사회 승민T' 채널**(브랜드 계정) 선택 → 허용
5. **Step 2** → **Exchange authorization code for tokens** → 나온 **Refresh token**(갱신 토큰) 복사
6. 클라우드 환경 메뉴 → 편집 → **환경 변수**에 한 줄 추가: `YT_REFRESH_TOKEN=복사한 값` → 저장
7. 이 채팅에 "유튜브 A-5까지 했음"이라고 쓴다 → Claude가 **열쇠 입력 카드**를 띄운다:
   - 주소 `oauth2.googleapis.com`, 방식 **아이디/비밀번호(Basic)**
   - 아이디 칸 = 클라이언트 ID, 비밀번호 칸 = 클라이언트 보안 비밀번호 (A-4에서 받은 JSON 파일에 있음)

> 갱신 토큰과 클라이언트 비밀번호를 **다른 곳에 나눠 둔다**. 갱신 토큰만 있으면 비밀번호 없이 쓸 수 없어서 안전하다.
> 환경 변수는 새 세션부터 적용된다. Claude가 확인할 때 새 세션이 필요하다고 하면 그대로 따르면 된다.

### A-6. 확인
- Claude가 `node 홍보/자동화/post.mjs token check` → "유튜브: 연결됨 (통합사회 승민T)"이 나오면 끝.
- 첫 업로드는 **비공개 시험 영상**(10초짜리)으로 해 보고, 강사가 Studio에서 보인 뒤 지운다.

### 유튜브 자동 업로드 규칙 (Claude가 지킴)
- 언제나 **비공개** 또는 **예약 공개(publishAt)**로 올린다. 2026-11-02부터는 공개 범위를 안 적으면 '공개'가 기본이 되었기 때문에, 도구가 항상 '비공개'를 직접 적는다.
- 아동용 여부, 유료 광고(PPL) 여부, 합성 미디어(실제처럼 보이는 AI) 여부를 **매번 적는다**. 유료 광고 여부는 2026-11-16부터 기본값이 없어졌다.
- 하루 업로드 한도 100회(1인 채널에는 충분).

### 유튜브 허락이 끊기는 경우
- 6개월 동안 한 번도 안 쓰면 끊긴다. 주간 보고서가 매주 쓰므로 걱정 없다.
- 구글 비밀번호를 바꾸면 끊길 수 있다 → A-5만 다시 하면 된다(10분).

## B. 인스타그램 (PC, 약 30분)

필요한 것: 인스타 **크리에이터 계정**(계정_만들기 2-2), **공개 계정**, 페이스북 계정(Meta 개발자 가입용 — 페이스북에 아무것도 올리지 않음).

### B-1. Meta 개발자 가입 (5분)
1. developers.facebook.com → **시작하기** → 페이스북 계정으로 로그인 → 휴대폰·이메일 인증 → 직업 '개발자'든 무엇이든 선택.

### B-2. 앱 만들기 (5분)
1. **내 앱 → 앱 만들기**
2. 앱 이름: `seungmint-insta`, 이메일: 본인
3. 사용 사례: **기타(Other)** → 앱 유형: **비즈니스(Business)** → 만들기
   (화면에 'Instagram에서 메시지 및 콘텐츠 관리' 같은 인스타 사용 사례가 보이면 그것을 골라도 된다)
4. '비즈니스 포트폴리오 연결'을 물으면 **지금은 연결 안 함**.
5. 앱 화면 → **제품 추가 → Instagram → 설정** → 'Instagram 로그인으로 API 설정'이 생긴다.

### B-3. 권한 확인 (3분)
'Instagram 로그인으로 API 설정' 화면의 권한 목록에 아래가 있는지 본다:
- `instagram_business_basic` (기본)
- `instagram_business_content_publish` (게시)
- `instagram_business_manage_insights` (주간 성과 보고)

### B-4. 내 인스타 계정 연결 + 토큰 받기 (10분)
1. 같은 화면 **1. 액세스 토큰 생성** → **계정 추가** → `seungmint.tonghap`으로 인스타 로그인 → 허용
   - **테스터 초대를 수락하라고 나오면**: PC 인스타그램(instagram.com) → 설정 → **앱 및 웹사이트** → **테스터 초대** → 수락. 그다음 다시 '계정 추가'.
2. 계정 옆 **토큰 생성** → 인스타 로그인 → 나온 긴 글자(토큰)를 **복사만** 한다(채팅에 붙이지 않음).
3. 이 채팅에 "인스타 토큰 복사했음" → Claude가 **열쇠 입력 카드**(주소 `graph.instagram.com`)를 띄운다 → 붙여넣고 저장.
4. Claude가 `token check`로 "인스타그램: 연결됨 (@seungmint.tonghap)"을 확인하고, 저장한 날짜를 기록한다.

> 대시보드에서 받은 토큰은 **60일** 쓸 수 있다. 앱을 '라이브(공개)'로 바꾸거나 비즈니스 인증을 할 필요는 없다(본인 계정만 쓰기 때문, 첫 연결 때 실제로 확인).

### B-5. 첫 게시는 같이
1. Claude가 카드뉴스를 JPEG로 바꾸고 → 강사가 그림·캡션을 확인 → "올려도 됨"
2. Claude가 게시 → 인스타 앱에서 확인. 이상하면 바로 앱에서 지우면 된다.

### 인스타 토큰 갱신 (약 50일마다, 5분)
- 토큰은 60일이면 끊긴다. Claude가 매주 확인해서 **만료 7일 전**에 알린다.
- 알림이 오면: B-4의 2~3만 다시(대시보드에서 **토큰 생성** → 열쇠 카드에 새 값 저장).
- (참고: 프로그램으로 연장하는 방법도 있지만, 연장하면 새 토큰 글자가 나와서 어차피 다시 저장해야 한다. 그래서 대시보드에서 새로 받는 방법이 더 간단하다.)

### 인스타 API의 한계
- 그림은 **JPEG만**, 8MB 이하, 비율 4:5(세로)~1.91:1(가로). 카드뉴스는 1080×1350(4:5)이라 맞다.
- 그림은 **누구나 열 수 있는 인터넷 주소**에 있어야 한다 → [이미지_공개주소.md](이미지_공개주소.md)
- API로는 인스타 앱의 **음악**을 넣을 수 없다. 음악이 필요한 릴스는 강사가 앱에서 올린다.
- 정확히 '저녁 7시' 게시는 어렵다(예약 작업이 1시간 단위). 시각이 중요하면 Meta Business Suite의 무료 예약을 쓴다.

## C. 스레드 (2~3개월 뒤, 약 20분)

인스타와 비슷하다. **시작할 때 이 채팅에서 화면을 보며 같이 한다.** 미리 알아 둘 것:
1. developers.facebook.com → **앱 만들기** → 사용 사례 **Threads API 액세스(Access the Threads API)** (인스타 앱과 따로 만든다)
2. 권한: `threads_basic`, `threads_content_publish`, `threads_manage_insights`
3. **앱 역할 → 역할 → 사람 추가 → Threads 테스터** → `seungmint.tonghap` 초대
4. 스레드 앱 또는 threads.com → **설정 → 계정 → 웹사이트 권한 → 초대** → 수락
5. 토큰 받기 → 열쇠 카드(주소 `graph.threads.com`). 토큰 받는 화면은 시작할 때 최신 화면으로 다시 확인한다.
- 한도: 글 500자, 서로 다른 링크 5개까지(2025-12-22부터), 하루 250개. 토큰은 60일.

## 자동화가 멈추는 곳과 대비

| 멈추는 이유 | 대비 |
|---|---|
| 인스타·스레드 토큰 60일 만료 | 매주 확인, 7일 전 알림 → 대시보드에서 새로 받아 다시 저장 |
| 유튜브 허락 '테스트' 상태 → 7일 만료 | A-3에서 '개인' 또는 '프로덕션'으로 |
| 인스타 계정이 개인 계정으로 돌아감 | 크리에이터 계정 유지 |
| 그림 공개 주소가 안 열림 | 게시 전에 도구가 먼저 확인하고 멈춤 |
| 같은 글을 두 번 올림 | 게시 기록 파일로 막음 |
| 실수로 공개 | 처음 2~4주는 '초안 → 강사 확인 → 게시'. 유튜브는 항상 비공개·예약 |

## 안 하는 것
- 네이버 블로그 자동 발행 프로그램(매크로): 계정 제재 위험 → 강사가 붙여 넣고 예약 발행.
- 카카오톡 채널: 발송 API 없음 → 강사가 관리자센터에서 예약 발송.
- 틱톡: 보류(본인 전용 도구는 공개 게시가 안 됨).
