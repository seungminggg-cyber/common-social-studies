# 유튜브 영상 만들기 (긴 영상·쇼츠·썸네일)

원고(`content/*.js`) 한 파일 = 영상 한 편. 문장마다 목소리를 만들고, 그 길이에 맞춰 장면 움직임·자막을 맞춘 뒤 mp4로 만든다.

## 만들기
```bash
(cd textbook && npm install)        # 글꼴·아이콘 (한 번만)
pip install edge-tts                # AI 목소리 (견본 전용)
node 홍보/영상/make.mjs v01 --stills   # 문장마다 정지 화면만 (빠른 확인, 몇 초)
node 홍보/영상/make.mjs v01            # 영상 (3분 영상 약 10분 걸림)
node 홍보/영상/make.mjs v01 --voice ko-KR-InJoonNeural   # 다른 목소리로
node 홍보/영상/make.mjs v01 --audio 녹음폴더              # 강사 녹음으로 (01.m4a, 02.m4a … 원고.txt 번호 순서)
```
결과 `홍보/영상/out/<원고 이름>/`: `영상.mp4`, `썸네일.png`, `자막.srt`(유튜브 자막 올리기용), `원고.txt`(녹음용 번호 붙은 원고), `설명_복사용.txt`(챕터 시각 자동). `out/`은 커밋하지 않는다.

## 원고 쓰는 법
- `scenes: [{ chapter, cls: 'dark', lines: [{ t, say }], html }]`
- `t`: 자막 겸 원고. `|`에서 자막을 나눔. `**굵게**`는 민트색. 읽는 말이 다르면 `say`(예: 25문항 → '스물다섯 문항').
- 움직임: `data-a="이름@언제/길이"`, 여러 개는 `;`. 이름은 `lib/motion.css`(up, pop, wipe, draw, hl, strike, dim …) 또는 원고 css의 @keyframes.
- 언제: `L2`(두 번째 문장 시작), `L2+0.3`, `w:25문항`(그 단어를 말하는 순간), `w3:고1`(세 번째 문장 안), `s+0.5`(장면 시작 뒤).
- 숫자 올라가기: `<b data-count="25" data-from="20" data-at="w:스물다섯">20</b>`.
- 색·글꼴은 `홍보/lib/brand.css`(디자인 채팅 담당)를 그대로 가져다 쓴다.

## 주의
- **edge-tts는 비공식 통로라 견본 전용.** 실제 게시 영상은 강사 녹음(`--audio`) 또는 사용권이 확인된 유료 AI 목소리.
- 유튜브 '진정성 없는 콘텐츠' 정책: 설명 없는 슬라이드쇼가 아니라 말에 맞춰 도표가 움직이는 설명 영상으로 만든다.
- 예비 고1 대상: '선행·미리·앞서' 쓰지 않음. 숫자에는 출처(화면 아래 '자료:' 줄, 설명란).
- 쇼츠는 화면 아래 약 1/4을 유튜브 버튼이 덮으므로 중요한 것은 위쪽에.
