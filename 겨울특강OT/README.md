# 겨울특강 OT 촬영용 PPT

예비 고1 통합사회 겨울방학 10주 특강 OT 영상을 찍을 때 쓰는 발표 자료(16:9, 36장).
학원 **초록 칠판에 빔으로 쏴서** 촬영하는 것을 기준으로 디자인했다.

## 만드는 순서
```bash
# 0) 미니맵 표지 그림(처음 한 번): 기출변형 폴더에서
cd 기출변형 && node cover/build-cover.mjs mmapfinal && cd ..
# 1) 부품 설치
cd 겨울특강OT && npm install
# 2) 네온 그림(지구본·로고·숫자·아이콘) → out/art/
node art.mjs
# 2-1) 움직이는 지구본: 반짝이는 반복 GIF + 서울에서 뻗는 화살표 12조각 → out/art/globe-*
node globe-anim.mjs && python3 globe_post.py
# 3) 앱 화면 휴대폰 틀·개념서 쪽·표지 JPEG → out/art/
python3 frames.py
# 4) PPT(애니메이션 포함) → out/승민T-통합사회-겨울특강-OT.pptx
node build.mjs
# 5) 예비용 PDF(글꼴이 없는 PC용) → out/…pdf
python3 pdf.py
# 6) 초록 칠판에 쏜 모습 미리보기(계산으로 만든 대략적인 모습)
python3 board_preview.py            # 대표 6장 → out/칠판미리보기.jpg
python3 board_preview.py --all      # 모든 장 → out/칠판미리보기-전체.pdf
python3 board_preview.py --light    # 조명 3가지 비교 → out/칠판미리보기-조명비교.jpg
# 7) 학원 칠판에 직접 띄워 보는 테스트용 PPT(5장: 화면 크기·색·밝기 계단·글자 크기·선 굵기) → out/칠판-테스트.pptx
node test-deck.mjs
```
- 글꼴은 Pretendard(무료, OFL). 촬영 PC에 설치해야 PPT가 디자인대로 보인다(`out/Pretendard-글꼴-설치용.zip`).
- `pdf.py`는 LibreOffice가 한글과 숫자 사이에 넣는 빈칸("10 주")을 끄고 변환한다. PowerPoint 화면과 거의 같다.
- 마지막 슬라이드 '촬영 전 점검'은 숨김 슬라이드다(빔 크기·색·글자 크기 확인용).
- 칠판 테스트: `칠판-테스트.pptx`를 실제 칠판에 띄우고 촬영 카메라 자리에서 폰으로 찍는다. 번호(색 1~12, 밝기 1~10, 선 1~6, 상자 A~C)로 결과를 받아 `palette.mjs` 색과 글자 크기를 고친다.

## 반전용 판 (2026-11-20)
- 학원 칠판에 띄웠더니 화면 색이 통째로 반전돼 나왔다(검정 바탕 → 흰색, 흰 글자 → 검정, 그림까지). 파일이 아니라 PC(윈도 색 필터, 단축키 Windows+Ctrl+C)나 빔 설정 때문.
- 설정을 끌 수 없을 때: `python3 invert_art.py && OT_INVERT=1 node build.mjs` → `out/…-반전용.pptx`. 색·그림을 미리 뒤집어 둬서(반전 × 반전 = 원래 색) 반전된 화면에서 원래 디자인대로 보인다. PC 화면에서는 흰 바탕 + 빨간 글자로 보이는 게 정상.
- 반전용 PDF: `python3 pdf.py "out/승민T-통합사회-겨울특강-OT-반전용.pptx" "out/승민T-통합사회-겨울특강-OT-반전용.pdf"`

## 애니메이션 (2026-11-20)
- pptxgenjs는 애니메이션을 못 넣어서, `anim.mjs`가 만든 .pptx의 슬라이드 XML에 PowerPoint 애니메이션(`<p:timing>`)을 직접 써 넣는다. 같은 그림이 여러 번 들어가면 하나로 합친다.
- `build.mjs`에서 `mark(s, '이름')` 다음에 그린 도형이 한 묶음, `plan(s, { auto, clicks })`로 묶음마다 [이름, 효과, 시작 ms, 설정]을 정한다.
  - auto = 슬라이드가 열리면 저절로, clicks = 클릭 한 번마다(그 안에서는 차례로 저절로). 강사 요청: 클릭 한 번에 차례로 자동, 2쪽 '직접 만들었습니다' 상자는 한 번에.
  - 효과: fade(서서히) · float(떠오르기) · zoom(확대, from=시작 배율) · wipe(닦아내기, dir l·r·t·b) · flicker(네온 깜빡이며 켜짐) · breathe(은은한 반복).
- 발표자 노트 맨 위에 '▶ 클릭 N번 — ①…'이 저절로 붙는다(클릭 모두 24번).
- 지구본: 바탕은 계속 반짝이는 GIF(둘레 빛 숨쉬기·서울 핑·도시 점·작은 별), 화살표 12개는 표지·마무리에서 서울에서 하나씩 닦아내기로 뻗는다. 단원 구분 화면은 GIF + 화살표 고정, 네온 숫자만 깜빡이며 켜짐.
- 이 환경에서는 PowerPoint로 재생해 볼 수 없다. LibreOffice로 열어 효과가 읽히는지(종류·방향·반복) 확인했다 — 실제 움직임은 강사 PowerPoint 슬라이드 쇼로 확인. PDF에는 애니메이션이 없다(다 나타난 화면).

## 디자인 규칙 (칠판에 쏘는 화면)
- 바탕은 **검정**: 빛을 안 쏘는 곳이라 칠판 색이 그대로 보인다. 흰 바탕은 칠판 전체를 번쩍이게 한다.
- 글자·선은 밝은 색만: 흰색, 하늘(미니맵 통합사회1 네온), 민트, 분필 노랑, 분홍(통합사회2). 빨강·진한 파랑·보라는 칠판 위에서 탁해진다.
- 칠판 위에서는 흰색과 하늘색이 거의 같은 민트색으로 보인다 → **강조는 노랑**이 맡는다.
- 영상(폰 화면)으로 보므로 본문 17~26pt 이상, 제목 36pt, 선은 굵게.
- 슬라이드 글은 짧게, 말할 내용은 **슬라이드 노트**(발표자 보기)에 블로그 글을 바탕으로 적었다.
- 모양은 미니맵 표지와 같은 네온(지구본, 서울에서 퍼지는 '핑' 점, 노선도, 모서리 잘린 상자).
