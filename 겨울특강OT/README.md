# 겨울특강 OT 촬영용 PPT

예비 고1 통합사회 겨울방학 10주 특강 OT 영상을 찍을 때 쓰는 발표 자료(16:9, 36장).
학원 **초록 칠판에 빔으로 쏴서** 촬영하는 것을 기준으로 디자인했다.

## 만드는 순서
```bash
# 0) 미니맵 표지 그림(처음 한 번): 기출변형 폴더에서
cd 기출변형 && node cover/build-cover.mjs mmapfinal && cd ..
# 1) 부품 설치
cd 겨울특강OT && npm install
# 2) 네온 그림(지구본·로고·숫자·아이콘) → out/art/
node art.mjs
# 3) 앱 화면 휴대폰 틀·개념서 쪽·표지 JPEG → out/art/
python3 frames.py
# 4) PPT → out/승민T-통합사회-겨울특강-OT.pptx
node build.mjs
# 5) 예비용 PDF(글꼴이 없는 PC용) → out/…pdf
python3 pdf.py
# 6) 초록 칠판에 쏜 모습 미리보기(계산으로 만든 대략적인 모습)
python3 board_preview.py            # 대표 6장 → out/칠판미리보기.jpg
python3 board_preview.py --all      # 모든 장 → out/칠판미리보기-전체.pdf
python3 board_preview.py --light    # 조명 3가지 비교 → out/칠판미리보기-조명비교.jpg
# 7) 학원 칠판에 직접 띄워 보는 테스트용 PPT(5장: 화면 크기·색·밝기 계단·글자 크기·선 굵기) → out/칠판-테스트.pptx
node test-deck.mjs
```
- 글꼴은 Pretendard(무료, OFL). 촬영 PC에 설치해야 PPT가 디자인대로 보인다(`out/Pretendard-글꼴-설치용.zip`).
- `pdf.py`는 LibreOffice가 한글과 숫자 사이에 넣는 빈칸("10 주")을 끄고 변환한다. PowerPoint 화면과 거의 같다.
- 마지막 슬라이드 '촬영 전 점검'은 숨김 슬라이드다(빔 크기·색·글자 크기 확인용).
- 칠판 테스트: `칠판-테스트.pptx`를 실제 칠판에 띄우고 촬영 카메라 자리에서 폰으로 찍는다. 번호(색 1~12, 밝기 1~10, 선 1~6, 상자 A~C)로 결과를 받아 `palette.mjs` 색과 글자 크기를 고친다.

## 디자인 규칙 (칠판에 쏘는 화면)
- 바탕은 **검정**: 빛을 안 쏘는 곳이라 칠판 색이 그대로 보인다. 흰 바탕은 칠판 전체를 번쩍이게 한다.
- 글자·선은 밝은 색만: 흰색, 하늘(미니맵 통합사회1 네온), 민트, 분필 노랑, 분홍(통합사회2). 빨강·진한 파랑·보라는 칠판 위에서 탁해진다.
- 칠판 위에서는 흰색과 하늘색이 거의 같은 민트색으로 보인다 → **강조는 노랑**이 맡는다.
- 영상(폰 화면)으로 보므로 본문 17~26pt 이상, 제목 36pt, 선은 굵게.
- 슬라이드 글은 짧게, 말할 내용은 **슬라이드 노트**(발표자 보기)에 블로그 글을 바탕으로 적었다.
- 모양은 미니맵 표지와 같은 네온(지구본, 서울에서 퍼지는 '핑' 점, 노선도, 모서리 잘린 상자).
