# 촬영용 개념 강의 자료 (판서 화면 + 녹음 + 영상)

판서가 한 단계씩 나타나는 강의 화면을 만든다. 강사가 화면을 넘기며 목소리만 녹음하면, 그 녹음에 맞춰 판서가 나타나는 강의 영상(mp4)을 만든다.
**쓰는 기준은 `작성기준.md`** (담백한 말투, 강조색 하나, 장식 없음)를 따른다.
이 저장소에서는 **통합사회** 강의 영상을 만들 때 쓴다(아직 통합사회 강의는 없음).
형식 견본(사회와 문화 Ⅰ-2 탐구 방법 4강)은 `society-and-culture` 저장소의 `강의자료/content/1-2.js`에 있다.
선택 과목 강의는 과목별 저장소에서 만든다. 도구를 고치면 `class-prep-template`에도 반영한다.

## 강사가 쓰는 법
1. `강의화면.html`을 **크롬이나 엣지로 연다** (파일을 더블클릭하거나 브라우저 창에 끌어 놓기).
2. 발표처럼 보기: → 키(또는 화면 클릭)로 판서가 하나씩 나타나고, ← 키로 되돌린다. `F`는 전체 화면, `T`는 차례.
3. `N`을 누르면 오른쪽에 **녹음 메모**가 나온다. 지금 단계에서 할 말이 표시된다.
4. `R`을 누르면 **녹음 모드**가 된다. 다시 `R`을 누르면 3·2·1 뒤에 녹음이 시작된다.
   - → 키로 판서를 넘기며 말한다. 마지막 판서에서 →를 누르면 그 화면 녹음이 끝나고, 다음 화면 녹음이 바로 이어진다.
   - 틀리면 `R`로 멈추고 그 화면에서 다시 `R`을 누른다. 그 화면의 녹음만 바뀐다.
   - ‘이 화면 들어보기’로 판서와 목소리가 맞는지 바로 확인한다.
   - 녹음은 브라우저 안에 보관되어 창을 닫았다 열어도 남는다. 다른 컴퓨터로 옮길 때는 저장한 파일을 ‘불러오기’로 연다.
5. 다 녹음하면 **‘녹음 파일 저장’**을 누르고, 생긴 `.json` 파일을 Claude에게 보낸다 → 강마다 영상(mp4)을 만들어 준다.

메모에서 `[사례를 읽어 준다]`처럼 대괄호 안에 있는 것은 할 일 안내다.
claude.ai 미리 보기 페이지에서는 마이크를 쓸 수 없어서 녹음이 되지 않는다(보기만 된다).

## 결과물 (`out/<강의 id>/`, 저장소에는 올리지 않음)
| 파일 | 내용 |
|---|---|
| `강의화면.html` | 발표·메모·녹음 화면. 글꼴까지 들어 있어 이 파일 하나로 동작한다 |
| `artifact.html` | 같은 화면을 claude.ai 페이지로 올릴 때 쓰는 판(녹음 안 됨) |
| `판서노트_학생용.pdf` | 화면을 2장씩 담고, 빈칸과 O·X 정답을 비운 노트 |
| `판서노트_교사용.pdf` | 같은 노트를 다 채운 것 |
| `녹음메모.pdf` | 화면 1장마다 판서 그림과 단계별로 할 말 |
| `png/` | 확인용 화면 그림(`png` 옵션) |
| `영상/<n>강_<제목>.mp4` | `make-video.mjs` 결과(1920×1080, 30fps) |

## 만드는 법 (Claude용)
```bash
bash scripts/setup-env.sh                 # 글꼴(textbook/node_modules)과 pyftsubset(fonttools, brotli) 준비
node 강의자료/build.mjs <강의 id>          # 강의화면.html + PDF 3개 (id 없이 실행하면 목록)
node 강의자료/build.mjs <강의 id> png nopdf   # 화면 그림만 (넘치는 화면 검사도 함께)
node 강의자료/make-video.mjs <녹음파일.json> [강 번호…] [--partial] [--no-anim]
```
- 영상에서 판서는 녹음 때 →를 누른 시각대로 나타나고, 나타나는 움직임(0.66초)도 1/30초씩 찍어 넣는다.
  - 소리는 이어 붙인 뒤 세 가지를 손본다: 낮은 웅웅 소리 거르기, 약한 잡음 줄이기, 음량 맞추기(−16 LUFS).
  - 8분짜리 강 하나에 2~3분 걸린다. `--no-anim`이면 더 빠르다.
- 미리 보기 페이지: `out/<id>/artifact.html`을 Artifact 도구로 올린다(아이콘 `slides`).

## 내용 쓰는 법 (`content/<id>.js`)
- 파일 이름(= id)은 선택 과목은 `<대단원>-<중단원>`(예: `1-2.js`), 통합사회는 책 이름을 앞에 붙인다(예: `t1-1-1.js` = 통합사회1 Ⅰ-01).
- 강(`lectures`) 안에 화면(`slides`)이 있다.
  - 화면마다 `tag`, `title`, `body`, `memo`를 쓴다. `tag`는 메모 칸에만 보이며 개념·도입·비교·주의·연습·자료·확인·정리 중 하나다.
  - 표지는 `kind: 'cover'`와 `today`(오늘 배울 것 목록, 하나씩 나타남)로 쓴다.
- `body`의 판서는 `lib/dsl.js` 도우미로 쓴다. 첫 인자는 몇 번째 단계에 나타나는지다.

| 도우미 | 쓰임 |
|---|---|
| `S` | 덩어리 |
| `I` | 글자 일부 |
| `B` | 빈칸. 강조색 글자로 채워지고, 학생용 노트에서는 빈칸으로 남는다 |
| `HL` | 옅은 바탕색 강조 |
| `UL` | 밑줄 |
| `CI` | 동그라미 |
| `H` | 정리 한 줄 |
| `A` | 글자 옆 회색 보충 |
| `LB` | 밑줄 + 이름 (사례 분석) |
| `O` / `X` | O·X 표시 |
| `ln` | 이름표 줄 |
| `pm` | 장점·한계 |
| `flow` | 흐름도 (예시 칸도 넣을 수 있음) |
| `oxList` | O·X 문제 |
| `cautions` | 주의할 점 |
| `bars` | 막대그래프 |
| `popDiagram` | 모집단·표본 그림 |

- **`memo` 개수 = 판서 단계 수 + 1**이다. 맞지 않으면 build가 멈추고 알려 준다.
- 필요한 부품(지도, 연표, 사상가 카드 등)이 없으면 `lib/dsl.js`와 `lib/deck.css`에 더한다. 이때도 작성기준의 디자인을 지킨다.
