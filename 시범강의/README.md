# 시범강의 촬영용 판서 슬라이드

통합사회1 Ⅳ-09 '문화 변동' 시범강의를 학원 초록 칠판에 빔으로 쏴서 찍을 때 쓰는 한 장짜리 PPT(16:10).
강사가 보낸 판서 그림에서 **문화 변동의 요인(1. 내재적 요인 · 2. 외재적 요인 = 문화 전파)** 과 **문화 동화 · 병존 · 융합 · 접변** 판서만 남겼다(2026-11-25).

```bash
node 시범강의/build.mjs   # → 시범강의/out/문화변동-판서-반전용.pptx (+ 정상색.pptx, 판서-미리보기.png)
python3 수능반OT/pdf.py 시범강의/out/문화변동-판서-반전용.pptx 시범강의/out/문화변동-판서-반전용.pdf
```
- 글씨: 나눔손글씨 펜(Nanum Pen Script, OFL, `textbook/node_modules/@fontsource/nanum-pen-script`)에 분필 질감(SVG 필터)을 입혀 줄마다 PNG로 넣는다 → 학원 PC에 글꼴이 없어도 똑같이 보인다. 글자를 고치려면 `build.mjs`의 `T(...)` 줄을 고치고 다시 만든다.
- 반전용: 학원 PC·빔이 색을 반전시키므로 바탕(흰색)과 그림 색을 미리 뒤집었다. PC 화면에서 흰 바탕이 정상. 정상색 판은 칠판 미리보기용.
- 애니메이션: 클릭 12번(문화 변동의 요인 → 내재적 → 발명 → 발견 → 외재적 → 직접 → 간접 → 자극 → 동화 → 병존 → 융합 → 접변). 한 번 클릭하면 그 줄과 예시가 분필로 쓰듯 왼쪽부터 닦아내기로 차례로 나온다. 원은 확대, 융합의 C는 깜빡이며 켜짐. 효과는 `../수능반OT/anim.mjs`.
