## 재수·N수 커리큘럼 (대형 재종 3시즌 기준, 2026-11-12 강사 결정)

강사 결정: 재수·N수반은 따로 합류 경로를 만들지 않고 대형 재종(강남대성·메가스터디 러셀·시대인재)과 같은 시즌으로 운영한다.
근거(2026학년도 사탐 기준): 강남대성 시즌1 개강~6월 말·시즌2 7월~9평·시즌3 9평~종강, 사회 실모는 7월부터(강대K 사회 7~11월 34회).
러셀은 2~6월 개념·기출·EBS 변형, 7~8월 상 난이도 + 실모, 9~11월 FINAL. 사탐 실모는 3~6월 월 1회, 7월부터 매주.
시대인재는 상반기 기출 분석서·브릿지 모의고사, 하반기 N제·서바이벌 모의고사(7월~). 대성 시즌ZERO는 1월 초~2월 중순, 반수 시즌은 6월 중순.

## 준비할 것 (강사 메모)

- 새로 만들 교재: 여름 고난도 문제(진도용) + 여름 고난도 실모 6회, MAXIMIN FINAL 8회. MAXIMIN 지금 책(실모 10회)은 봄에 과목별 6회, 여름에 전 범위 4회로 나눠 쓴다.
- 고1 학평 실모: 범위가 다르다(6월 통합사회1 Ⅰ~Ⅳ-3, 9월 통합사회1 + 통합사회2 Ⅰ·Ⅱ, 10월 통합사회2 Ⅳ-1까지). 고2·고3 실모(전 범위)와 따로 고른다. 겨울에 이미 푼 고1 학평 기출은 피한다.
- 겨울 합반: 예비 고1은 처음 배우는 내용이라 속도가 빠를 수 있다. 앱 매일 퀴즈나 짧은 보충으로 복습을 챙긴다.
- 고2 조교 1:1 선택과목: 수강생 학교의 고2 편성표를 먼저 모은다. 일반·진로선택은 5등급 상대평가, 사회·과학 융합선택 9과목만 절대평가(2028 대입 개편 확정안).
- 고2가 그만두지 않게: 학평 시즌 4번 + 여름 특강 묶음 등록, 학평 직후 성적 상담, 쉬는 기간에는 앱 퀴즈·오답 노트.
- 날짜 고칠 때: 2027년 학평 시행 계획(2~3월), 2028 수능 시행 계획(3월 말: EBS 연계 비중, 모평 날짜), 학교별 시험 일정표(3월·9월).
