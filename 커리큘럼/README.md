## 준비할 것 (강사 메모)

- 새로 만들 교재: **여름 고난도 문제집**(수특 변형은 2~5월, 수완 변형은 5월 말~6월 초, 6모 변형은 6모 뒤 2주 안), **MAXIMIN FINAL** 6~8회(9모 뒤 마감). MAXIMIN 지금 책(실모 10회)은 여름 '시즌1'로 쓴다.
- 고1 학평 실모: 범위가 다르다(6월 통합사회1 Ⅰ~Ⅳ-3, 9월 통합사회1 + 통합사회2 Ⅰ·Ⅱ, 10월 통합사회2 Ⅳ-1까지). 고2·고3 실모(전 범위)와 따로 고른다.
- 겨울 합반: 예비 고1은 처음 배우는 내용이라 속도가 빠를 수 있다. 앱 매일 퀴즈나 짧은 보충으로 복습을 챙긴다. 예비 고3은 1월 말 수능특강이 나오면 숙제로 같은 단원 문항을 더한다.
- 고2 조교 1:1 선택과목: 수강생 학교의 고2 편성표를 먼저 모은다. 일반·진로선택은 5등급 상대평가, 사회·과학 융합선택 9과목만 절대평가(2028 대입 개편 확정안).
- 고2가 그만두지 않게: 시즌 4번 + 여름 특강 묶음 등록, 학평 직후 성적 상담, 쉬는 기간에는 앱 퀴즈·오답 노트.
- 날짜 고칠 때: 2027년 학평 시행 계획(2~3월), 2028 수능 시행 계획(3월 말: EBS 연계 비중, 모평 날짜), 학교별 시험 일정표(3월·9월).
