# MINIMAX 킬러편 출제

## 목적
승민T 학원의 상위권 학생이 2028 수능 통합사회(첫 시행)에서 1등급을 받게 하는 최고 난도 문항집이다. 수능형 기출이 예시문항 25개뿐이라서, 이 책이 학생이 만나는 가장 수능다운 고난도 문제가 된다. 문항 200개를 다 쓰면, 같은 문항을 풀이 기술별로 묶어 **스킬특강 교재**를 만든다.

## 먼저 읽을 것 (이 순서로)
1. `기출변형/킬러편/기준.md` — 난도 기준, 이중추론, 형식 목표, 강사 규칙, 파일 형식, 스킬 태그. **이 책의 기준이다.**
2. `기출변형/킬러편/교훈.md` — 강사 검수 의견과 지난 작업의 교훈. 새로 배운 것은 여기에 적는다.
3. `기출변형/킬러편/진행.md` — 어디까지 했는지
4. `기출변형/킬러편/설계/<중단원키>.json` — 중단원별 재료와 문항 제안(설계 카드). **제안일 뿐이다.** 더 좋은 형식·소재가 떠오르면 바꾼다. 바꾸면 그 문항의 `src`·`kform`에 실제로 쓴 것을 적는다.
5. 필요할 때: `기출변형/CLAUDE.md`(문항 형식·표시 규칙·검사 도구), `기출변형/참고/3차지침.md`(평가원 3점 패턴), `기출변형/참고/3차작업/출제지시.md` 5절(자료 블록 쓰는 법), 견본 `기출변형/content/2/mock/m7.js`(강사가 승인한 회차)

## 품질 기준 (요약 — 자세히는 기준.md)
- 난도: 2028 예시문항 2.5점, 스타강사코리아 UNIVERCITY 2.5점과 같거나 더 어렵게. 어려움은 **추론**에서 나온다. 교과서 밖 지식으로 갈리는 선지는 쓰지 않는다.
- 모든 문항에 **이중추론**이 있다. 첫 추론의 결과가 두 번째 추론에 꼭 필요해야 한다.
- 수능형과 신유형을 고루 쓴다: 순서도, 질문 분류표, 표·그래프 분석, 계산, 학생 O/X 응답표, 수행평가 채점 결과 역추론, 벤 다이어그램, 지도 + 자료, 사료·문서. 이 밖의 새 유형도 직접 생각해 만든다.
- 정답은 자료와 개념서 안의 근거로 하나로 정해진다. 범위 = 개념서(`textbook/content/`).
- 원문 문장·자료·숫자를 옮기지 않는다(저작권). 원문 PDF·글자본·결과 PDF는 커밋하지 않는다.

## 확인 (출제자 ≠ 검토자)
- 새로 쓴 문항은 다른 에이전트(Opus, 노력 수준 high)가 `기출변형/킬러편/검토지시.md`대로 **정답을 가리고 다시 푼다.** 준비: `node 킬러편/도구/solve-prep.mjs <폴더> <단원키…>`, 대조: `python3 킬러편/도구/정답대조.py <폴더> "1-④, …"`.
- 검토자가 '예상 정답률 50% 넘음', '이중추론 약함', '지름길 있음'이라고 하면 난도를 올려 다시 쓴다. 정답이 다르게 나오면 원인을 찾아 고친다.
- 자동 검사·빌드는 기준.md 8절. 빌드·자동 검사는 Opus 하위 에이전트(노력 수준 low)에 맡겨도 된다.

## 사용량
- 하위 에이전트는 동시에 2~3개까지 돌린다. 하위 에이전트를 쓰면 비용이 많이 든다. 다시 풀기처럼 독립된 확인이 필요할 때와, 빌드처럼 생각이 필요 없는 일에만 쓴다.
- 한도로 멈추면 풀리는 시각에 `send_later`로 다시 깨우기를 예약한다.
- 중단원(또는 대단원) 하나가 끝날 때마다 커밋하고 push한다. `진행.md`에 몇 문항까지 했는지 적는다.
