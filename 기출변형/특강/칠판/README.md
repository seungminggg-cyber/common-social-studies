# 초록 칠판 + 빔 프로젝터용 시범강의 PPT

2028 수능 예시문항 통합사회 5·15·21번을 해설하는 시범강의 영상용 PPT(2026-11-19 강사 요청, 11-20 두 번 수정). 표지 + 문항 3장.

## 강사가 정한 것
- 문항: 5번(기온·강수 편차), 15번(롤스·노직 벤 다이어그램), 21번(비교 우위). 모두 2.5점.
- 16:9, 파워포인트. 화면에는 **원문만** 띄우고 풀이는 전부 분필로 판서.
- **한 문항 = 한 장**(발문 + 자료 + 〈보기〉 + 선지). 처음엔 앞장(자료)·뒷장(선지) 두 장이었으나, 강사가 시강 시뮬레이션 뒤
  "한 문제가 두 장으로 나뉘면 판서하며 수업하기 불편하다"고 해 한 장으로 합침(2026-11-20).
- 판서 칸: 모든 장에서 오른쪽 약 40%를 비워 둠(장을 넘겨도 판서가 화면 글자와 겹치지 않게).
- 2026-11-20: "원본 문제와 정말 유사하게" → 글자를 다시 입력하던 방식을 버리고 **평가원 문제지 원본을 부분별로 잘라 분필색 그림으로** 넣는다.
  (다시 입력한 판은 파워포인트에서 15번 제시문 들여쓰기와 5번 공식의 '−' 자리가 어긋났음)

## 디자인
- 바탕은 검정: 빔이 빛을 쏘지 않는 곳은 초록 칠판이 그대로 보인다. 흰 바탕을 쓰면 칠판을 덮어 분필 글씨가 안 보인다.
- 원본 그림의 어두운 부분 → 흰색(투명도로), 흰 바탕 → 투명. 그래서 글자·선·빗금·그래프·교사 그림이 분필로 그린 것처럼 보인다.
  선이 가늘면 빔에서 흐려지므로 600dpi에서 1px 굵게 한다. 문항 번호만 분필 노랑.
- 한 장 안의 부분 그림은 같은 배율(시험지와 같은 글자 크기 비율), 가로 위치도 원본 들여쓰기 그대로.
  한 장에 문제 전체가 들어가므로 **높이가 배율을 정한다**: 5번 원본의 약 1.06배(본문 약 10pt), 15번 1.12배(11pt), 21번 1.39배(13pt).
  글자가 세로로 길어 실제로 차지하는 폭은 화면의 40~50%뿐이라 판서 칸은 오른쪽 절반 이상 남는다.
  (두 단으로 나눠도 판서 칸 40%를 지키면 더 커지지 않음 — 칠판에서 더 크게 보려면 빔 화면 자체를 크게 띄운다)
- 정답·단서·선지별 판단은 **발표자 노트**에만(`../content/analysis.js`에서 가져옴). 화면에는 안 나온다.

## 만들기
원문(평가원 문제지 PDF·잘라 낸 그림·PPT)은 저작권 때문에 저장소에 올리지 않는다(`기출변형/out/`은 커밋 안 됨).

```bash
python3 -I 기출변형/특강/칠판/crop-chalk.py <예시문항 문제지 PDF> 기출변형/out/시범강의/chalk
cd <작업 폴더> && npm install pptxgenjs jszip
NODE_PATH=<작업 폴더>/node_modules node 기출변형/특강/칠판/build-deck.cjs 기출변형/out/시범강의/chalk 기출변형/out/시범강의/시범강의-5-15-21.pptx
```
- `crop-chalk.py`: pdftotext -bbox로 문항 번호·선지 줄을 찾고, 자료 상자 위·아래 테두리는 600dpi 그림의 긴 가로줄로 찾아 자른다.
  21번 뒷장의 작은 표는 '두 표 사이 틈이 비어 있는 가로줄'로 찾아 말풍선·칠판 받침을 뺀다. 결과는 부분별 PNG + `parts.json`(원본 위치·크기, pt).
- 다른 문항을 더하려면 `crop-chalk.py`에 그 문항의 부분(발문·자료·선지)을 넣고 `build-deck.cjs`의 `item(번호, [부분…])` 한 줄을 더한다.
- 발표자 노트: 정답·핵심 단서·풀이 순서 + [선지 판단]·함정(`../content/analysis.js`).
