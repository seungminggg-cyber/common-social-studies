# 초록 칠판 + 빔 프로젝터용 시범강의 PPT

2028 수능 예시문항 통합사회 5·15·21번을 해설하는 시범강의 영상용 PPT(2026-11-19 강사 요청).

## 강사가 정한 것
- 문항: 5번(기온·강수 편차), 15번(롤스·노직 벤 다이어그램), 21번(비교 우위). 모두 2.5점.
- 16:9, 파워포인트. 화면에는 **원문만** 띄우고 풀이는 전부 분필로 판서.
- 문항마다 2장: 앞장 = 발문 + 자료, 뒷장 = 발문(작게) + 자료(작게) + 선지.
- 판서 칸: 모든 장에서 오른쪽 약 40%를 비워 둠(장을 넘겨도 판서가 화면 글자와 겹치지 않게).

## 디자인
- 바탕은 검정: 빔이 빛을 쏘지 않는 곳은 초록 칠판이 그대로 보인다. 흰 바탕을 쓰면 칠판을 덮어 분필 글씨가 안 보인다.
- 글자·선은 흰 분필색, 문항 번호만 분필 노랑. 글꼴은 맑은 고딕(학원 PC에 기본으로 있음).
- 글은 PPT 글자로 다시 입력(영상에서도 읽히는 크기, 강사가 고칠 수 있음). 5번 그래프는 원본에서 잰 값으로 다시 그림, 지도는 원본 그림을 흰 선(투명 바탕)으로 바꿈. 15번 벤 다이어그램·21번 표·말풍선은 PPT 도형.
- 정답·단서·선지별 판단은 **발표자 노트**에만(`../content/analysis.js`에서 가져옴). 화면에는 안 나온다.

## 만들기
원문(평가원 문장·그래프 값·지도 그림)은 저작권 때문에 저장소에 올리지 않는다. `기출변형/out/시범강의/src/`(커밋 안 됨)에 둔다.
- `content.cjs`: 문항 글자·그래프 값(평가원 PDF 글자층과 300dpi 그림을 보고 옮김)
- `q5-map.png`: 문제지 2쪽을 600dpi로 그려 5번 지도 칸만 잘라, 어두운 정도를 흰색 투명도로 바꾼 그림

```bash
cd <작업 폴더> && npm install pptxgenjs jszip react react-dom react-icons sharp
NODE_PATH=<작업 폴더>/node_modules node 기출변형/특강/칠판/build-deck.cjs 기출변형/out/시범강의/src 기출변형/out/시범강의/시범강의-5-15-21.pptx
```
- 미리보기: LibreOffice로 PDF → 그림. 미리보기에서는 한글과 괄호·숫자 사이가 조금 벌어져 보이지만(LibreOffice 동작) 파워포인트에서는 붙어 나온다. 그래서 줄 수는 넉넉하게 어림하고, 글 상자는 가운데 맞춤으로 여백을 고르게 한다.
- 걸린 들여쓰기(선지 ①~⑤, 〈보기〉, 갑·을 제시문)는 탭 하나 + 문단 들여쓰기로 만든다(`hang()`).
