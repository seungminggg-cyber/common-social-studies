# 서운고 주간지(MINT) 3주 계획 (초안, 2026-11-08)

- 시험 범위(통합사회2): Ⅲ-3·4, Ⅳ-2·3, Ⅴ 전체 · 학생 1명 · 학교 키 `seoun`, 문항 id 약자 `sw`
- 주간지는 3번 나간다(강사 결정). **서운고 학습지를 아직 받지 못해** 개념서 중단원으로 나눈 초안이다. 학습지를 받으면 DAY를 학습지 주제 기준으로 다시 나눈다.

|---|---|---|
| 1주 | Ⅲ-3 자산 관리와 금융 생활(09) · Ⅲ-4 국제 무역과 지속가능발전(10) | 1 금융 상품과 자산 관리 원칙 / 2 생애 주기와 금융 생활 설계 / 3 국제 분업·절대 우위와 비교 우위 / 4 비교 우위 계산·교역 조건 / 5 무역 확대의 영향·지속가능발전 |
