# 학교별 내신 주간지 (2026-11-08 시작)

인천 계양 고1(계양고·작전고·인천국제고·서운고·계산여고) 2학기 기말고사 4주 전부터 나눠 주는 **종이 주간지**. 학교 학습지를 반영해 학교마다 따로 만든다.

## 만들기
```bash
cd 기출변형
node 주간지/build.mjs jakjeon 1 [png]   # → 주간지/out/작전고-1주차.pdf (문제 + 뒤쪽 정답과 해설)
```
- 한 주 = 표지(이번 주 계획표·푸는 법) → DAY 1~5 → 오답 기록지 → 정답과 해설.
- DAY = 한 중단원: 개념 정리(개념서 '한 장 정리') + 개념 O/X 6(개념서 '이렇게 나온다') + 백지 테스트 칸 → 객관식 6 + 서답형 1.
  DAY 5 = 종합 점검(MINIMAX 1차 문항 재사용 8개, `reuse`).
- 빌드가 문항 높이를 재서 단을 꽉 채우는 순서로 객관식을 다시 늘어놓는다(서답형은 마지막, 번호는 한 주 안에서 이어짐).

## 파일
- `content/<학교>/w<주>.js` — 한 주 설정(학교·범위·DAY 목록·재사용 문항), `content/<학교>/w<주>-<중단원>.js` — DAY 문항(객관식 6 + 서답형 1).
  학교 키: jakjeon(작전고). 다른 학교는 학교 키를 정해 같은 모양으로.
- `참고/출제지시.md` — 문항 쓰는 규칙(내신형, 난이도 하1·중2·중상2·상1, 서답형 형식).
- `weekly.css` — 주간지 디자인(시안 H + 대단원 색).

## 학교 학습지
- 강사 드라이브 폴더(주소는 저장소에 적지 않음) → `python3 -I scripts/fetch-sources.py <폴더 주소> /home/user/학습지`, HEIC는 pillow-heif로 JPG 변환(`/home/user/학습지/jpg/<학교>/`).
- 사진·원문은 **저장소에 올리지 않는다**(공개 저장소, 학교 선생님 자료). 강조점만 참고해 문항을 새로 쓴다.
