# 학교별 내신 주간지 (2026-11-08 시작)

인천 계양 고1(계양고·작전고·인천국제고·서운고·계산여고) 2학기 기말고사 전 **3주 동안(3번)** 나눠 주는 **종이 주간지**. 학교 학습지를 반영해 학교마다 따로 만든다.

## 만들기
```bash
cd 기출변형
node 주간지/build.mjs jakjeon 1 [png]   # → 주간지/out/작전고-1주차.pdf (문제 + 뒤쪽 정답과 해설)
```
- 한 주 = 표지(이번 주 계획표·푸는 법) → DAY 1~5 → 정답과 해설.
- DAY = **개념서 중단원 하나**(학교 학습지 내용은 그 중단원에 넣음): 개념 정리 + 개념 O/X 6 → (바로 이어서) **객관식 8**, 하루 목표 **30분**. **DAY 5는 대단원 총정리**.
- 빌드가 문항 높이를 재서 단을 꽉 채우는 순서로 객관식을 다시 늘어놓는다(번호는 한 주 안에서 이어짐).

## 강사가 정한 규칙 (2026-11-08, 1주차 견본 검토)
1. **학교 학습지 개념이 최우선.** 개념 정리·O/X·문항은 그 학교 학습지에 있는 개념으로. 학습지에 없는 사상가·개념(예: 마르크스, 베버, 헌법 제119조, 역선택, 지역 경제 협력체, 단리·복리, 효율성·형평성)은 묻지 않는다(선지에도 되도록 쓰지 않음).
2. **서답형 없이 객관식만.**
3. **학습지의 예시·연습 문제는 모두 싣는다.** 빈칸·서술형이던 것은 같은 자료·숫자로 객관식으로 바꾼다. 이 문제들은 `content/<학교>/private/`(.gitignore — 학교 선생님 자료·학평 원문이라 공개 저장소에 올리지 않음)에 둔다.
   새 채팅(새 컨테이너)에서는 private가 없으므로 학습지 사진을 다시 받아 만든다. 빌드는 없는 문항을 빼고 경고한다.
4. 개념 정리·O/X는 학습지 내용을 새 문장으로 정리해 주 설정 파일(`w<주>.js`의 summary·ox)에 적는다. 학습지 '학습 자료'(사례·그래프)와 학습지에 손으로 적힌 강조(필기)도 소재로 쓴다.
5. **백지 테스트 칸과 오답 기록지는 넣지 않는다**(2026-11-08). DAY 첫 쪽은 개념 정리·O/X 바로 아래에서 객관식이 이어진다(빌드가 알아서 함).
6. **디자인은 시안 1(실전 띠형)으로 확정**(2026-11-08): 표지는 대단원 색 전면 + 시리즈 이름 + 큰 WEEK 번호 + 3주 진행 막대 + 큰 대단원 번호, DAY 머리는 대단원 색 띠, 본문은 흰 바탕·검정 괘선, 문제 두 단 사이 세로선, DAY마다 목표 시간. `styles/s1.css`(빌드 기본값). 
7. **시리즈 이름 MINT**(MIN + T = 승민T, 2026-11-08). 표지 이름 아래 '승민T 학교별 내신 주간지'. **주간지는 3번(3주)** 나간다 — 주차 계획은 3주로 짠다.
8. **DAY = 개념서 중단원 하나**(2026-11-09). 학교가 주제를 다르게 나눠도(예: 작전고 Ⅲ = 주제 1~5) 개념서·시중 문제집처럼 중단원으로 묶는다 — Ⅲ = 07 자본주의·경제 체제 / 08 합리적 선택·시장 참여자 / 09 금융 / 10 국제 무역(Ⅳ = 11~13, Ⅴ = 14~16). 학습지 주제·예시 문제는 내용이 맞는 중단원 DAY에 넣는다.
9. **하루 객관식 8문항(빈 칸이 크면 최대 10 — 14번), 목표 30분**(개념 정리·O/X 포함). 난이도 하 1 · 중 3 · 중상 3 · 상 1쯤.
10. **DAY 5는 꼭 대단원 총정리**: 그 주 중단원 전체를 한 장으로 정리 + O/X 6(중단원 섞기) + 객관식 8(중단원 고르게 섞기, 실전처럼). 학원 개념 수업은 Ⅲ~Ⅴ 모두 한 번씩 끝났다(강사).
11. **계산 문제 위주 DAY**(2026-11-09): Ⅲ-2(개념서 08) = 편익·명시적 비용·암묵적 비용·기회비용·순편익(매몰 비용 포함) 계산, Ⅲ-4(개념서 10) = 절대 우위·비교 우위·기회비용·특화·교역 이익 계산. 객관식 8문항 중 **6문항 이상 계산**(학습지 계산 문제 포함), 나머지는 그 중단원 핵심 개념. 공식은 발문에 준다. 숫자·상황은 문항마다 다르게(같은 표 모양 반복 금지), 해설에 계산 과정을 단계별로. Ⅲ 총정리 DAY에도 08·10은 계산 문항을 1개 이상.
12. **내지 보완**(강사 확인 2026-11-09, 빌드가 처리): 문제 머리에 개념서 번호 대신 개념 이름만, 정답과 해설은 검정·회색, 쪽 옆 색인은 DAY 1~5(DAY마다 아래로), O/X 정답은 한 줄 + X만 이유. 글자 크기·DAY 끝 '풀이 메모'는 그대로. 2·3주차 계획은 차차 정한다. 인천국제고 1주차는 Ⅲ-3·4 학습지를 받은 뒤 한 번에 시작.
13. **드라이브에 없는 학습지는 기다린다**(2026-11-09): 학교에서 아직 안 나눠 줬거나 학생이 아직 안 보낸 것이다. 강사가 받는 대로 바로 올린다. 그 범위를 개념서만으로 미리 만들지 않는다. 1주차 마감(11/15)에 걸리는 빈 곳이 있으면 조정 채팅에 바로 알린다.
14. **빈 칸이 크면 문제를 더 넣는다**(강사 2026-11-09): 하루 객관식 8문항이 기본. DAY 끝에 빈 '풀이 메모' 칸이 크게 남으면 그 자리에 문제를 더 넣어 **최대 10문항**(쪽수는 늘리지 않음). 계산 위주 날(08·10)을 먼저 채운다. 작전고·계양고 1주차는 44문항(작전고 DAY 2·4, 계양고 DAY 1·4가 10문항).

## 파일
- `content/<학교>/w<주>.js` — 한 주 설정: 학교·범위, DAY마다 title(중단원 이름, 총정리는 "Ⅲ단원 총정리")·unit(개념서 중단원 키, 총정리는 그 대단원의 아무 중단원)·summary·ox·items(문항 id).
- 문항 파일: `content/<학교>/*.js`(`export default { unit?, questions: [...] }`, 문항마다 unit 또는 파일 unit) — id로 찾는다. `t2-07-1-003`처럼 쓰면 MINIMAX 문항을 가져온다.
  학교 키: jakjeon(작전고). 다른 학교는 학교 키를 정해 같은 모양으로.
- `참고/출제지시.md` — 문항 쓰는 규칙(내신형, 난이도, 형식).
- `weekly.css` — 주간지 디자인(시안 H + 대단원 색).
