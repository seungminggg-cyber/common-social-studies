# 학교별 내신 주간지 — 문항 출제 지시서

강사(승민T)가 인천 계양 지역 고1 학생(계양고·작전고·인천국제고·서운고·계산여고)에게 2학기 기말고사(통합사회2) 전 3주 동안(3번) 나눠 주는 **종이 주간지**의 문항을 쓴다.
같은 저장소의 `기출변형/CLAUDE.md`(문항 형식·저작권·표시 규칙)와 `기출변형/참고/3차지침.md` 6절(강사 검수에서 정한 표시 규칙)을 먼저 읽는다.

## 무엇이 다른가 (수능형 문제집과 비교)
- **학교 내신(정기고사) 대비**다. 교과서 개념을 정확히 아는지, 교과서 자료(표·그래프·지도·사례)를 읽을 수 있는지를 묻는 학교 시험 모양으로 쓴다.
  수능형 킬러(두 사상가 순서도, 3단 계산 등)는 하루 1문항 이하.
- **강사 규칙(2026-11-08): 학교 학습지 개념 최우선, 학습지에 없는 사상가·개념은 묻지 않음, 서답형 없이 객관식만, 학습지 예시 문제는 모두 싣기** — `README.md`의 '강사가 정한 규칙'.
- 하루(DAY) = **개념서 중단원 하나**(학교 학습지 내용·예시 문제는 그 중단원 DAY에). DAY마다 **객관식 8문항**, 하루 목표 30분. **DAY 5 = 대단원 총정리**(중단원을 섞은 객관식 8).
  - 객관식 난이도: 하 1 · 중 3 · 중상 3 · 상 1.
  - 발문을 고르게: '옳은 것은?', '옳지 않은 것은?'(DAY당 1개쯤), '<보기>에서 고른 것은?', 자료(표·그래프·사례·대화) 해석, 개념 짝짓기.
- 학교 학습지의 개념·학습 자료·필기를 먼저 읽고, 그 안에서 묻는다. 개념서는 사실 확인용.

## 근거 자료 (읽을 것)
- 개념서 본문: `textbook/content/_t2-3/u07.js` ~ `u10.js`(통합사회2 Ⅲ단원 07~10 중단원), 개념 번호와 '이렇게 나온다'·한 장 정리: `textbook/content/_cc/t2-3.js`.
  문항의 `concept`는 이 개념 번호(1부터)다. 개념서 범위 안에서 쓴다(범위를 조금 넘으면 `note`에 자세히).
- **겹치면 안 되는 문항**: `기출변형/content/1/t2-07.js`~`t2-10.js`, `기출변형/content/2/t2-07.js`~`t2-10.js`(MINIMAX 문제집). 같은 사례·숫자·자료·선지 문장을 쓰지 않는다(유형은 같아도 됨).

## 형식 (JS 파일, `export default { unit, questions: [...] }`)
```js
export default {
  unit: 't2-07',
  questions: [ // 객관식 6개. 형식은 기출변형/CLAUDE.md '문항 형식'과 같다.
    { id: 'jj-w1-07-01', level: '하', concept: [1], type: '개념 이해', src: '교과 개념(…)',
      stem: '…', data: [], bogi: [...](선택), choices: ['…','…','…','…','…'], answer: 3,
      explain: '정답 근거. ① … ② … (오답 선지마다 틀린 이유)', note: '(선택)' },
  ],
  /* (서답형은 쓰지 않음 — 2026-11-08 강사 결정)
    id: 'jj-w1-07-s1', level: '중', concept: [2], type: '서술형',  // 단답형 | 서술형
    stem: '…', data: [], lines: 3,          // lines: 답 쓰는 줄 수(단답형 1)
    answer: '모범 답안',
    rubric: ['채점 기준 1 (점수)', '…'],     // 서술형만: 부분 점수 기준 2~3줄
    explain: '해설',
  }, */
};
```
- id: `<학교 약자>-w<주>-<중단원 두 자리>-01`~ (예: jj-w1-07-01; jj = 작전고). 학습지 문제는 `<학교 약자>-ws-01`~ (private 폴더).
- 자료 블록은 개념서 render가 아는 것만: `p`, `dialog`, `table`, `chart`(bar·line·pie 등), `map`, `diagram` 등 — 이미 있는 문항(`기출변형/content/1/t2-08.js` 등)의 쓰임을 보고 그대로 따른다. 확실하지 않으면 `table`·`p`·`dialog`(`{ t: 'dialog', rows: [['갑', '…'], …] }`)만 쓴다.
- 정답 번호: 두 중단원(12문항)에서 ①~⑤가 2~3번씩, 같은 번호가 세 번 연속 나오지 않게.
- <보기> ㄱ~ㄹ, 조합 선지는 기출 모양(ㄱ, ㄴ / ㄱ, ㄷ / ㄴ, ㄷ / ㄴ, ㄹ / ㄷ, ㄹ 등). 세 개 조합은 ④·⑤에.
- 계산 문항은 공식을 발문에 준다(기회비용 = 명시적 비용 + 암묵적 비용 …).
- 해설: 정답 근거 + **오답 선지(①~⑤) 또는 <보기>(ㄱ~ㄹ)마다 틀린 이유**. 학생이 해설만 보고 혼자 이해할 수 있게.
- 문장은 '-다'체. 실제 통계는 출처를 확인한 것만, 아니면 가상 수치(표시는 하지 않아도 빌드가 정리함).

## 저작권
- 교과서·문제집·시험 문장을 옮기지 않는다. 사례·숫자·자료는 새로 만든다.

## 끝나면
- `node -e "import('<파일 경로>').then(m=>console.log(m.default.questions.length, m.default.short.id))"`로 문법 확인.
- 스스로 각 문항을 정답을 가리고 다시 풀어 정답이 하나뿐인지 확인한다.
- 보고: 파일 경로, 문항별 (id, 난이도, 유형, 정답), 확신이 없는 사실이 있으면 목록.
