# 학교별 주간지 채팅 안내 (2026-11-08)

학교마다 채팅 하나가 이 안내를 따른다. 채팅 첫 메시지에 학교 이름·키·약자·범위·학생 수·드라이브 폴더 주소·작업 브랜치가 적혀 있다(아래 {…} 자리).

강사(승민T)의 고1 통합사회2 2학기 기말고사 대비 종이 주간지를 {SCHOOL}용으로 만든다. 이 채팅은 {SCHOOL}만 맡는다(다른 4개 학교는 각각 다른 채팅이 맡음). 강사는 비개발자다. 한국어로, 쉬운 말로, 결과부터 짧게 답한다.

## 먼저 할 일
1. 작업 환경 준비: `bash scripts/setup-env.sh` (npm 부품·글꼴), `pip install -q pillow-heif` (HEIC 사진 변환).
2. 읽기 순서: `기출변형/주간지/README.md`(강사가 정한 규칙 — 반드시 지킴) → `기출변형/주간지/참고/출제지시.md` → 견본 `기출변형/주간지/content/jakjeon/w1.js`, `w1-extra.js`, `w1-07.js`~`w1-10.js`, `기출변형/주간지/build.mjs`.
3. 학교 학습지 받기(드라이브 폴더 주소는 저장소·커밋에 절대 적지 않는다):
   `python3 -I scripts/fetch-sources.py "<첫 메시지의 드라이브 폴더 주소>" /home/user/학습지` → `/home/user/학습지/pdf/{FOLDER}/`. HEIC는 pillow-heif로 JPG로 바꿔 본다.
4. 학습지를 **한 장씩 전부** 읽고(개념 학습지 + 예시·연습 문제 학습지 + 학생 필기), 학습지 주제 목록과 예시 문제 목록을 정리한다.

## 이 학교 정보
- 학교 키: `{KEY}`, 문항 id 약자: `{ABBR}` (예: {ABBR}-w1-x-01, 학습지 문제 {ABBR}-ws-01).
- 시험 범위(통합사회2): {RANGE}. 맡은 학생 {N}명. 시험까지 약 4주(정확한 날짜 미정).
- 학교 교과서는 중단원을 개념서와 다르게 나눌 수 있다(예: 작전고 Ⅲ = 주제 1~5). DAY는 **학교 학습지의 주제** 기준으로 나눈다.

## 견본 규칙 (작전고 1주차, 강사 확정 2026-11-08 — README '강사가 정한 규칙')
- 학교 학습지 개념 최우선. 학습지에 없는 사상가·개념은 묻지 않는다(선지에도 되도록 안 씀).
- 서답형 없이 객관식만. 하루 5~6문항(예시 문제가 많은 날은 더).
- 학습지의 예시·연습 문제는 **모두** 싣는다. 빈칸·서술형은 같은 자료·숫자로 객관식으로 바꾼다. 이 문제들은 `기출변형/주간지/content/{KEY}/private/`(.gitignore, 공개 저장소에 올리지 않음).
- 개념 정리·O/X 6개는 학습지 내용을 새 문장으로(학습 자료·필기도 소재로). 교과서·학습지 문장을 그대로 옮기지 않는다(private 폴더의 학습지 문제만 예외).
- 새로 쓴 문항은 다른 검토자(에이전트 1개)가 정답 가리고 다시 풀어 확인한다.

## 진행 방식
1. 학습지를 다 읽은 뒤, 강사에게 **4주 계획**(주차별 범위·DAY 구성)을 짧게 제안하고 확인받는다. 학습지가 아직 없는 범위는 받은 학습지 범위부터.
2. 1주차부터 `기출변형/주간지/content/{KEY}/w1.js` 등을 만들고 `cd 기출변형 && node 주간지/build.mjs {KEY} 1` → PDF를 강사에게 보낸다(SendUserFile).
3. 공통 파일(`build.mjs`, `weekly.css`, README의 규칙 부분)은 되도록 고치지 않는다. 꼭 필요하면 강사에게 먼저 말한다(다른 학교 채팅과 겹침 방지).
4. 커밋·push는 이 채팅의 브랜치 `{BRANCH}`에만. `기출변형/주간지/README.md`의 '진행'에 {SCHOOL} 한 줄만 추가한다.
5. 한도 아끼기(강사 요청): 에이전트는 동시에 1~2개까지. 5개 학교 채팅이 함께 돌고 있다. 한도에 걸리면 풀리는 시각에 send_later로 다시 깨우기를 예약한다.

## 강사 수정 사항 받기
강사는 작전고 견본을 따로 보고 수정 사항을 '조정 채팅'에 준다. 조정 채팅이 이 채팅으로 메시지를 보내고, 공통 규칙은 브랜치 `claude/practical-lamport-a7zkp4`의 README에 적는다.
메시지를 받으면: `git fetch origin claude/practical-lamport-a7zkp4 && git merge origin/claude/practical-lamport-a7zkp4`로 공통 파일을 받고, 이미 만든 주간지에도 그 수정 사항을 적용한다.
