# MINT 총정리 — 학교 학습지 총정리 (2026-11-27 시작)

학교마다 그 학교 학습지를 **최대한 자세하게** 정리한 기말 대비 책. 학생이 혼자 풀어 가고, 수업 때 강사가 돌면서 봐 준다.
인천국제고가 첫 견본이고, 다른 네 학교도 같은 틀(`content/<학교키>/`)로 이어 만든다. 학교키는 `../상중하/build.mjs`의 SCHOOLS와 같다(jakjeon, gyeyang, gyesan, seoun, inguk).

## 만들기
```bash
node 기출변형/총정리/build.mjs inguk            # → 총정리/out/인천국제고-총정리.pdf(학생용) + 인천국제고-총정리-정답.pdf(별책)
node 기출변형/총정리/build.mjs inguk png        # 쪽 그림(PNG)까지 → out/png/
node 기출변형/총정리/build.mjs inguk only=10    # 중단원 하나만(견본) → 인천국제고-총정리-10.pdf
```
- 맨 뒤 붙이기: `book.js`의 `append`에 적은 PDF(예: `out/append/인천국제고-모의고사.pdf`)가 있으면 학생용 맨 뒤에 붙인다(pdfunite). 없으면 그냥 넘어간다.

## 책 구성 (강사 결정 2026-11-28: 두 파트로 나누고 빈칸판은 뺌)
- 표지 → 차례(PART 1·2) · 이 책 쓰는 법
- **PART 1 학습지 개념 총정리**: 중단원마다 학습지 순서대로 자세한 정리(빈칸 없음, 항목마다 '학습지 N쪽', ★ = 학교 선생님 필기·강조, 학습지 없는 시험 범위는 개념서로 채우고 **'필수 개념 참고'** 표시 — '개념서', '개념서로 보충' 같은 말은 책에 쓰지 않는다)
- **PART 2 연습문제 총정리**: 중단원마다 **학습지 문제**(학습지에 실린 문제 그대로, `private/<중단원>.js`의 `problems`) → **O/X**(X는 고쳐 쓰기) → **계산 풀이**(08·10: 공식 모음 → 학습지 예시와 단계별 풀이 → 숫자를 바꾼 연습) → 대단원 끝 **백지테스트** → 맨 끝 **Ⅳ·Ⅴ 백지도**(book.blankMap) → (붙일 PDF: 모의고사)
- 쪽마다 아래에 **목표 시간 · 걸린 시간 · 채점(맞은 개수/문항 수)**. 정리 쪽은 읽기 1·2·3회 칸. 목표 시간은 빌드가 계산(정리 1분에 약 250자, 학습지 문제 2.5분, 빈칸 채우기 0.5분, O/X 0.7분, 학습지 예시 3분, 연습 6분).
- 옆 색인 = 중단원 번호, 대단원 색(Ⅲ 초록 · Ⅳ 주황 · Ⅴ 파랑).
- **정답 별책**: 학습지 문제 정답과 풀이, O/X 정답과 고친 문장, 계산 연습 풀이, 백지테스트 모범 답안, 백지도 정답.

## 강사가 정한 것 (2026-11-28, 인천국제고 검토)
- 두 파트: PART 1 학습지 개념 총정리(빈칸 없음) / PART 2 연습문제 총정리(학습지 문제 그대로 → O/X → 계산 → 대단원 백지테스트 → 백지도). 빈칸판 없음.
- '이 책 쓰는 법' 쪽 없음(차례만). 중단원 첫머리에 '01 학습지 개념 총정리 N항목'·'01 학습지 문제 02 O/X' 같은 목록 멘트 없음.
- 학습지 밖 시험 범위는 '필수 개념 참고'로 표시(‘개념서’, ‘개념서로 보충’, ‘학습지 없음’ 같은 말 금지). 원고 source에도 쓰지 않는다.
- 정리 노트 줄은 회색(분홍빛으로 보인다는 의견).
- 학생 이해에 지도가 필요한 곳에 지도: 공통 지도 `lib/maps-t2.js`(CONFLICT_MAP 세계 분쟁, EAST_ASIA_MAP 동아시아 영토, FOSSIL_MAP 화석 에너지, RESOURCE_CONFLICT_MAP 자원 분쟁, RENEWABLE_MAP 신·재생) — 원고에서 import해 블록으로 넣는다. 필요하면 지도를 더 만든다(개념서 `textbook/lib/maps.js` 형식).
- 시리즈 이름 MINT 총정리. 백지도는 학교판(인천국제고 62 · 서운고 58 · 나머지 공통 55개국).
- 학교마다 채팅을 따로 만들어 만든다(강사 2026-11-28).

## 원고 쓰는 법 (`content/<학교>/<중단원>.js`)
```js
export default {
  unit: 't2-10', no: '10', big: 'Ⅲ', title: '국제 무역과 분업', source: '학습지 「…」 1~22쪽',
  sum: [ { h: '항목 제목', pg: '2'(학습지 쪽, 없으면 '' → '필수 개념 참고'), blocks: [개념서 render 블록…] } ],
  ox: [ ['문장', 'O'], ['문장', 'X', '바르게 고친 문장'] ],
  calc: { formulas: [...], practice: [ { title, stem, data, formula, asks: [...], steps: [...], answer } ] },  // 계산 있는 중단원만
}
```
- `{{핵심어}}` = 굵게(예전 빈칸판의 핵심어 표시, 빈칸판은 2026-11-28에 뺐지만 `blankVersion` 함수는 남겨 둠). `★` = 학교 선생님 필기·형광펜·강조(슬라이드 학습지는 굵게·색·검은 상자로 강조한 곳). `**굵게**`도 쓸 수 있다(`{{ }}`를 `** **` 안에 넣지 않는다).
- 블록: 개념서 `textbook/lib/render.js`의 블록(table, kv, ul, p, chain, flow, compare 등) + 총정리 전용 그림 `{ t: 'svg', kind: 'tradeSurplus' }`(`lib/svg.js`).
- `private/<중단원>.js`(**저장소에 올리지 않음**, .gitignore): 학습지에 실린 문제 `problems: [{ from, stem, data, bogi, choices, answer, steps }]`(빈칸 채우기는 `fill: ['…___…'], answer: ['답'…]`), 계산 예시 `examples: [{ title, from, stem, data, steps, answer }]`. 인천국제고: 08(문제 05), 09(학평 18·22번, 확인 문제 07·08), 10(19쪽 개념 점검, 확인 문제 01·02·05 + 예시 6쪽·8~9쪽), 12(십자말풀이 20번, 갈퉁 문제). 새 컨테이너에는 없으므로 학습지를 보고 다시 만든다(없으면 빌드가 빼고 알려 줌).
- 대단원 끝 백지테스트: `content/<학교>/blank/*.js` = 백지테스트 채팅(브랜치 `claude/blank-test`, `기출변형/백지테스트/content/`)의 파일을 그대로 복사(`lib/blank.js`가 그 형식을 읽음). 어느 파일을 쓸지는 `book.js`의 `blank`.

## 꼭 지킬 것
- 저장소는 공개다. 정리·O/X·빈칸 문장은 **새로 쓴 문장**. 학습지 표·문제를 그대로 옮긴 것은 `private/`. 학습지 사진·PDF·추출 글·결과 PDF(`out/`)는 커밋하지 않는다. 드라이브 주소를 적지 않는다.
- 주간지·개념서·문제집의 공통 파일은 고치지 않는다(필요하면 이 폴더로 복사). 디자인은 주간지 MINT 시안 1 계열(`styles/mint.css` 앞부분은 `../주간지/styles/s1.css`에서 복사).
- 사실은 개념서로 확인한다(예금자 보호 한도는 2025-09-01부터 1억 원).
