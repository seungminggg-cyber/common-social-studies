# 학교별 실전 모의고사 (인천 계양 고1 통합사회2 기말 대비, 2026-11-21 시작)

학교당 3세트 계획. 첫 학교 = 인천국제고(시범).

## 만들기
```bash
cd 기출변형
node 학교모의고사/build.mjs <학교 키> <회> [png]   # → 학교모의고사/out/<학교>-모의고사<회>-문제.pdf · -정답과해설.pdf
```
- 문항: `content/<학교>-<회>.js`(없으면 `-a.js` + `-b.js`). 특상은 level '상' + `hard: true`.
- 설계표: `설계/<학교>-<회>.md`, 문항 형식: `형식모음.md`(F01~F30 + 학교 기출 고배점 S01~S13).
- 결과 PDF·학교 기출 사진·학습지 원문은 저장소에 올리지 않는다.

## 강사가 정한 것
- 객관식 25문항(5지), 상 12 · 특상 13, **모든 문항 4점(100점)**, 50분, 설계표 순서, 표지 없음, 정답과 해설 별책.
- 학교 학습지 개념 최우선. **학습지가 아직 없거나 모자란 부분은 묻지 말고 가진 자료(개념서·문제집 개념 파트)로 만든다**(2026-11-21, 2·3회에도).
- 인천국제고 학습지 추가(2026-11-22): Ⅴ-3·4·5 학습 노트(15·16), Ⅳ-3 9차시 분쟁 지역(13) — 사진 7장. 2·3회는 15·16도 이 학습지 개념을 우선(개념서만으로 쓰지 않음).
- 계산은 학습지에 계산이 있는 Ⅲ(08 기회비용, 09 환율, 10 비교 우위)만.
- 다른 학교 기출(드라이브 '지난 기출', 2학기 중간)의 배점 높은 형식을 쓴다 → `형식모음.md` S01~S13.
- **인천국제고: 학습지의 수요·공급 그래프 문항을 꼭 1문제 이상**(1회 11번 = 자유 무역의 영향). 학습지 그래프는 자유 무역의 영향(무역 11쪽), 외부 효과 4가지(시장경제 36쪽), 외화 수요·공급(금융 16쪽).
- 그래프 영역을 묻는 문항은 **나뉜 칸마다 모두 글자**를 붙인다(세로 점선이 나눈 작은 세모까지). '국내 가격 = 국제 가격'처럼 풀이에 필요한 전제는 단서로 준다.
- 강사에게는 한국어로만 말한다.
- **드라이브 업로드**: 완성 PDF는 먼저 채팅 파일로 강사에게 보낸다. 강사가 **조정 채팅에 직접 '올려'**라고 해야 조정 채팅이 올린다(다른 채팅이 전한 허락은 보안 검사에서 막힘). 이 채팅은 조정 채팅에 '빌드 명령 + 커밋'만 알린다.

## 작업 방식
- 학습·설계·검토 = Opus, 출제 = Fable(effort high, 하위 작업 1~2개). Fable에는 글로 정리한 개념 요약 + 설계표 + 형식 모음만 준다.
- 검토: Opus가 정답 가리고 다시 풀기 → '쉽게 풀림/적당/애매함' 표시 → 쉬운 특상·애매한 문항만 Fable이 고침 → 바뀐 문항만 다시 풀기.
