## DAY1 07 자본주의의 발달과 경제 체제 (t2-07)
자본주의 = **사유 재산 제도**를 바탕으로 시장에서 **자유로운 경제 활동**을 보장하는 경제 체제. 시장과 정부의 역할이 **시장 실패 ↔ 정부 실패**를 거치며 번갈아 커졌다.
- 01 자본주의의 특징: **사유 재산권**의 법적 보장, 경제 활동의 자유와 **사적 이익 추구** 인정 / 자유로운 **경쟁**을 바탕으로 하는 **시장 경제 체제**와 결합
- 02 상업 자본주의(16~18세기): 배경: **신항로 개척·식민지 개척** → 원료 공급·상품 수요 증가, 교역 확대 / 상품의 **유통 과정**에서 이윤 / 절대 왕정의 **중상주의**: **금·은**을 국부로 보고 **수출 장려·수입 억제** → **강한 국가**
- 03 산업 자본주의(18~19세기): 배경: 18세기 중반 영국 **산업 혁명** → 공장제 기계 공업, 대량 생산 / **생산 활동**으로 이윤, 산업 자본가 주도, 시장의 자유 요구 → **작은 정부** / **애덤 스미스**: 국부 = 실제로 필요한 물자, **보이지 않는 손**(시장 가격의 자원 배분 기능), 정부 개입 반대(**자유방임주의**)
- 04 대공황과 수정 자본주의(20세기 중반): 대공황 원인: 자유방임 → 소수 대자본의 **독과점**·부의 편중 → **과잉 생산**과 **유효 수요(구매력) 부족** / 1929년 미국 주가 대폭락 → 연쇄 도산·대량 실업(**시장 실패**) / **케인스**: 정부가 적극 개입해 **유효 수요** 창출 → **큰 정부**, 공공사업(후버 댐)·복지 확충 / **뉴딜 정책**(루스벨트): 은행에 자금 지원(파산 방지), 농산물 가격 지원, 대규모 공공사업으로 일자리 창출
- 05 인플레이션: 물가가 **지속적으로 상승**하는 현상 → 화폐의 실질 가치(구매력) 하락 / **수요 견인**: 총수요 증가(호황기), 총수요 곡선 **오른쪽** 이동 → 물가 ↑, 실질 GDP ↑ / **비용 인상**: 원자재·원유 가격 상승 → 총공급 곡선 **왼쪽** 이동 → 물가 ↑, 실질 GDP ↓ → **스태그플레이션** 유발
- 06 신자유주의(20세기 후반~): 배경: 1970년대 두 차례 **석유 파동** → **스태그플레이션**(경기 침체 + 물가 상승) → 과도한 개입이 효율성을 떨어뜨린 **정부 실패** / **하이에크·프리드먼**: **작은 정부**, 공기업 **민영화**, 노동 시장 **유연화**, 기업 **규제 완화**, 복지 축소, **세금 감면** / 효율성은 높였으나 **2008년 글로벌 금융 위기**(서브프라임 모기지 → 리먼 브러더스 파산) 이후 **빈부 격차** 심화로 비판
- 07 경제 문제와 경제 체제: 경제 문제의 원인 = **희소성** / 세 가지: **무엇을 얼마나**(생산물) · **어떻게**(생산 방법) · **누구에게**(분배) / 기준: **효율성**(최소 비용 최대 편익)·**형평성**(공정한 분배) / 분류 기준 1 **생산 수단의 소유**: 사적 소유 = **자본주의**, 공적 소유 = **사회주의** / 기준 2 **해결 방식**: 시장 가격 = **시장 경제**, 정부의 계획·명령 = **계획 경제** / **혼합 경제**: 대공황 이후 시장 경제를 바탕으로 정부가 개입 — 오늘날 대부분의 나라
- 08 시장 경제 vs 계획 경제: 시장: 보이지 않는 손 → **효율적 배분**, 강한 경제적 유인(창의·혁신) / 한계: **빈부 격차**, **시장 실패**(독과점·공공재 부족·환경 오염), 급격한 **경기 변동** / 계획: 정책 목표를 **빠르게** 달성, **불평등 완화**(형평성) / 한계: **근로 의욕 저하**, 자유 제한, 정부의 **정보 부족·판단 착오** / **대한민국 헌법**: 재산권 보장(제23조, 공공복리에 적합하게), 최저 임금제(제32조), 경제상의 자유와 창의 존중 + 국가의 규제·조정(제119조) ↔ **북한 헌법**: 생산 수단의 국가·협동 단체 소유, **계획 경제**
- 09 국민 경제의 순환: **가계**: 생산물 시장의 **수요자**, 생산 요소 시장의 **공급자**(노동·토지·자본 → 임금·지대·이자) / **기업**: 생산물 시장의 **공급자**, 생산 요소 시장의 **수요자** / **정부**: 조세를 받아 공공 서비스 제공
  ! 상업 / 산업 자본주의: 이윤의 원천: **유통**(무역) ↔ **생산**(공장). 정부: 강한 국가(중상주의) ↔ 작은 정부(자유방임)
  ! 수정 자본주의 / 신자유주의: 배경: **대공황 = 시장 실패** ↔ **석유 파동·스태그플레이션 = 정부 실패** / 큰 정부 ↔ 작은 정부
  ! 정부 개입 물결: 중상주의(강화) → 자유방임(최소화) → 수정 자본주의(강화) → 신자유주의(축소). 앞에서 시장 실패, 뒤에서 정부 실패
  ! 두 분류 기준: **소유**(자본주의·사회주의)와 **해결 방식**(시장·계획 경제)을 섞어 쓰지 않는다

## DAY2 08 합리적 선택과 시장 실패 (t2-08)
합리적 선택 = **기회비용은 최소화, 편익은 극대화** → **순편익 = 편익 − 기회비용 > 0**. 개인의 합리적 선택이 모여도 사회 전체가 늘 이로운 것은 아니다(**시장 실패**).
- 01 희소성과 선택: **희소성**: 인간의 욕구에 비해 이를 충족할 자원이 **상대적으로** 부족한 상태(절대적인 양이 적은 것이 아님) → **선택**의 발생 / “세상에 공짜 점심은 없다”
- 02 편익과 기회비용: **편익**: 선택으로 얻는 **금전적 이익 + 비금전적 만족**(즐거움, 성취감) / **기회비용** = **명시적 비용**(실제로 지출한 금액) + **암묵적 비용**(포기한 대안의 ‘편익 − 명시적 비용’ 중 가장 큰 것)
- 03 계산 순서: ① 대안마다 **편익 − 명시적 비용** ② 기회비용 = 내 명시적 비용 + 다른 대안의 ① 중 **가장 큰 값** ③ 순편익 = 편익 − 기회비용 / 순편익이 **양(+)인 대안**이 합리적(최대 하나). 대안이 둘뿐이면 두 순편익의 합 = 0
- 04 매몰 비용: 이미 지출되어 **회수할 수 없는** 비용 → 합리적 선택 시 **고려하지 않는다** / **콩코드 오류**: 막대한 개발비가 아까워 실패가 예상되는 사업을 멈추지 못한 비합리적 선택
- 05 시장 실패: 시장이 불완전하거나 재화의 특성 때문에 **자원이 효율적으로 배분되지 못하는** 상태 / **독과점** · **외부 효과** · **공공재 부족** · **정보의 비대칭성**(거래 당사자 간 정보량 차이, 예: 중고차 시장)
- 06 독과점: 공급자가 하나(**독점**)거나 소수(**과점**) → 가격·생산량을 임의로 조정, 과점은 **담합** / 생산량을 줄여 가격을 올림 → 사회적 최적 수준보다 **적게** 공급
- 07 외부 효과: 다른 경제 주체에게 **의도하지 않은** 이익·손해를 주고도 **대가를 주고받지 않음** / **외부 경제**(양봉, 독감 예방 접종, 교육): 생산 측면 사회적 비용 < 사적 비용, 소비 측면 사회적 편익 > 사적 편익 → **과소** 생산·소비 → **보조금·세금 감면** / **외부 불경제**(공장 폐수, 흡연, 환경 오염): 생산 측면 사회적 비용 > 사적 비용, 소비 측면 사회적 편익 < 사적 편익 → **과다** 생산·소비 → **세금·환경 부담금·과징금**
- 08 재화의 분류: **경합성**: 한 사람의 소비가 다른 사람의 소비 기회를 줄임 / **배제성**: 대가를 내지 않은 사람의 소비를 막을 수 있음 / **사적 재화**(경합·배제: 막히는 유료 도로, 옷, 휴대폰) / **클럽재**(비경합·배제: 막히지 않는 유료 도로, 수도, 전기, 케이블 TV) / **공유 자원**(경합·비배제: 막히는 무료 도로, 바닷속 물고기, 환경 → 남용) / **공공재**(비경합·비배제: 막히지 않는 무료 도로, 국방, 치안 → **무임승차**, 과소 생산)
  ! 암묵적 비용: 포기한 대안들의 값을 **더하지 않는다** — 가장 큰 **하나**만. 명시적 비용이 0이어도 기회비용은 0이 아니다
  ! 외부 효과 그래프: S′(사회적 비용)가 S **위** = 외부 불경제(과다) / D′(사회적 편익)가 D **위** = 외부 경제(과소)
  ! 도로의 변신: 무료 도로가 막히면 **공유 자원**, 한산하면 **공공재** / 유료 도로가 막히면 **사적 재화**, 한산하면 **클럽재**

## DAY3 09 자산 관리와 금융 생활 설계 (t2-09)
성공적인 금융 생활 = 튼튼한 **자재**(금융 자산)를 고르고 **원칙**(안전성·수익성·유동성)을 지키며 **장기 설계도**(생애 주기)를 그리고 **환경 변화**(금리·물가·환율)에 대응하는 과정.
- 01 자산: 경제적 가치가 있는 유·무형의 재산 / **실물 자산**(토지·건물·금·예술품: 인플레이션 방어에 유리) / **금융 자산**(현금·예금·주식·채권)
- 02 예금 · 채권 · 주식: **예금**: 금융 기관, **예금주**, **이자**, 위험 낮음(안전성 최고) / **채권**: 정부·공공 기관·주식회사가 자금 조달용 발행, **채권자**(돈을 빌려준 사람), **이자 + 시세 차익**, 만기 있음, 위험 중간 / **주식**: 주식회사가 자본금 마련용 발행, **주주**(지분 소유, **의결권**), **배당금 + 시세 차익**, 만기 없음, 원금 손실 위험 높음
- 03 예금의 종류와 예금자 보호: **요구불 예금**: 입출금 자유, 이자율 낮음(결제·보관) / **저축성 예금**: **정기 예금**(목돈 한 번에), **정기 적금**(매달 일정 금액) / **예금자 보호 제도**: 금융 기관이 파산해도 **예금 보험 공사**가 보호, **1인당 최고 1억 원**(원금 + 소정의 이자, 2025.9.1.부터 5천만 원 → 1억 원), **금융 회사별**로 각각 적용
- 04 펀드 · 보험 · 연금: **펀드**: 모은 돈을 **전문가(자산 운용사)**가 대신 투자 → **간접 투자** / **보험**: 미래의 예상치 못한 위험(사고·질병)에 대비해 보험료 납부 / **연금**: 젊을 때 적립, 노령·퇴직 시 나누어 받음
- 05 자산 관리의 3원칙: **안전성**: 원금이 손실되지 않고 가치가 보호되는 정도 / **수익성**: 가격 상승·이자 수익을 기대할 수 있는 정도 / **유동성(환금성)**: 필요할 때 쉽게 현금으로 바꿀 수 있는 정도(예금 높음, 부동산 낮음) / **상충 관계**: 수익성이 높으면 위험이 커 안전성이 낮다 → **포트폴리오**(분산 투자, 토빈 “달걀을 한 바구니에 담지 마라”)
- 06 생애 주기와 재무 설계: **흑자 시기**(청년기~중장년기: 수입 > 지출, 자산 형성) / **적자 시기**(노년기: 모아 둔 자산으로 생활) → 소득 기간이 한정되므로 **장기적 재무 설계** 필수 / **100 − 나이** 원칙: 그 비율(%)만큼 **위험 자산**, 나머지는 **안전 자산** (30세 위험 70%, 60세 위험 40%) / 재무 설계 5단계: **목표 설정** → **상태 분석** → 계획 수립 → 실행 → **평가·수정**
- 07 경제적·사회적 환경 변화: **기준 금리 인상** → 예금 선호 ↑, 대출 축소, 주식 매력 ↓ / **물가 상승** → 화폐 구매력 ↓, 실물 자산(부동산·금) 선호 ↑ / **세율 인상** → 가처분 소득 ↓, 소비·투자 축소 / 정치 불안정(전쟁·테러) → **안전 자산**(금·달러·국채) 수요 급증 / 저출생·고령화 → 연금 준비 중요 / ESG·친환경 소비 → 관련 주식·펀드 투자 증가
- 08 환율의 결정과 변동: **외화 수요**(외화가 나감): 수입 대금 지급, 해외 투자, 해외여행 / **외화 공급**(외화가 들어옴): 수출 대금 수취, 외국인의 국내 투자·여행 / 공급 > 수요(초과 공급) → 환율 **하락** / 수요 > 공급(초과 수요) → 환율 **상승** / 같을 때 **균형 환율** / **환율 상승 = 원화 가치 하락**(1달러 1,200원 → 1,300원)
- 09 환율 변동의 효과: **환율 상승**: 수출 증가·수입 감소 → **상품 수지 개선**, 해외여행 감소·외국인 국내 여행 증가 → **서비스 수지 개선**, 수입 원자재 가격 상승 → **물가 상승**, **외채 상환 부담 증가**, 통화량 증가 요인 / **환율 하락**: 반대 — 수출 감소·수입 증가, 수지 악화, 물가 하락, 외채 상환 부담 감소
  ! 예금자 보호: **원금 + 이자** 합산, **금융 회사별** 1억 원씩. 주식·채권·펀드는 보호 대상 아님
  ! 수익의 종류: 이자: 예금·채권 / 배당: **주식만** / 시세 차익: 채권·주식. 만기: 정기 예금·채권 있음, 주식 없음
  ! 두 요인이 동시에: 외화 수요와 공급이 **함께 늘면** 거래량은 반드시 늘지만 환율 방향은 **알 수 없다**

## DAY4 10 국제 무역과 분업 (t2-10)
**생산 요소(자원·노동·자본)의 분포 차이** → **생산비 차이** → 유리한 것에 **특화**하여 교환(**국제 분업**)하면 양국 모두 이익.
- 01 무역의 발생과 국제 분업: **자원**(기후·지형·천연자원의 편중, 예: 중동의 석유) · **노동**(인구 규모·임금·기술 수준) · **자본**(기술력·기계 설비·금융)의 차이 / **특화**: 각 국가가 다른 나라보다 유리한(생산비가 적게 드는) 상품 생산에 집중 / **국제 분업**: 특화한 상품을 교환하며 생산을 나누어 맡는 체제(예: 스마트폰 부품)
- 02 절대 우위론(애덤 스미스): 다른 나라보다 **절대적으로 적은 생산비**(또는 많은 생산량)로 생산할 수 있는 능력 → 절대 우위 상품에 특화 / 한계: 한 나라가 **모든 상품에 절대 우위**를 가지면 무역 발생을 설명하지 못함
- 03 비교 우위론(리카도): 모든 상품에 절대 우위가 있어도 **기회비용이 상대적으로 더 적은** 상품에 특화하여 교역하면 양국 모두 이익 / **기회비용이 작을수록 비교 우위**. 두 나라가 같은 재화에 비교 우위를 함께 가질 수는 없다
- 04 계산 공식: **생산비 표**(1단위에 필요한 노동자 수): X재 1단위의 기회비용 = **X재 생산비 ÷ Y재 생산비**(Y재 단위) / **생산량 표·생산 가능 곡선**(최대 생산량): X재 1개의 기회비용 = **Y재 최대량 ÷ X재 최대량** / **교역 조건**: X재 1개당 받는 Y재가 **두 나라 기회비용 사이**에 있어야 양국 모두 이익 / 교역 이익 = 교역 후 소비량 − 교역 전 소비량
- 05 무역의 이익: **소비자**: 선택의 폭 확대, 저렴한 가격 → 만족도 증가 / **기업**: 해외 시장 확보, **규모의 경제**(대량 생산 → 평균 생산비 절감), 선진 기술 획득 / **국가**: 효율적 자원 배분, 일자리·국민 소득 증가, 문화·사회 교류 확대
- 06 자유 무역: 국가의 간섭 없이 시장 원리에 따라 무역 → 모두에게 이익(소비 가능 영역 확대, 소비자 후생 증가, 생산성 증가, 규모의 경제, 선진 기술 습득) / 국제 가격이 국내 가격보다 **높으면 수출**(국내 가격 상승, 생산자 잉여 ↑, 소비자 잉여 ↓) / **낮으면 수입**(국내 가격 하락, 소비자 잉여 ↑, 생산자 잉여 ↓), 두 경우 모두 국내 **총잉여 증가** / **WTO**: 다자간·글로벌, 무역 분쟁 조정 / **FTA**: 양자 또는 특정 지역 간 관세·비관세 장벽 철폐 → 상호 의존도 심화
- 07 자유 무역의 이면과 보호 무역: 문제: 선진국·개발 도상국 간 **불평등 심화**, 경쟁력 약한 국내 산업(농업·영세 제조업) **위축·실업**, 장거리 운송의 **탄소 배출**, 개발 도상국 노동자 착취(아동 노동) / **보호 무역**: 국내 산업 보호·육성을 위해 무역 규제 / 수단: **관세**, **비관세 장벽**(수입 할당제, **수출 보조금**) / 근거: 실업 방지, **유치산업** 보호, 불공정 거래 대응(**반덤핑 관세**), **국가 안보**(농업 등)
- 08 지속가능한 국제 무역: 전통적 무역: 효율성·이윤 극대화 ↔ 지속가능한 무역: **경제적 이익 + 공정성(사회) + 환경 보호** / 새로운 무역 장벽: **ESG 경영**, **RE100**(사용 전력 100% 재생 에너지), **탄소 중립** → 실천하지 않는 기업은 배제되는 추세 / **공정 무역**: 소외된 생산자·노동자에게 **공정한 가격**(최저 생계비 이상), 노동권 보장(아동·강제 노동 금지), 안전한 작업장, 환경 보호 / 정부(규제 강화·친환경 R&D·지속가능 FTA) · 기업(ESG·RE100·투명한 공급망) · 소비자(윤리적 소비·공정 무역 제품 구매·불매)
  ! 절대 우위 / 비교 우위: **생산비(생산량) 자체** 비교 ↔ **기회비용** 비교. 노동자 수 표는 **적은 쪽**, 생산량 표는 **많은 쪽**이 절대 우위
  ! 생산 가능 곡선: 노동량이 같을 때 축의 끝값이 큰 나라가 그 재화의 절대 우위. 기울기(Y/X)가 **완만**할수록 X재 기회비용이 작다
  ! 수출 보조금: **관세가 아니라 비관세 장벽**이다

## DAY5 12 국제 관계와 평화를 위한 노력 (t2-12)
국제 관계를 보는 눈(**현실주의 ↔ 이상주의**), 평화를 이루는 길(**칸트·갈퉁**), 평화를 만드는 **행위 주체**, 국제적 분배 정의(**해외 원조**)를 함께 정리한다.
- 01 현실주의: 인간·국가는 **이기적**(국익·생존 추구), 국제 관계는 세계 정부가 없는 **무정부 상태** / 평화 = 힘에 의한 **세력 균형** / **모겐소**: 정치 = 권력 투쟁, 판단 기준 = **국익**, 약소국은 **동맹** / 한계: **군비 경쟁**, 전쟁 정당화, 세력 균형의 **불안정성**, **다양한 행위 주체 간과**
- 02 이상주의: 인간·국가는 **이성적**, 분쟁은 **무지·오해, 잘못된 제도**에서 유래 / 평화 = 국제기구·국제법 등 **제도의 개선**, **다양한 주체의 노력** / 한계: 현실의 **경쟁·갈등 설명 어려움**, 실효성 있는 **제재 어려움**
- 03 국제 분쟁: 형태: **영토·인종·민족·자원** 분쟁(여러 형태에 함께 속할 수 있음) / 문제: 핵·생화학 무기의 **평화 위협**, 존엄성·인권 등 **보편적 가치 훼손** / 해결: **문명의 다양성 존중**, **약소국 배려** 제도, **국제적 분배 정의**
- 04 칸트의 영구 평화론: 평화는 **이성이 명령하는 의무**로 성취 → 모든 전쟁을 끝내는 **평화 연맹** 필요(**≠ 평화 조약**: 하나의 전쟁 종식) / **예비 조항**: 화근 숨긴 조약 무효, 국가 매매 금지, **상비군 폐지**, 분쟁용 **국채 금지**, **내정 간섭 금지**, 적대 행위 금지 / **확정 조항**: **공화정체**, **자유로운 국가들의 연방**, **보편적 우호(환대)** → **환대권**: 평화적인 이방인을 적대하지 않을 권리
- 05 갈퉁의 평화론: **직접적 폭력**(범죄·테러·전쟁) / 간접적: **구조적**(부정의한 제도, 억압·착취, 비의도적일 수도) + **문화적**(종교·예술·매체 등이 폭력을 **정당화**) / **폭력의 삼각형**: 어느 꼭짓점에서도 시작되어 쉽게 전달 / **소극적 평화**(직접적 폭력 없음) → **적극적 평화**(간접적 폭력까지 제거), 오직 **평화적 수단**으로
- 06 평화를 위한 행위 주체: **국가**: 크기와 관계없이 **독립적 주권**, 자국 이익·국민 보호 외교 / **정부 간 국제기구**: **국가**가 가입(**UN·WHO·OECD**) / **국제 비정부 기구**: **민간단체·개인**이 가입(**국경 없는 의사회·그린피스**) / **개인**(전직 국가 원수·노벨상 수상자) / **다국적 기업**
- 07 해외 원조에 대한 입장: **노직**: 소유물에 대한 절대적 권리 → 원조는 **자선**(강제 불가) / **싱어**: **이익 평등 고려** → 국적·인종 무관, 원조는 **의무** / **롤스**: **고통받는 사회**를 질서 정연하게 돕는 **의무**, **차단점**(질서 정연해지면 빈곤해도 중단), **차등의 원칙 국제 적용 X**, 무법 국가는 필요시 군사 개입 / **싱어의 롤스 비판**: 지금 굶주리고 병드는 **개인을 방치**
  ! 현실주의 / 이상주의: 본성: 이기적 ↔ 이성적 / 평화: **세력 균형** ↔ **제도 개선** / 한계: 다양한 주체 간과 ↔ 현실 갈등 설명 어려움
  ! 칸트: 상비군·국채는 **예비 조항(금지)**, 공화정·연방·환대는 **확정 조항**. 평화 조약은 평화 연맹이 아니다
  ! 갈퉁: 직접적 폭력만 없음 = **소극적** 평화. 구조적·문화적 폭력까지 없음 = **적극적** 평화
  ! 원조: 노직 = 자선(의무 아님), 싱어 = 국적 무관 의무, 롤스 = 고통받는 사회까지, 차단점 있음

## DAY6 13 남북 분단과 동아시아 역사 갈등 (t2-13)
세계 평화 실현을 위한 우리의 노력 = **남북 평화 통일**(분단 비용을 없애고 통일 편익을 얻음) + **동아시아 역사 갈등**의 평화적 해결.
- 01 남북 분단의 배경: **지역적 분단**(1945년 광복 이후 북위 38도선) → **체제상의 분단**(자본주의·사회주의) → **정부상의 분단**(1948년 서로 다른 정부 수립) / **국제적 배경**: 미소 **냉전** 대결 심화, 지정학적 요충지 → 남쪽 미국, 북쪽 소련의 영향 / **국내적 배경**: 민족 내부의 응집력 부족 — **신탁 통치** 찬반 논쟁과 이념 갈등, **6·25 전쟁**으로 분단 **고착화**
- 02 분단 비용: 분단으로 남북한이 부담하는 유·무형의 모든 지출 / 분단이 지속되는 동안 **영구적**, 민족 모두의 손해인 **소모적** 비용, 통일과 동시에 **소멸** / **유형**: 국방비, 외교 경쟁 비용, 국토 불균형 발전 / **무형**: **이산가족의 고통**, 국민들의 불안
- 03 통일 비용: 통일 과정과 이후 남북한 간 **격차 해소**와 이질적 요소 **통합**에 드는 비용 / 통일 이후 일정 기간 **한시적**, 통일 한국의 번영을 위한 **투자적·생산적** 비용 / 예: **화폐 통합**, **공공재 구축**, **초기 사회 문제 처리** 비용
- 04 통일 편익: 통일 이후 **지속적으로** 얻는 경제적·비경제적 보상과 혜택 / **경제적**: 분단 비용 해소(국방비 절감·신용 등급 상승·외국인 투자 유치), **규모의 경제**, 시장 확대, 남한의 기술·자본 + 북한의 자원·노동력 → 시너지 / **경제 외적**: **이산가족** 문제 해결, **국제적 위상** 제고, **전쟁 위험** 해소, 분단에서 비롯된 갈등·적대감 해소, 지역주의 완화
- 05 독일 통일의 교훈: 동서독은 분단 상태에서도 **문화 교류**, 서독의 **동독 지원**, 활발한 **교류·협력**이 통일의 기초 / 서독은 **외교적 노력**으로 미국·소련·영국·프랑스의 동의를 이끌어 냄 / 통일 후 이질적 체제에서 살아온 사람들 간 **정신적 통합의 어려움**
- 06 평화 통일을 위한 노력: **개인**: 북한에 대한 **올바르고 균형 있는 인식**, 통일에 대한 관심 / **사회·문화**: 긴장 완화·교류 확대 등 **점진적 사회 통합**, 사회·문화적 통합까지 이루어야 **진정한 통일** / **국가**: **안보 기반 구축**과 신뢰 형성을 위한 **교류·협력 병행**, 통일에 관한 **국민적 합의** 도출 / **국제**: 통일은 주변국의 이해관계가 얽힌 **국제적 문제** → 국제 사회와 협력 강화 / 흐름: **1972** 7·4 남북 공동 성명(**자주·평화·민족 대단결** 3원칙) → **1985** 이산가족 상봉 → **1991** 남북 **UN 동시 가입** → **2000** 평양 남북 정상 회담, **6·15 공동 선언** → **2007** 제2차 정상 회담
- 07 동아시아의 역사 갈등: **중국**: **동북공정** — 고조선·부여·고구려·발해를 고대 중국의 **지방사**로 왜곡 → 목적: 중국 영토 안 **소수 민족 통합**, 분리 독립 방지, **국경 안정** / 중화 문명 우수성 홍보 과정의 **문화 원조 논란** / **일본**: 교과서의 **식민 지배·침략 전쟁 정당화**, **독도** 영유권 왜곡 주장, **야스쿠니 신사** 참배 → 외교 분쟁으로 이어지기도 함
- 08 역사 갈등의 해결 노력: **공동 역사 연구**: 역사 인식 차이 극복(2005·2012년 동아시아 공동 역사 교재 — 침략·전쟁 반성, 평화로운 미래 지향) / **인적 교류 확대**: 한·중·일 학계 협력, 유학생·청소년 교류 프로그램 / **우리 역사 연구 성과 알리기**: 패권적·배타적 자국 중심주의 역사관 경계, 국제 사회 공감대 형성
  ! 세 가지 비용·편익: 분단 비용 = **영구·소모**(통일 시 소멸) / 통일 비용 = **한시·투자** / 통일 편익 = **지속적** 혜택
  ! 유형 / 무형: 국방비·외교 경쟁비 = **유형** 분단 비용 / 이산가족의 고통·국민 불안 = **무형** 분단 비용
  ! 배경 구분: 냉전 = **국제적** 배경 / 신탁 통치 논쟁·6·25 전쟁 = **국내적** 배경

## DAY1 15 자원 소비와 지속가능한 발전 (t2-15)
자원은 **유한성·편재성·가변성**을 지닌다. 화석 에너지 중심의 소비가 **자원 갈등**과 **기후 변화**를 낳았으므로, 경제·사회·환경의 균형을 이루는 **지속가능한 발전**을 국가·기업·개인이 함께 추구한다.
- 01 자원의 의미와 특성: 자원 = 자연에서 얻는 것 가운데 **기술적·경제적으로 이용할 수 있는** 것 / **비재생**(화석 에너지·광물) ↔ **재생**(태양광·풍력·수력·지열) / **유한성**(매장량 한정 → 고갈, 가채 연수) · **편재성**(특정 지역에 치우침 → 국제 이동·갈등의 원인) · **가변성**(기술·경제·문화에 따라 가치 변화: 셰일가스, 종교와 식량)
- 02 세 가지 화석 에너지: **석탄**: 18세기 **산업 혁명**의 증기 기관 연료, **제철**·화력 발전 / 주로 **고생대 지층**, 비교적 **고르게** 매장 → 국제 이동 적은 편, 오염 물질 **가장 많음**, 생산·소비 1위 중국 / **석유**: 1차 에너지 소비 비중 **1위**(세계 약 32%), **수송용 연료**·석유 화학 원료 / 페르시아만 연안에 편재 → 국제 이동량 **최대** / **천연가스**: **냉동 액화(LNG)**·파이프라인으로 소비 증가, 난방·발전, 오염 **가장 적음** / 석유·천연가스는 신생대 제3기층 **배사 구조**
- 03 원자력·신재생 에너지가 유리한 곳: **원자력**: **지반이 안정**되고 냉각수를 얻기 쉬운 해안 / 온실가스 거의 없음 ↔ 방사성 폐기물·사고 위험 / **수력** 유량·낙차 큰 하천 / **풍력** 강하고 꾸준한 바람(편서풍 해안·바다) / **태양광** 일사량(건조 기후) / **지열** 판의 경계(화산 지대) / **조력** 조차 큰 해안(시화호)
- 04 나라별 1차 에너지 소비 구성: 중국·인도 **석탄**, 러시아 **천연가스**, 사우디아라비아 **석유·천연가스**, 프랑스 **원자력**, 브라질·노르웨이 **수력** 등 재생 에너지 / 세계는 화석 에너지가 약 **81%**(2024년) / 대한민국은 화석 약 83%, 원자력 비율이 높은 편, 에너지의 90% 이상 **수입**
- 05 자원을 둘러싼 갈등: **영유권 분쟁**: 북극해(빙하 감소 → 자원·항로 경쟁), 카스피해(바다냐 호수냐에 따라 자원 배분이 달라짐), 남중국해 / **자원 민족주의**: 자원을 정치·경제적 **무기**로 — **OPEC**(1960, 석유 파동), 러시아의 유럽 가스 공급 축소(2022), 희토류 수출 통제 → **수입처 다변화**
- 06 자원 소비와 기후 변화: 채굴 과정의 환경 파괴, 화석 에너지 연소 → **온실가스** → 기후 변화(오늘날은 **인위적 원인**의 영향이 큼, 산업화 이전보다 약 1.1℃ 상승) / **1인당** 배출: 산유국·선진국 많음, 저개발국 적음 / **누적**: 미국 최대(**역사적 책임**) / 한 해 배출: 중국 최대(**현재의 책임**) / 피해는 저개발국·취약 계층에 큼(**기후 불평등**)
- 07 지속가능한 발전과 국제 사회의 노력: 지속가능한 발전 = 미래 세대의 필요를 해치지 않으며 현재의 필요를 채움(**경제 성장·사회 통합·환경 보전**의 균형) / **IPCC**(1988) → 기후 변화 협약(1992) → **교토 의정서**(1997, **선진국만** 감축 의무) → **파리 협정**(2015, **모든 당사국**, 목표 5년마다 제출, 2℃보다 훨씬 낮게·1.5℃) / **SDGs** 17개 목표(→ K-SDGs)
- 08 주체별 노력과 신재생 에너지: 국가: **탄소 배출권 거래제**(허용량을 사고팖), 오염 배출 부과금, 신재생 보급, **2050 탄소 중립** / 기업: 친환경 기술, **RE100**(자발적 캠페인), ESG / 개인: 절약, 대중교통, **탄소 중립 포인트**, **로컬 푸드** / 신재생 에너지: 고갈·배출 거의 없음, 수입 의존 ↓ ↔ 날씨에 따라 발전량 들쭉날쭉(**저장 장치**), 넓은 부지·초기 비용, 경관 훼손·주민 갈등
  ! 유한성 / 편재성 / 가변성: 언젠가 **고갈** / 특정 지역에 **치우침**(국제 이동이 많아지는 원인) / 기술·문화에 따라 **가치 변화**
  ! 교토 의정서 / 파리 협정: 1997, **선진국만** 감축 의무 / 2015, **모든 당사국**이 스스로 정한 목표를 5년마다 제출
  ! 비율 / 양: 1인당 ↔ 총량, 비중(%) ↔ 발전량은 다르다 — 양 = 전체 × 비율, 인구 = 총량 ÷ 1인당

## DAY2 16 미래 사회와 세계시민으로서의 삶 (t2-16)
미래는 정해진 하나가 아니라 **우리의 선택**에 따라 달라지는 여러 가능성이다. 과학기술의 **양면성**을 성찰하고(요나스의 **책임 윤리**), 국경을 넘어 연대하는 **세계시민**(누스바움·싱어)으로 살아간다.
- 01 미래를 예측하는 까닭: 인구·자원·기후·과학기술의 변화를 **예측하고 대비** — 개인: 유연한 대응·위험 예방·진로 설계 / 국가: 알맞은 정책, 안정적 발전 / **미래학**: 과거·현재 자료로 미래를 **과학적·체계적**으로 예측, 미래 = **여러 가능성** / 세계 인구: 2024년 약 82억 명 → 2080년대 중반 약 **103억 명 정점** 뒤 조금씩 감소 전망
- 02 분야별 전망 — 정치·경제·생태환경: **정치**: 국제기구 발달·민주주의 확산·공동 대응 ↔ 전쟁·테러, 영토·종교 갈등, 난민, 자국 이익 우선 / **경제**: 세계적 무역·분업으로 번영 ↔ 경기 침체의 빠른 확산, **빈부 격차** 심화 / **생태환경**: 국제 협력·친환경 기술로 기후 위기 대응, 생물 다양성 유지 ↔ 기후 변화·열대림 파괴·사막화로 생태계 붕괴
- 03 분야별 전망 — 과학기술: 긍정: 인공지능·로봇·생명 공학으로 편리한 생활, 수명 연장, 우주·가상 공간으로 활동 확대 / 부정: 인간 정체성 혼란, **정보 격차**(접근·활용 능력 차이), 일자리 감소, **전자 감시**(쌓인 개인 정보로 감시), **데이터 편향성**(학습 자료 속 편견 → 차별적 결과)
- 04 과학기술의 양면성과 인공지능: 과학기술은 혜택과 위험을 함께 지닌 **양면성** → **윤리적 성찰과 사회적 합의** / 커즈와일: 인공지능이 인간 지능을 넘는 **특이점** — 폭발적 발전과 통제 불가능의 위험 / EU 인공지능 법(2024): **위험 정도**에 따라 의무 차등(행동 조종·사회적 점수 금지, 채용·교육·의료는 엄격 관리) / 인공지능을 **시간·공간·사회·윤리** 관점으로(윤리: 존엄성·공정성·책임성, **사람 중심**)
- 05 요나스의 책임 윤리: 현대 기술의 영향은 먼 미래·지구 전체 → **전통 윤리로는 대응 불가**, 책임 대상을 **미래 세대와 자연**까지 확대, 미래 세대는 요구할 수 없으므로 현세대의 **일방적 책임** / "인류가 계속 존재할 수 있도록 행위하라" — 자기 목숨은 걸어도 **인류의 존속**은 걸 수 없다 / **공포의 발견술**: **나쁜 결과의 예측**을 우선 → 기술 포기가 아니라 **신중하고 책임 있는** 행동
- 06 세계시민과 누스바움: **세계시민**: 한 나라 국민을 넘어 **세계적 시각**에서 지구촌 문제를 이해하고 해결에 참여하는 사람 / 나의 작은 선택(소비·에너지·온라인 언행)이 먼 곳 사람과 미래 세대에 영향 / **누스바움**: 나 → 가족 → 이웃·지역 → 국가 → 인류의 **동심원**, 바깥 원 사람들을 안쪽으로 끌어당기기 / **애국심을 버리는 것이 아니라** 인류에 대한 존중과 함께
- 07 싱어의 원조 의무: 연못에 빠진 아이 비유: 큰 희생 없이 고통을 줄일 수 있다면 **거리·국적과 상관없이** 도와야 한다 / 여유 있는 사람이 소득 일부를 기부하는 것은 선택이 아니라 **도덕적 의무** → 지구촌 빈곤, 공적 개발 원조·공정 무역과 연결
- 08 세계시민으로서 미래 삶의 방향: **자아 정체성 확립**(성격·가치관·능력 성찰, 나의 역할 찾기) · **공동의 책임** · **관용과 개방성**(다양성 존중, 대화로 갈등 해결) · **참여와 연대**(캠페인·청원, 기부·국제 자원봉사, 윤리적 소비, NGO 활동, 선거 참여) / 난민 논쟁(2018 제주 예멘 난민, 2021 아프가니스탄 특별 기여자): **인간 존엄성**과 **사회 통합**을 함께, **사실에 근거한** 토론

## 15 (Ⅴ 학습노트 12쪽 — 자원)
- 세계 1차 에너지 소비량 계속 증가(경제 성장·인구 증가). 2022년 석유 > 석탄 > 천연가스 > 신·재생 > 수력 > 원자력. 필기: 수력은 오래전(1800년대)부터 써 통계상 신재생과 따로, 원자력은 폐기물 위험으로 감소 추세.

- 주요 통계(2022): 석탄 생산 중국 약 53%·인도, 소비 중국 약 55%·인도, 수출 인도네시아·오스트레일리아, 수입 중국·인도·일본·한국(동아시아). 석유 생산 미국·사우디·러시아, 수출 사우디 1위, 수입 중국·미국. 천연가스 생산 미국·러시아·이란, 수출 미국·러시아·카타르, 수입 중국·일본(동아시아, 화력 발전용).
- ★ 화석 에너지 지역별 생산·소비(100% 막대): 석탄 생산·소비 모두 아시아(중국·인도), 석유 생산 서남아시아·북미 / 소비 아시아, 천연가스 생산 북미·유럽(러시아). 필기: 서남아시아와 아시아를 따로 분류하는지 주의.

## 15 (Ⅴ-4 학습노트 7차시 13쪽 — 국가별 에너지 소비)
- 탐구: 1인당 에너지 소비량은 선진국·산유국 많고 사하라 이남 아프리카·남부 아시아 적다. 2023 1차 에너지 소비량 중국 > 미국 > 인도(중국 인구 많고 경제 성장).
- 소비 구조: 중국·인도·인도네시아 석탄 비율 높음, 러시아·이란 천연가스, 캐나다·브라질 수력.
- 화석 에너지 소비 비율 변화(1990→2023): 중국 급증해 세계 최대(2010 전후 미국 추월), 미국·러시아·일본 감소(필기: 친환경 에너지 전환, 국가·기업 탄소 중립). 상위 5개국이 세계 화석 에너지 소비의 50% 이상.
- OECD(선진국) vs 비OECD(개발 도상국): 비OECD 화석 에너지 소비량이 빠르게 증가(2000년대에 OECD 추월). 1990→2023 OECD는 석탄 감소·천연가스 증가, 비OECD는 석유·천연가스·석탄 모두 증가, 석탄이 가장 많이 증가.

## 15 (Ⅴ 학습노트 14쪽 — 원자력·신재생)
- 원자력: 우라늄·플루토늄 핵분열(핵융합) 열에너지. 장점: 적은 연료로 많은 전력, 화력보다 대기 오염 적음. 단점: 방사능 누출 위험, 방사성 폐기물 처리 어려움. 입지: 지반 안정 + 냉각수 풍부(바닷가).
- 원자력 생산량 비율(2023): 미국 약 30% > 중국 16 > 프랑스 12 > 러시아 8 > 대한민국 7. 전력 생산 중 원자력 비율: 프랑스 65 > 우크라이나 51 > 대한민국 29 > … 미국 18. 필기: **총량 / 비율 구분**(원자력 생산량 1위 미국, 비율 1위 프랑스).
- 신재생: 정의(화석을 변환한 신에너지 + 햇빛·물·바람·지열 재생 에너지), 대기 오염 적고 고갈 가능성 낮음. NDC(국가 온실가스 감축 목표) 달성 위한 신재생 의무 할당제·환경 규제로 개발 활발. 기술 발달로 **균등화 발전 비용(LCOE: 준비~연료 처리까지 모든 비용, 발전 방식 경제성 비교)**이 화력·원자력보다 낮아진 나라 등장. 국가별 연료 수급·자연환경 차이·정책으로 에너지원별 LCOE가 다름.
- 입지: 수력 = 강수량 많아 유량 풍부·큰 강(중국 1위, 브라질 아마존강) + 산지·빙하 침식 골짜기로 낙차(캐나다, 노르웨이, 러시아) / 풍력 = 일정하고 강한 바람이 지속되는 산지·해안·섬(중국 1위, 미국, 독일, 영국, 에스파냐, 프랑스) / 태양광(열) = 비 적고 일사량 풍부(중국 1위, 미국, 일본, 에스파냐) / 지열 = 신기 조산대·판의 경계(미국 1위, 인도네시아, 필리핀, 튀르키예, 뉴질랜드, 멕시코, 케냐).
- 발전량 비율(2022): 수력 중국 30·브라질 9.9·캐나다 9.2, 풍력 중국 35·미국 21·독일 6·영국 3.8, 태양광 중국 32·미국 16·일본 7.7, 지열 미국 20·인도네시아 17·튀르키예 11.5·필리핀 10.8. 필기: 풍력 = 편서풍(영국·서유럽), 태양광 = 지중해성(에스파냐), 지열 = 환태평양 조산대(불의 고리).

## 12·13 (Ⅳ-3 학습노트 9차시 17~18쪽 — 영역 분쟁)

- 유럽 분리 독립: 북아일랜드 = 개신교 영국(잉글랜드) vs 가톨릭 다수 북아일랜드 / 카탈루냐 = 독자적 언어·문화·민족과 높은 경제 비중으로 에스파냐에서 독립 요구 / (그 밖에 벨기에 언어 갈등 등 — 사진 18쪽 확인).

## 15 (Ⅴ-3 학습노트 6차시 11쪽 — 자원의 의미·특성·분류)
- 자원 = 자연으로부터 얻는 것 중 인간의 일상·경제 활동에 유용한 것. **기술적 의미**(현재 기술로 개발·사용 가능) ⊃ **경제적 의미**(기술적으로 가능 + 경제성 있어 상업적으로 널리 사용). 그림: 자연 ⊃ 기술적 ⊃ 경제적, A(경제적)·B·C 칸(필기: 셰일 석유처럼 A↔B가 바뀌는 가변적 자원).
- 특성: 가변성(기술 수준·경제 조건·문화적 배경에 따라 의미·가치 변화) / 유한성(매장량 한정 → 고갈, **가채 연수 = 확인된 가채 매장량 ÷ 연간 생산량**, 새 매장지 발견·수요 증감에 따라 가변적) / 편재성(일부 지역에 편중 → **자원 민족주의**: 자원 보유국이 공급·가격 조정으로 자원을 전략 무기화해 국제적 영향력 강화·경제 성장을 꾀함).
- 분류 ① 의미: 좁은 의미(천연자원 — 생물 자원, 무생물 자원(광물·에너지)) / 넓은 의미(+ 인적 자원(인구·기술·창의력), 문화적 자원(언어·종교·제도)). ② 재생 가능성: 재생 불가능(비재생·고갈 자원 — 화석 에너지 석유·석탄·천연가스) / 재생 가능(재생·순환 자원 — 수력·조력·지열·풍력·태양광(열), 신재생) / 사용량과 투자 정도에 따라 재생 수준이 달라지는 자원(구리·철광석 등 금속 광물, 재활용 여부). 막대 그림: 화석 연료 → 식물·동물·삼림·토양 → 비금속 광물 → 금속 광물 → 대기·물 → 태양광·열·조력·풍력·수력(무한 재생).
- 에너지 자원 = 화석 에너지·원자력 에너지(핵분열)·신재생 에너지(수력·태양광·풍력·지열 등)로 동력을 생산하는 자원. 1차 에너지 = 가공 전 천연자원 상태로 공급(석유·석탄·천연가스·수력·원자력), 2차 에너지 = 1차를 변환·가공(전기, 도시가스).

## 15 (Ⅴ 학습노트 16쪽 — 자원 문제와 분쟁)
- 에너지 자원 분포·소비에 따른 문제: 국가 간 갈등 심화(자원 확보·이동 둘러싸고, 보유국의 자원 민족주의) / 자원 고갈(유한성 + 소비 증가 → 에너지 부족) / 에너지 소비 격차(소비 상위 5개국 — 중국 압도적 1위, 미국, 인도, 러시아, 일본 — 이 세계 소비의 50% 이상, 저개발국은 전기 없이 땔감으로 난방·조리) / 환경 문제(화석 연료 연소 → 환경 오염·지구 온난화).
- 자원 분쟁 지역: 북극해(러시아·미국·캐나다·덴마크·노르웨이, 석유·해상 교통로), 센카쿠 열도(일본·중국·타이완, 석유·해상 교통로), 남중국해(중국·타이완·베트남·필리핀·말레이시아·브루나이, 해양 생물·석유·천연가스·해상 교통로), 포클랜드 제도(영국·아르헨티나, 석유).
- 동부·동남아시아 영역 분쟁 표: 쿠릴 열도(지시마 열도) 실효 지배 러시아·분쟁 일본, 석유·금·수산물 / 센카쿠 열도(댜오위다오) 일본 지배·중국·타이완 분쟁, 석유·천연가스 / 시사 군도(파라셀 군도) 중국 지배·베트남·타이완 분쟁, 석유·천연가스·구아노(새똥 비료)·수산물 / 난사 군도(스프래틀리 군도) 베트남·필리핀·중국·타이완 등 분할 지배, 중국·타이완·필리핀·베트남·브루나이·말레이시아 분쟁, 석유·천연가스·구아노.
- 북극해: 한반도의 약 70배, 세계 석유 약 13%·천연가스 약 30% 매장. 지구 온난화로 얼음이 녹아 탐사·개발·해상 교통로 가능 → 연안국 러시아·미국·캐나다·노르웨이·덴마크가 영유권 주장.
- 포클랜드 제도: 아르헨티나에서 약 400km, 실효 지배 영국(해외 영토), 아르헨티나는 '말비나스 제도'라 부르며 영유권 주장, 최근 석유 자원 분쟁으로 격화.
