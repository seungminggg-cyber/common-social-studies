## 학습지 개념 요약 (계양고 소책자, 새 문장으로 정리)

**07 (74~77쪽)** 자본주의 = 사유 재산 제도 바탕, 자원의 효율적 배분. 특징: 경제 활동의 자유 최대 보장, 사유 재산권 법적 보장, 시장 가격에 따른 거래. 상업 자본주의(16~18세기): 15세기 신항로 개척 뒤 절대 왕정의 중상주의, 상품의 유통·무역으로 이윤(인도 후추를 싸게 사서 유럽에 비싸게), 자본 축적 → 산업 자본주의 밑거름. 산업 자본주의(18~19세기): 18세기 중반 산업 혁명, 공장제 기계 공업·대량 생산, 생산 과정에서 이윤, 스미스 '보이지 않는 손'·자유방임주의. 수정 자본주의(20세기): 시장 실패·1929 대공황(기업·은행 도산, 실업), 대규모 공공사업·복지로 시장에 적극 개입하는 큰 정부(뉴딜), 케인스. 신자유주의(20세기 말): 1970년대 석유 파동·스태그플레이션 → 정부 실패, 민영화·규제 완화·복지 축소·자유 무역, 시장 효율성↑이나 빈부 격차 심화 비판, 하이에크. 석유 파동 1차 1973 제4차 중동 전쟁, 2차 1979 이란 혁명(당시 세계 4위 석유 수출국, 생산 중단). 대공황 = 수요 부족 → 정부가 수요 창출로 대응 가능 / 스태그플레이션 = 석유 가격 상승에 따른 공급 부족 → 정부 개입으로 대응 어려움 → 정부 기능 한계 → 신자유주의. 대처리즘·레이거노믹스: 세금 감면, 규제 완화, 공기업 민영화, 복지 축소. 2008 세계 금융 위기: 미국이 경기 부양으로 금리 최대한 인하 → 신용도 낮은 사람에게도 주택 담보 대출(서브프라임 모기지) → 금리 상승·집값 하락 → 대출금 못 갚음 → 은행 연쇄 파산. 탐구 '경제학자 가상 인터뷰': 스미스(각자 이익 추구 → 사회 전체 이익 증가, 보이지 않는 손 = 시장 가격, 작은 정부·야경국가), 케인스(시장은 항상 효율적이지 않음, 대규모 댐 건설 → 일자리·임금 → 유효 수요 → 대공황 극복), 하이에크.
**08 (78~85쪽, 78~79 사진 없음)** 기회비용 = 명시적 비용 + 암묵적 비용(공연 관람비·교통비 20만 + 하루 임금 10만 = 30만), 순편익(편익 − 기회비용)이 양(+)인 대안이 합리적 선택, 다른 대안 순편익은 음(−). 합리적 선택의 한계 = 시장 실패, 요인: 불공정 경쟁(독과점이 공급량 줄이고 가격 올림, 담합), 공공재의 부족(비배제성·비경합성, 국방·치안·가로등, 시장에 맡기면 과소 공급, 무임승차), 외부 효과(의도하지 않은 이득·손해에 보상 없음, 긍정적 → 과소 / 부정적 → 과다). 재화 분류 표: 사적 재화(배제·경합: 물건 구매, 의료 서비스, 막히는 유료 도로), 자연 독점(배제·비경합: 유료 케이블 방송, 한산한 유료 도로, OTT), 공유 자원(비배제·경합: 막히는 무료 도로, 공해상 물고기), 공공재(비배제·비경합: 국방, 치안, 가로등, 한산한 무료 도로). 외부 효과 사례를 소비/생산 측면 × 외부 경제/불경제로 분류하는 활동. 지속가능발전(미래 세대 능력을 해치지 않고 현재 필요 충족), K-SDGs(UN 2015 17개 목표를 우리 상황에 맞게). 정부: 공정 경쟁 법·제도(독과점 규제·담합 방지), 공공재 생산, 외부 효과에 세금·보조금 등 경제적 유인(긍정적 유인 = 편익 증가·기회비용 감소: 금전적 이득·명예·칭찬 / 부정적 유인 = 편익 감소·기회비용 증가: 금전적 손실·처벌·비난; 긍정적 외부 효과 → 보조금·세제 혜택, 부정적 → 배출량 제한·세금), 사회 보장·누진세 재분배. 기업: 재화·서비스 공급, 일자리, 기업가 정신(위험·불확실성 감수하고 혁신, 슘페터: 기술 혁신 → 낡은 것 파괴·새것 창조 '창조적 파괴' / 드러커: 기업가 정신 = 새로운 가치를 창출하는 행위, 자기 경영), 사회적 책임(환경 보호·소비자 안전·노동자 권리·기업 윤리), ESG(환경 E·사회적 책임 S·건전한 지배 구조 G), RE100(2050년까지 사용 전력 100% 재생 에너지, 국제 캠페인). 노동자: 헌법 제32조 제3항 근로 조건 기준 → 근로 기준법(근로 계약·임금·근로 시간·휴식·재해 보상), 제33조 제1항 노동 3권(단결권 = 노동조합 결성, 단체 교섭권 = 근로 조건 집단 교섭, 단체 행동권 = 파업 등 쟁의 행위) → 노동조합 및 노동관계조정법, 최저 임금제. 소비자: 소비자 주권(소비자가 생산을 결정), 윤리적 소비(생산·유통 과정까지 윤리적으로 판단; 유기농·방목 사육·공정 무역 마크 상품 고르기, 유해 제품 기업 불매).
**09 (86~89쪽)** 금융 자산(현금·예금·채권·주식) ↔ 실물 자산(토지·건물·기계). 예금(원금+이자, 요구불: 수시 입출금·이자 낮음 / 저축성: 정기 예금·적금), 채권(정부·기업·은행이 이자·원금 약속하고 발행, 이자 + 시세 차익), 주식(배당금 + 시세 차익, 주주로 의사 결정 참여), 펀드(전문 기관 간접 투자), 보험, 연금. 특성 비교 질문: 만기가 있나, 이자가 있나, 시세 차익, 배당, 예금자 보호. 예금자 보호(금융 기관 영업 정지·파산 시 예금 보험 공사가 한도 안에서 지급). 자산 관리 = 소득 기반 소비·저축·투자 계획. 원칙: 수익성(가격 상승·이자, 예금보다 채권·주식 높음), 유동성(현금 전환 쉬움, 예금보다 주식·채권 낮음), 안전성(예금>채권>주식), 수익성과 안전성은 상충. 포트폴리오(분산 투자, 토빈 1981 노벨상 '계란을 한 바구니에 담지 말라'). 금융 생활 설계: 목표 수립(단기·중장기) → 계획 수립(소득 예측·소비 규모·저축·투자 방법) → 실행 → 검토 및 평가(분석·수정). 생애 주기 곡선(수입 > 지출 시기 저축·투자, 은퇴 뒤 지출 > 수입). 금융 의사 결정 고려: 금리(상승 → 이자 부담·소비·대출 감소, 예금 증가 / 하락 → 예금 줄이고 주식 등 투자, 대출로 투자), 물가(상승 → 화폐 가치 하락 → 실물 자산 투자 / 하락 → 예금 등 유동성 높은 자산 선호), 환율(상승 → 외국 주식 투자자·외화 보유자의 원화 환산 수익 증가, 국내 자동차는 미국에서 가격 하락 효과 → 수출 유리, 유학생 송금 부담 증가; 1달러 1,000원 → 1,200원 = 원화 가치 하락), 사회 환경(금융 위기 → 금융 자산 가격 하락·소비·투자 침체, 전쟁·원자재 가격 급등 → 물가 상승·실물 자산 선호, 팬데믹 봉쇄 → 소비·투자 위축, 외교 관계 악화 → 관련 기업 주가 하락). 학습지 자료: A·B 두 사람의 소득 사용 원그래프(소비·저축 및 투자·부채 상환·예비 자금).
**10 (90~92쪽)** 무역 = 상품·서비스·생산 요소의 국제 거래, 생산 요소 분포 차이 → 생산비 차이. 절대 우위(특정 상품을 더 적은 생산비, 스미스) / 비교 우위(같은 상품을 더 적은 기회비용, 리카도: 한 나라가 두 상품 모두 더 많이 생산해도 둘 다 이익). 특화·국제 분업. 무역의 이익: 소비자 싼 값·다양한 상품, 기업 규모의 경제, 국가 자원·기술력 부족 해결. 학습지 예제: 1단위당 생산비(달러) 표 → 무역 전 생산 비용·무역 후 비용(각자 특화 상품 2단위 생산 후 1:1 교환) → 아낀 이익. 노동량 표(한 나라가 두 재화 모두 노동 적게) → 기회비용 비교 → 비교 우위 → 특화·교환. 무역 확대 문제: 이익 분배 불평등, 강제·아동 노동, 열악한 근로·낮은 임금, 생태계 파괴·기후변화 → 공정 무역(생산자·노동자에게 정당한 대가), WFTO 10대 원칙(소외된 생산자 기회, 투명성·책임성, 공정한 무역 관행, 공정한 가격 지불, 아동·강제 노동 금지, 차별 금지·성 평등·결사의 자유, 올바른 노동 조건, 역량 강화, 공정 무역 홍보, 환경 보호), 대체 에너지·재활용, 파리 협정. 주체: 정부(환경 규제 강화·친환경 기술 지원, 노동 조건 법), 기업(친환경 생산, 사회적 책임), 소비자(공정 무역 상품).
