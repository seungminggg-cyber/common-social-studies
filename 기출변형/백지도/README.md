# 백지도 테스트 (통합사회2 Ⅳ·Ⅴ 나라 위치)

인천 계양 고1 기말 대비. 세계 지도에서 나라 위치를 익히는 테스트지.

## 1단계 — 나라 세기 (2026-11-22)
- `나라목록.md`·`나라목록.json`: 다섯 학교 학습지 + 개념풀 + 개념서의 Ⅳ·Ⅴ 나라(횟수, 나온 곳)
- `후보목록.md`: 자주 나오는 순위(30·50개국), `자원파트_추가후보.md`: 50개국 밖 자원 관련 나라
- 도구: `names.py`(이름 사전), `count.py`(개념풀·개념서 세기), `build.py`(합치기), `rank.py`(순위)
  - 학교 학습지는 사진을 눈으로 읽어 JSON으로 적은 것(사진·JSON은 저장소 밖)

## 2단계 — 테스트지 (강사 확정 2026-11-22)
- 범위: 50개국 + 쿠웨이트·아제르바이잔·투르크메니스탄·카자흐스탄·이집트 = **공통 55개국**
  - 서운고 + 라오스·태국·캄보디아(메콩강) = 58, 인천국제고 + 앙골라·적도 기니·콩고 민주 공화국·가봉·수단·탄자니아·우간다(기니만·나일강) = 62
  - 작전고·계양고·계산여고는 공통판
- 형식: 대륙별 5장(① 동·동남·남아시아 ② 서남·중앙아시아 ③ 유럽 ④ 아프리카 ⑤ 아메리카·오세아니아), 번호 붙은 나라(노란색)의 이름 쓰기, 정답판 따로
- 만들기: `node 기출변형/백지도/build.mjs` → `기출변형/백지도/out/백지도_<공통|서운고|인천국제고>_<학생용|정답>.pdf` (out은 저장소에 안 올림)
- 지도: `textbook/data/geo/countries-kor-50m.json`(Natural Earth, 우리나라 정부 시각 국경), 정적 방위 도법(지역마다 가운데를 맞춤)
- 나라·번호 자리·작은 나라 빼내기 선은 `build.mjs`의 `SHEETS`에서 고친다. 번호는 지도 위쪽 띠부터 왼쪽 → 오른쪽 순서.
