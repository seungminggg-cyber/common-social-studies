# MINIMAX 킬러편 — 출제 기준

강사(승민T)가 2026-11-15에 요청한 책이다. 다른 문서보다 이 문서가 먼저다. 이 문서에 없는 것은 `기출변형/CLAUDE.md`, `참고/3차지침.md`를 따른다.

## 1. 이 책이 무엇인가
- **2028 수능 통합사회 대비 고난도(킬러) 문항 200개**, 한 권. 통합사회1 89문항, 통합사회2 111문항. 중단원별 문항 수는 `배분.json`에 있다.
- 읽는 사람은 승민T 학원의 상위권 학생이다. 개념서 MINIMAP, 기출분석 MINIMAX를 끝내고 1등급을 노린다.
- 2028은 첫 통합사회 수능이다. 수능형 기출이 예시문항 25개뿐이다. 그래서 이 책은 학생이 만나는 **가장 수능다운 최고 난도 문제집**이어야 한다.
- 이 책을 다 만든 뒤, 같은 문항으로 **스킬특강 교재**를 만든다(`스킬특강/기획.md`). 사회문화 1타 강사의 스킬특강처럼 비슷한 유형을 묶어 접근법과 빠른 풀이법을 가르치는 책이다. 그래서 문항마다 `skill`(풀이 기술 묶음) 태그를 단다.

## 2. 난이도 기준 — "UNIVERCITY 2.5점과 같거나 더 어렵게"
- **기준선**: 2028 수능 예시문항의 2.5점 8문항(3·5·12·13·14·15·21·22번)과 스타강사코리아 UNIVERCITY 모의고사(2회)의 2.5점 16문항. 구조 분석은 `참고/UNIVERCITY분석.md` — 2.5점 가운데 진짜 이중·삼중 추론인 다섯 문항(구 지우기 퍼즐, 두 그래프 짝 짓기, 산점도 + 산업 구조, 빈칸 역추론, 시기 판별 → 지역) 수준을 킬러편의 **기본**으로 삼는다. 강사는 UNIVERCITY 2.5점 문항이 모두 괜찮다고 했다. 단, **통합사회 범위 밖 내용**만은 쓰지 않는다.
- 모든 문항은 `level: '상'`이다. 배점으로 치면 2.5점(수능 3점급)이다.
- **어려움은 추론에서 나와야 한다.** 교과서 밖 사실(순위, 세부 연도, 최대 수출국 등)이나 지엽 지식으로 어렵게 만들지 않는다. 정답은 자료와 개념서 안의 근거로 **하나로** 정해져야 한다. 11/07 분석에서 스타강사 문항의 약점이 이 점이었다. 우리는 이 약점을 따라 하지 않는다.
- 각 문항은 아래 여섯 가지 가운데 **셋 이상**을 갖춘다(3차지침 2절과 같음). 그리고 **이중추론**(3절)이 있어야 한다.
  1. 판별이 먼저: 사상가·지역·국가·제도·시기·값을 숨기고, 단서 2개 이상으로 찾게 한다.
  2. 두 자료 결합: 한 자료만으로는 답이 나오지 않는다(그래프 + 지도, 표 + 글, 순서도 + 제시문).
  3. 계산·비교 2단계: 비율과 절대량, 증가율과 증가량, 기회비용(명시적 + 암묵적), 교환 비율 범위, 지수 역산.
  4. 판단 구조: <보기> ㄱ~ㄹ, '적어도 한 사람', 예/아니요 순서도, 질문 분류표, 채점 결과 역추론, 벤 다이어그램.
  5. 정교한 함정: 주체·방향·범위 바꾸기(만/모두/항상), 비슷한 사상가 주장 섞기, 원인과 결과 뒤집기, 단위 바꾸기, 남반구 계절.
  6. 단원 결합: 두 중단원 이상(예시문항 13번처럼 밑줄 여러 개가 여러 단원).
- 기준선을 넘었는지 판단하는 질문: "예시문항 2.5점이나 UNIVERCITY 2.5점과 나란히 놓으면, 이 문항이 더 오래 걸리고 더 많이 틀리는가?" 검토자는 예상 정답률(상위 30% 학생 기준)과 풀이 단계 수를 적는다. 예상 정답률이 50%를 넘으면 다시 쓴다.

## 3. 형식 — 수능형 + 신유형 + 이중추론 (강사 요청 2026-11-15)
강사: "수능형, 신유형 문항이 많았으면 좋겠다. 순서도, 표 및 그래프 분석, 계산, O/X, 수행평가(채점형) 바탕으로 추론하는 문제 등. 이밖에도 Fable이 스스로 사고해서 다양한 유형의 이중추론 문항을 만들어 줬으면 좋겠다."

- **이중추론**이란, 선지를 판단하기 전에 추론을 두 번 거쳐야 하는 구조다. 첫 번째 추론으로 숨은 것 하나를 확정하고, 그것을 이용해 두 번째 숨은 것을 확정한다. 예:
  - 채점 결과(점수) → 학생이 쓴 O/X 역추론 → (가) 사상가 확정 → 선지 판단
  - 예/아니요 순서도의 갈림길 → A·B 사상가 확정 → 질문 (가)에 들어갈 진술 추론
  - 표의 비율과 총량 → 각 국가의 절대량 계산 → 지도 위치와 짝 짓기
  - 기회비용 표 → 비교 우위 확정 → 교환 비율 범위에서 이익 여부 판단
  - 연표의 사건 순서 → (가) 시기 확정 → 그 시기 문서의 내용 판단
- 신유형 형식 예(이 밖에도 새로 만들어도 된다): 예/아니요 순서도, 질문 분류표, 학생 O/X 응답표·채점 결과(수행평가 채점형), 학생 답안 채점, 벤 다이어그램 A·B·C, 3축 좌표, 거품·도넛·트리맵·편차·방사형·산점도·인구 피라미드·삼각 그래프, 상댓값 지수(기준=100), 퍼즐(지역·구 지우기), 조건 여럿으로 국가·경로 역추론, 대화·수업 장면, 탐구 보고서, 신문 기사 밑줄 다발, 카드·주사위 전개도.
- **책 전체의 형식 목표**(200문항 기준, 대략):

| 형식 | 문항 수 |
|---|---|
| 사상가(두세 명 비교, 순서도·벤·질문 분류표 포함) | 35~45 |
| 그래프 해석(서로 다른 모양을 고루) | 35~45 |
| 표 분석·계산(경제·인구·지수) | 25~35 |
| 지도 해석(지도 + 다른 자료) | 15~20 |
| 수행평가·채점 결과·학생 O/X 응답 역추론 | 15~25 |
| 사료·문서·헌법 조항·기사 밑줄 | 15~20 |
| 단원 결합형(두 중단원 이상) | 20 이상(다른 형식과 겹쳐도 됨) |
| '옳지 않은 것' 발문 | 10~15 |

- 같은 단원 안에서 같은 형식·같은 소재를 되풀이하지 않는다. MAXIMIN·1차 모의고사·MINIMAX 1·2차 문항과 같은 자료·사례·숫자를 쓰지 않는다(`node tools/dup-check.mjs k --vs 2`, `--vs 1`).

## 5. 강사가 정한 규칙(그대로 지킨다)
`참고/3차지침.md` 6절 전부. 요약:
- 밑줄은 검정이다. '옳지 않은 것'의 '않은' 밑줄은 빌드가 넣는다. 문제 쪽에 출처·'가상 자료'·'(새로 씀)' 같은 표시를 쓰지 않는다(실제 통계는 `source: '자료: …'`만 적으면 해설 끝으로 간다).
- <보기> ㄱ~ㄹ은 그림의 A·B·C 순서로 놓는다. 학생 고르기 선지에서 세 명 조합은 ④·⑤에 둔다.
- 계산 공식은 문제에 준다(부양비·노령화 지수·기회비용·교환 비율 등).
- 사상가는 개념서 사상가 카드 범위 안에서만 쓴다. **테일러·레건·아퀴나스는 오답 선지로도 쓰지 않는다.** 요나스·왈처·베카리아는 써도 된다.
- 세계 지도에는 적도선을 그리고, 지점은 정확한 좌표에 작은 점으로 찍는다. 선지는 '지점 ↔ 자료' 대응을 판단해야 풀리게 한다.
- 분배의 '업적'은 이룬 결과·성과로 보여 준다(시간은 노력으로 읽힘).
- 실제 숫자는 출처가 확인된 것만 쓴다. 나머지는 그럴듯한 가상 숫자다. 지도는 우리나라 정부 시각 국경이다.

## 6. 문항 파일 형식
- 파일: `content/k/<중단원키>.js` (예: `content/k/t2-08.js`), `export default [ … ]`.
- id: `<중단원키>-k-<세 자리>` (예: `t2-08-k-001`). 한 번 정한 id는 바꾸지 않는다.
- 항목은 `기출변형/CLAUDE.md`의 문항 형식과 같다: `id, level: '상', concept, type, src, stem, data, bogi, choices, answer, explain, note`.
  - `type`은 정해진 11가지 중 하나다(개념 이해, 사례 적용, 자료 해석, 그래프 해석, 지도 해석, 사상가 입장, 사상가 비교, 입장 비교, 글 해석, 질문 분류표, 계산).
- 킬러편에만 있는 항목(책에는 안 보임):
  - `kform`: 형식 이름(자유롭게, 예: '채점 결과 역추론 + 벤 다이어그램')
  - `kcond`: 갖춘 조건 번호 배열(2절의 1~6, 예: `[1, 2, 4, 5]`)
  - `double`: 이중추론 한 줄 설명(예: '채점 점수 → 학생 응답 → 사상가 확정')
  - `skill`: 스킬특강 묶음 키(7절)
- 정답 번호는 단원마다, 그리고 책 전체에서 ①~⑤가 고르게 나오게 한다. 같은 번호가 세 번 연속 나오지 않게 한다.
- 해설(`explain`)은 정답 근거를 먼저 쓰고, 오답 선지(①~⑤)나 <보기>(ㄱ~ㄹ)마다 틀린 이유를 쓴다. 계산은 과정까지 쓴다. **이중추론의 두 단계를 순서대로 보여 준다.** 문체는 '-이다/-한다'이다.
- 보충 설명(`note`)에는 개념서 밖 내용, 함정의 원리, 빠른 풀이 요령을 쓴다. 스킬특강의 재료가 된다.
- 자료 블록 쓰는 법: `참고/3차작업/출제지시.md` 5절, 견본 `content/2/mock/m7.js`(강사가 승인한 회차).

## 9. 디자인과 노력 수준 (강사 확인 2026-11-15: 디자인은 기존 틀 그대로)
- **본문은 기존 문제집 틀을 그대로 쓴다.** `node build.mjs k …`가 MINIMAX·MAXIMIN과 같은 모양(개념서 시안 H, 문제 머리, 대단원 색·엄지 색인, 쪽수 줄이기 7쪽안 `wbc`)으로 만든다. 시리즈가 한눈에 같아 보이고, 강사가 이미 승인한 모양이다. 출제 세션은 디자인에 사용량을 쓰지 않는다.
- **표지·간지는 아직 없다.** 문항이 끝난 뒤 강사와 정한다(MINIMAX '네온 길' 계열의 킬러편 색 등, `cover/`). 출제 세션이 만들지 않는다.
- **노력 수준**(강사 확인 2026-11-15): 출제 세션(Fable) 자신 = high, 다시 풀기·난도 판정(Opus) = high, 새 그림 기능 코드(Opus) = medium, 빌드·자동 검사(Opus) = low. **쪽 그림 눈 확인은 Fable이 직접 한다**(강사: 그림 확인을 더 값싼 모델에 맡기지 않음).
- **새 자료 모양이 필요하면 렌더러에 더한다.** 지금 있는 것: 그래프 bar·hbar·stack100·line·scatter(거품)·pie(도넛)·climate·climdev(편차)·radar·pyramid, 도식 yesno(순서도)·venn3·triangle·timeline·cycle·cards·citymodel·concentric·layers·stairs·econflow·cultchange, 지도(세계·지역·서울 자치구). 3축 좌표, 트리맵, 삼각 그래프(세 비율) 같은 것이 필요하면 Opus 하위 에이전트에게 `textbook/lib/`에 **새 kind로** 더하게 한다. 기존 kind의 모양은 바꾸지 않는다(개념서·다른 문제집 빌드가 달라지면 안 됨). 더한 뒤 `textbook/content/z-gallery.js`에 견본 하나를 넣는다.
- **스킬특강 교재**는 예시문항 특강 교재(`특강/`)의 틀과 디자인을 다시 쓴다(`스킬특강/기획.md`). 내용 구성에 필요한 칸(스킬 요약 카드, 판서 노트 등)은 더해도 되지만, 글꼴·색·쪽 모양은 시리즈와 맞춘다.
