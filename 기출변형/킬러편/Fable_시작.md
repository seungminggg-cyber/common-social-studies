# Fable 세션 시작 문장 (킬러편 출제)

강사가 새 채팅(모델 Fable 5.2, 모드 Auto)을 열고 아래 문장을 붙여 넣는다. `<드라이브 주소>`만 채운다(주소는 저장소에 적지 않는다). 이어서 할 때도 같은 문장을 쓰면 된다 — `진행.md`를 보고 남은 단원부터 한다.

# 할 일
「MINIMAX 킬러편」 200문항을 쓴다. 다 쓰면 같은 문항으로 스킬특강 교재를 만든다.

# 왜 / 누구를 위해
나는 통합사회 학원 강사 승민T다. 이 책은 우리 학원 상위권 학생들이 2028 수능 통합사회(첫 시행)에서 1등급을 받게 하려는 최고 난도 문항집이다. 수능형 기출이 예시문항 25개뿐이라 이 책이 학생들이 만나는 가장 수능다운 고난도 문제가 되어야 한다. 시중 고난도 모의고사(스타강사코리아 UNIVERCITY)의 2.5점 문항과 같거나 더 어려워야 하지만, 어려움은 추론에서 나와야 하고 범위 밖 지식으로 어렵게 만들면 안 된다. 수능형과 신유형(순서도, 표·그래프 분석, 계산, O/X, 수행평가 채점 결과로 추론 등)을 많이 넣고, 네가 스스로 생각해 다양한 이중추론 유형을 만들어 주기를 바란다. 그다음 그 문항들로, 사회문화 1타 강사의 스킬특강처럼 비슷한 고난도 유형을 묶어 접근법과 빠른 풀이법을 가르치는 교재를 네가 직접 만들어 주기를 바란다.

# 시작
- 준비물은 브랜치 `claude/exciting-lovelace-2lu2pq`에 있다(킬러편 준비 + 문제집·개념서 최신본). 먼저 `git fetch origin claude/exciting-lovelace-2lu2pq`를 하고, 네 작업 브랜치를 그 위에 만든다(`git checkout -B <네 작업 브랜치> origin/claude/exciting-lovelace-2lu2pq`). 이어서 하는 세션이면 네 작업 브랜치에 이미 쌓인 커밋이 있는지 먼저 본다.
- 저장소 스킬 `.claude/skills/minimax-killer/SKILL.md`를 읽고, 거기 적힌 순서로 `기출변형/킬러편/기준.md`, `교훈.md`, `진행.md`, 설계 카드를 읽는다.
- 새 컨테이너이므로 먼저 저장소 루트에서 `bash scripts/setup-env.sh`를 돌린다. 원문 대조용 자료는 `python3 -I scripts/fetch-sources.py <드라이브 주소> /home/user/자료/통합사회`로 저장소 밖에 받는다(오래 걸리니 백그라운드로).
- 설계 카드는 Opus가 만든 **제안**이다. 더 좋은 형식·소재·이중추론이 떠오르면 바꿔도 된다.

# 진행
1. 중단원 묶음별로 쓴다. 묶음마다: 출제 → 다른 에이전트(Opus, 노력 수준 high)가 `킬러편/검토지시.md`대로 정답 가리고 다시 풀기 + 난도 판정 → 고침 → 자동 검사·빌드·쪽 그림 확인 → 커밋·push → `진행.md`에 기록.
2. 200문항이 끝나면 책 전체를 검사하고(정답 분포, 형식 목표, 중복, 원문 대조), 학생용·교사용·정답과 해설 PDF를 빌드해 나에게 파일로 보낸다(PDF는 커밋하지 않는다).
3. 그다음 `킬러편/스킬특강/기획.md`를 보고 스킬특강 교재를 만든다.

# 일하는 방식
- 나는 자는 중이라 중간에 답할 수 없다. 묻지 말고, 판단이 필요한 곳은 합리적으로 정해서 진행하고 `진행.md`의 '강사 확인' 목록에 적는다. 위험하거나 되돌릴 수 없는 일(다른 브랜치에 push, 파일 대량 삭제)만 하지 않는다.
- 해야 할 일이 남아 있는 동안 멈추지 않는다. 오류·시간 초과 같은 보통 장애는 원인을 찾아 해결하고 계속한다. 사용량 한도에 걸리면 풀리는 시각에 맞춰 `send_later`로 다시 깨우기를 예약한다.
- 하위 에이전트는 동시에 2~3개까지. 다시 풀기(독립 확인)와 빌드·자동 검사(노력 수준 low)에만 쓰고, 출제는 네가 직접 한다.
- 진행을 보고할 때는 도구 결과로 확인한 것만 했다고 쓴다.
- 마지막 보고는 비개발자인 나를 위해 쉬운 한국어로 쓴다. 결론(몇 문항, 어디까지 했는지, 결과 PDF 위치)을 먼저, 그다음 내가 확인할 것. 다음 세션이 이어받을 수 있게 네 작업 브랜치 이름도 적는다.
