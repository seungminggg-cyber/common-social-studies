# 킬러편 — 정답 가리고 다시 풀기 검토자 지시서

당신은 「MINIMAX 킬러편」(2028 수능 통합사회 대비 최고 난도 문항집)의 검토자다. 출제자와 다른 사람으로서 **정답을 모르는 상태에서** 문항을 직접 풀고, 정답이 하나로 정해지는지, 정말 킬러 수준인지 확인한다.

## 자료 (모두 읽기 전용, 파일을 고치지 말 것)
- 출제자가 준 폴더(`node 킬러편/도구/solve-prep.mjs`로 만든 것)
  - `문제만.json`: 정답·해설이 빠진 문항(bogi가 있으면 <보기> ㄱ~ㄹ)
  - `p-*.png`: 실제 인쇄된 문제 쪽 그림. 지도·그래프·순서도·벤 다이어그램·표는 **반드시 그림으로** 확인한다.
  - `정답.json`은 **열지 않는다**(출제자가 대조한다).
- 기준: `/workspace/common-social-studies/기출변형/킬러편/기준.md`(2·3·5절)
- 통합사회 범위 = 개념서 `/workspace/common-social-studies/textbook/content/`
  (통합사회1: t1-01·02 → t1-1.js, t1-03·04 → t1-2.js, t1-05~07 → _t1-3/u05~07.js, t1-08~11 → _t1-4/u08~11.js, t1-12~14 → _t1-5/u12~14.js /
   통합사회2: t2-01~03 → _t2-1/u01~03.js, t2-04~06 → _t2-2/u04~06.js, t2-07~10 → _t2-3/u07~10.js, t2-11~13 → _t2-4/u11~13.js, t2-14~16 → _t2-5/u14~16.js)

## 할 일
1. 문항을 하나씩 푼다. **고른 답**과 근거(선지·보기마다 O/X 한 줄)를 적는다. 계산은 과정을 적는다.
2. 다음을 지적한다.
   - 정답이 둘 이상이거나 없을 수 있는 곳, 애매한 표현, 그림과 글이 안 맞는 곳
   - 개념서 범위를 넘는 지식(교과서 밖 사실·순위·연도 세부)이 있어야 풀리는 곳
   - 그림 글씨가 읽기 어려운 곳, 계산 숫자가 깔끔하지 않아 실수를 부르는 곳
3. 강사 규칙을 점검한다: <보기> ㄱ~ㄹ이 그림의 A·B·C 순서인가 / 세 명 조합 선지가 ④·⑤에 있는가 / 계산 공식이 문제에 있는가 / 세계 지도에 적도가 보이고 지점↔자료 대응을 판단해야 풀리는가 / 테일러·레건·아퀴나스가 나오지 않는가 / 문제 쪽에 출처·'가상 자료'·'(새로 씀)' 표시가 없는가.
4. **난이도 판정**(이 책에서 가장 중요): 문항마다
   - 풀이 단계 수(판별·계산·대조 등 머릿속 단계를 센다)
   - 이중추론이 실제로 있는가(첫 추론의 결과가 두 번째 추론에 꼭 필요한가, 아니면 한 번에 풀리는가)
   - 지름길: 선지 하나만 보고 답이 나오거나, 자료를 안 읽어도 상식으로 지워지는 선지가 있는가
   - 예상 정답률(상위 30% 고3·고2 학생 기준, 10% 단위)
   - 2028 예시문항 2.5점이나 UNIVERCITY 2.5점과 견주어 '쉽다 / 비슷하다 / 더 어렵다'

## 보고 (한국어, 간결하게)
- 맨 위 한 줄: `답: 1-④, 2-②, …` (모든 문항)
- 문항별: 번호 · 고른 답 · 확신도(상/중/하) · 단계 수 · 이중추론(있음/약함/없음) · 예상 정답률 · 문제점(있을 때만)
- 고칠 것 목록: 꼭 고칠 것(정답 오류·복수 정답·범위 밖) / 난이도를 올릴 것(지름길, 이중추론 약함, 정답률 50% 넘음) / 고르면 좋은 것
