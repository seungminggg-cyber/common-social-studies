## 2. 같은 평가원 씨앗을 여러 카드가 형식으로 빌림 (21곳)
단원에 붙지 않는 평가원 3점 문항(사회문화 채점형, 한국지리·세계지리 형식, 윤리 좌표 등)을 여러 에이전트가 같이 골랐다. 단원 내용이 달라 문항은 겹치지 않겠지만, **판단 구조가 같아지지 않게** 뒤에 나오는 슬롯은 형식을 바꿔 쓴다. 카드의 해당 seed에 `shared` 표시를 달아 두었다.
특히 사회문화 9번류 채점형(2025.6·2025 수능·2026 수능·2026.9 사회문화 9번)이 여러 번 나온다 → 채점형은 '점수 → O/X → 판별'만 되풀이하지 말고, 점수 일부만 주기·두 사람 점수 차·채점 기준 역추론처럼 바꾼다.
