# 백지테스트 (인천 계양 고1 정규반, 2026-11-12 시작)

학생이 수업 때 **답지**를 외운 뒤 같은 모양의 **테스트**(답만 빈 판)에 쓰고 채점한다. 교사용 모범 답안은 따로.

## 만들기
```bash
node 기출변형/백지테스트/build.mjs 07 [png]          # 쪽 하나 → out/백지-07-학생용.pdf(답지+테스트)·-교사용.pdf
node 기출변형/백지테스트/build.mjs set1 [작전고]      # 1회 묶음 → out/1회/1회-<학교>-답지.pdf·-테스트.pdf·교사용
```
- 내용: `content/<중단원>.js`(공통, 개념서 번호) · `content/<학교>1.js`(학교별 쪽: gy 계양, jj 작전, ig 인천국제고(표시 '국제'), sw 서운) · 회차 묶음 `content/sets.js`.
- 블록: `flow`(개념 지도) · `table`(비교 표, `wide`·`head`) · `keys`(키워드) · `fill`(빈칸 정리, `{답}`). `**굵게**` = 핵심어(채점 기준).
- 칸이 `'!'`로 시작하면 **주어진 칸**(테스트에도 회색으로 보이고 칸 수에서 빠짐).

## 강사가 정한 것 (2026-11-12)
- 형식 가(키워드)·나(개념 지도)·다(빈칸 정리)·마(비교 표)를 섞는다. 라(O/X)는 안 씀. PDF만.
- 이름: **답지 / 테스트 / 교사용 모범 답안**. 블록 제목은 **개념 이름만**(설명·한마디 멘트 금지, '헷갈리는 짝'·'뜻을 한 줄로' 같은 말 금지).
- 공통 본편(중단원 1쪽) + 학교별 쪽(그 학교 학습지에만 있는 개념). 여러 학교 학생이 한 반에서 같이 한다.
- 수업 2번: 1회 11/15 Ⅲ(07~10), 2회 11/22 Ⅳ·Ⅴ(11~16). 계산여고는 1회 Ⅰ-3·Ⅱ-3·Ⅴ-2·Ⅴ-3, 2회 Ⅲ-3·4·Ⅳ-2·3.
- **1회 1시간**: 1번 방식(칸 줄이기) — 학교마다 약 85칸(공통 쪽 17~19칸 + 학교별 약 10~25칸). 덜 중요한 칸은 '!'로 주어진 칸.
  추정 근거: 외우기 1칸 20~30초, 기억해 쓰기 1분 약 40자, 채점 1칸 3초.
- 참고 순서: 학교 학습지 → 개념풀 → 나머지 문제집. 학습지·문제집 원문과 결과 PDF는 저장소에 올리지 않는다.
