# 계산 문제 (인천 계양 고1 통합사회2 기말 대비, 2026-11-12 시작)

통합사회2 **Ⅲ-2(개념서 08)** 기회비용·편익·순편익·매몰 비용, **Ⅲ-4(개념서 10)** 절대·비교 우위, 기회비용, 특화, 교역 조건, 무역 이익의 **계산 객관식**.
브랜치 `claude/calc-problems`(백지테스트 브랜치에서 시작). 주간지·문제집 공통 파일은 고치지 않고 이 폴더 안에서만 만든다.

## 만들기
```bash
cd 기출변형
node 계산문제/build.mjs gyeyang [png]   # → 계산문제/out/계양고-문제.pdf · 계양고-정답과해설.pdf
# 학교 키: gyeyang 계양고 · jakjeon 작전고 · inguk 인천국제고 · seoun 서운고 · gyesan 계산여고 · sample 공통만
```
- 학교별 1권 = 공통 18문항(난이도 하·중·상 × 08 3 + 10 3) + 학교 추가 6문항. 정답과 해설은 **별책 PDF**.
- 디자인: 주간지 MINT 시안 1(`주간지/styles/s1.css`)을 그대로 씀. 난이도마다 새 쪽, 남는 칸은 '풀이 메모'.
- 결과 PDF·PNG(`out/`)는 저장소에 올리지 않는다.

## 강사가 정한 것 (2026-11-12)
- 객관식만(5지), 난이도 하·중·상, 공식은 발문에 준다, 숫자·상황·표 모양은 문항마다 다르게.
- 학교별 추가 6문항(하 1·중 2·상 3 기본, 인천국제고는 중 2·상 4로 더 어렵게). 서운고·계산여고는 시험 범위가 Ⅲ-3·4라 10(무역)만.
- **표지 없음, 오글거리는 문구 없음**(제목은 '난이도 하·중·상', 'OO고 추가 문제'만). 첫 쪽 위에 학교·이름 한 줄.
- 정답과 해설은 별책.

## 파일
- `content/common.js` 공통 18문항(id `cm-<h|m|s><08|10>-NN`)
- `content/<학교>.js` 학교 추가 6문항(id `gy-c-NN`, `jj-c-NN`, `ig-c-NN`, `sw-c-NN`, `gs-c-NN`)
- `build.mjs` PDF·PNG 만들기(넘침 검사, 정답 분포 출력)

## 학교 유형 (학습지 확인, 2026-11-12)
- 계양고: 대안 여럿 기회비용·순편익, 매몰 비용, 무역 전후 비용 비교
- 작전고: 밑줄 친 비용 분석, 편익 표, 1단위 생산비(명·시간·달러) → '2단위 생산 후 1:1 교환' 노동력 절감
- 인천국제고: 암묵적 비용 표에서 편익 역산, 콩코드 오류, 노동자 수 표(분수 기회비용), 총노동량·교역 전후 소비, 교역 후 기회비용 변화, 자유 무역 잉여 그래프
- 서운고: 최대 생산량 표(기회비용 공식 제시), 교환 비율이 기회비용 사이인지, 2:5 교환 이익
- 계산여고: **Ⅲ-3·4 학습지 아직 없음** → 다른 학교 유형을 섞어 만듦. 학습지를 받으면 `content/gyesan.js`를 다시 맞춘다.

## 검수
- 문항마다 직접 검산 + 정답을 가린 채 별도로 다시 풀기(48문항).
- 기존 계산 문항(주간지 학교별 브랜치, MINIMAX t2-08·t2-10)과 숫자·상황이 겹치지 않게 함.
