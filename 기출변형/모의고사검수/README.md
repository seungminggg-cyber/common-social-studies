# 모의고사 검수 (2026-11-27 시작, 브랜치 `claude/mock-review`)

강사(승민T)가 받는 여러 모의고사(학교별 모의고사·강사 직접 출제·제미나이 출제)를 **정답 확인 · 예상 정답률·난이도 · 오류 · 고칠 점** 네 가지로 검수한다.
이 채팅은 문항을 직접 고치지 않는다. 보고서와 '이렇게 고치자' 문장 제안까지만 만든다.

## 검수 방법
1. 대상 확인: 어느 학교·범위(`기출변형/주간지/README.md`의 '시험 범위')·누가 만들었는지.
2. 정답 가리고 다시 풀기: 이 채팅 + 하위 에이전트(Opus). 갈리거나 애매한 문항만 Fable(effort high)로 다시 판정. 에이전트는 동시에 1~2개.
3. 예상 정답률(%)·난이도(하·중·상·특상). 기준 집단 = 일반 고1 내신 응시자.
   - 드라이브 학평 해설(2025~2026 고1·고2)에는 **문항별 실제 정답률이 실려 있지 않음**(2026-11-27 확인) → 풀이 단계 수, 함정 선지, 자료 해석 부담, 계산, '모두 고르기' 여부로 추정.
4. 오류: 정답 오류·복수 정답·정답 없음, 사실 오류(개념서 `textbook/content/`, 예금자 보호 1억 원), 범위 밖 개념(학교 시험 범위·학습지), 발문·선지 모호, 자료↔선지 불일치, 용어·오탈자, 정답 번호 분포, 배점 합계, 겹치는 문항, 그림·표.
5. 보고서: 요약(큰 오류 수, 예상 평균, 난이도 분포, 먼저 고칠 3문항) + 문항별 표.
   - 학교별: 강사 OK → 그 학교 채팅에 고칠 목록 send_message, 조정 채팅에 한 줄 알림.
   - 강사·제미나이: 고친 문장을 강사에게 바로 정리.

## 저장 규칙
- 강사·제미나이 모의고사 원문, 받은 PDF, 보고서는 `out/`(저장소에 올리지 않음).
- 진행 기록에는 문항 문장 없이 '무엇을 언제 검수했는지, 큰 오류 수'만.
