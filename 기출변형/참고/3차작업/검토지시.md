# 정답 가리고 다시 풀기 — 검토자 지시서

당신은 고등학교 통합사회(2022 개정) 수능 모의고사의 검토자다. 출제자와 다른 사람으로서 **정답을 모르는 상태에서** 25문항을 직접 풀고, 정답이 하나로 정해지는지 확인한다.

## 자료 (모두 읽기 전용, 파일을 고치지 말 것)
- 폴더 `scratchpad/solve<차수>-<회>/`(프롬프트에 경로가 있음)
  - `문제만.json`: 정답·해설이 빠진 25문항(bogi가 있으면 <보기> ㄱ~ㄹ)
  - `p-04.png` ~ : 실제 인쇄된 문제 쪽 그림. 지도·그래프·순서도·벤 다이어그램·표는 반드시 그림으로 확인한다.
  - `정답.json`은 **열지 않는다**(끝난 뒤 출제자가 대조).
- 통합사회 범위 = 개념서 `/workspace/common-social-studies/textbook/content/`
  (통합사회1: t1-01·02 → t1-1.js, t1-03·04 → t1-2.js, t1-05~07 → _t1-3/u05~07.js, t1-08~11 → _t1-4/u08~11.js, t1-12~14 → _t1-5/u12~14.js /
   통합사회2: t2-01~03 → _t2-1/u01~03.js, t2-04~06 → _t2-2/u04~06.js, t2-07~10 → _t2-3/u07~10.js, t2-11~13 → _t2-4/u11~13.js, t2-14~16 → _t2-5/u14~16.js)

## 할 일
1. 25문항을 하나씩 풀어 **고른 답**과 근거(선지·보기마다 O/X 한 줄)를 적는다. 계산 문항은 계산 과정을 적는다.
2. 다음을 지적한다: 정답이 둘 이상이거나 없을 수 있는 곳, 애매한 표현, 그림과 글이 안 맞는 곳, 개념서 범위를 넘는 지식(교과서 밖 사실·순위·연도 세부 등)이 있어야 풀리는 곳, 그림 글씨가 읽기 어려운 곳.
3. 강사 규칙 점검: <보기> ㄱ~ㄹ이 그림의 A·B·C 순서인가 / 학생 고르기 선지에서 세 명 조합이 ④·⑤에 있는가 / 계산 공식이 문제에 주어졌는가 / 세계 지도에 적도가 보이고 지점↔자료 대응을 판단해야 풀리는가 / 테일러·레건·아퀴나스가 나오지 않는가 / 문제 쪽에 출처·'가상 자료'·'(실제 … 단순화)'·'(새로 씀)' 표시가 없는가.
4. 2.5점 문항이 수능 3점급(판별·두 자료 결합·2단계 계산·판단 구조·정교한 함정·단원 결합 중 셋 이상)인지 한 줄씩.

## 보고 (한국어, 간결하게)
- 맨 위 한 줄: `답: 1-④, 2-②, …` (25개 모두)
- 문항별: 번호 · 고른 답 · 확신도(상/중/하) · 문제점(있을 때만)
- 고칠 것 목록(꼭 고칠 것 / 고르면 좋은 것)
