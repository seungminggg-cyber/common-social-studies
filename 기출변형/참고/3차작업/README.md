근거 기출은 `참고/평가원기출/겹침목록.json`에서 같은 단원·overlap '완전' 먼저·2.5점은 level '상' 먼저, 이미 쓴 씨앗(7회 src 등)과 회차끼리 겹치지 않게 배분.
