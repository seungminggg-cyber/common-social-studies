# 3차(전면 수정) 지침 — MINIMAX 합본·MAXIMIN

강사 요청(2026-11-07): "MINIMAX·MAXIMIN 문제들 전면 수정. 문제 형식 다양화, 통합사회 기출 + 3개년 사회탐구 평가원 모의고사의 문제 형식과 난이도를 반영해 출제.
특히 MINIMAX 심화(STEP 2)와 MAXIMIN의 2.5점 문항은 수능 3점, 스타강사코리아 유니버시티 2.5점 혹은 그 이상의 난이도로."

`CLAUDE.md`, `참고/문항작성지침.md`, `참고/2차지침.md`를 먼저 읽는다. 여기에는 3차에서 달라지는 점만 적는다.

## 1. 근거 자료
- **평가원 선택과목 3개년 기출 목록** `참고/평가원기출/겹침목록.json`(문항마다 형식·자료·통합사회 단원·개념·겹침 정도·변형 방법) + `참고/평가원기출/과목별요약.md`.
  원문 PDF·글자본은 저장소 밖 `/home/user/자료/평가원3개년/`(공개 저장소라 올리지 않음). 없으면 `python3 -I scripts/fetch-sources.py <폴더 주소>`로 다시 받는다(주소는 강사에게).
- 통합사회 기출: `../textbook/참고/기출분석.md`, `기출분류.json`(2028 수능 예시문항 + 학평), 특강 교재 `특강/content/analysis.js`.
- 외부 모의고사 분석(스타강사코리아 예선 2회분, 2026-11-07): 단원 비율 9 : 16, 배점 8·9·8, 예시문항 사상가 목록, 순서도·3차원 좌표·도넛·거품 그래프·학생 답안 채점·응답표, 실제 지명·통계, 교과서 밖 지식 선지. (정답·문항은 저장소에 두지 않음)

## 2. 배점과 난이도
- MAXIMIN 회마다 **1.5점 8 · 2점 9 · 2.5점 8**(2028 예시문항과 같음). 2.5점 = 상(수능 3점급), 2점 = 중상~상, 1.5점 = 하~중.
- MINIMAX STEP 2의 상 문항도 2.5점과 같은 기준.
- **수능 3점급(상)의 조건 — 아래에서 셋 이상**
  1. 판별이 먼저: 자료에서 사상가·지역·국가·제도·시기를 추론해야 한다(이름을 숨김, 단서는 2개 이상).
  2. 두 자료 결합: 그래프+지도, 표+글, 지도+기후 그래프처럼 한 자료만으로는 답이 안 나온다.
  3. 계산·비교 2단계: 비율 ↔ 절대량, 증가율 ↔ 증가량, 기회비용(명시적+암묵적), 교환 비율 범위, 소멸 위험 지수·부양비처럼 두 번 계산.
  4. 판단 구조: <보기> 4개(ㄱ~ㄹ), '적어도 한 사람', 예/아니요 순서도, 질문 분류표 역추론, 채점 결과 역추론, 벤 다이어그램 A·B·C.
  5. 정교한 함정: 주체·방향·범위 바꾸기(만/모두/항상), 비슷한 사상가 주장 섞기, 원인↔결과 뒤집기, 단위 바꾸기.
  6. 단원 결합: 두 중단원 이상(2028 예시 13번처럼 밑줄 다섯 개가 세 단원).
- **어렵게 만드는 방법으로 쓰지 않는 것**: 교과서 밖 사실 지식(최대 수출국, 순위, 연도 세부 등)만으로 갈리는 선지. 꼭 필요하면 자료 안에 단서를 주거나 `note`에 근거를 적는다.
  (스타강사 예선 문항의 약점이 이것 — 우리는 '자료 안에 근거'가 원칙인 평가원·수능 예시 방식을 따른다.)

## 3. 형식 다양화 — MAXIMIN 회마다 목표
| 형식 | 회당 |
|---|---|
| 사상가(한 명 입장·두세 명 비교·순서도·벤) | 4~5 (그중 순서도 또는 벤 1) |
| 그래프 해석(막대·꺾은선·원/도넛·띠·산점도·거품·인구 피라미드·편차·생산 가능 곡선 중 서로 다른 모양) | 4~5 |
| 지도 해석(세계·우리나라·서울) | 2 |
| 계산(기회비용·순편익·비교 우위·지수) | 2 |
| 질문 분류표·응답표(학생 O/X)·채점 결과 | 2 |
| 사료·문서·헌법 조항·신문 기사 밑줄 | 2 |
| 수업 장면·대화·학생 답안 | 2 |
| '옳지 않은 것' 발문 | 1~2 |
| 단원 결합형 | 2 이상 |
- 1번은 통합적 관점(학평처럼 형식은 매번 다르게), 정답 번호 ①~⑤ 각 5개.
- 새 그림 기능: `diagram kind: 'yesno'`(예/아니요 순서도), `chart kind: 'scatter'` + `bubble`(거품 그래프), `chart kind: 'pie'` + `donut: true`, 지도 `routes`(경유점 항로)·`subregions`(서울 자치구 등)·기호 `shape: 'star'|'square'|'tri'`.

## 4. 평가원 기출 변형
- `겹침목록.json`에서 overlap '완전'인 문항을 먼저 씨앗으로 쓴다. '부분'은 outside(범위 밖 요소)를 통합사회 내용으로 바꿔서 쓴다.
- 형식·평가 요소만 살리고 **문장·자료·사례·숫자는 모두 새로**(저작권). 원문 문장과 같은 긴 문장이 없는지 `tools/dup-check.mjs --src`로 확인.
- `src`에 근거를 적는다: 예 `'2026학년도 수능 생활과 윤리 15번 형식'`.

## 5. 작업 방식
- 단원(중단원)별 또는 회차별로 나눠 쓴다. 쓴 사람과 다른 검토자가 **정답을 가리고 다시 풀어** 정답이 하나인지, 근거가 개념서 범위 안인지 확인한다.
- 바꾼 문항은 id를 그대로 두고 내용만 바꾼다(새로 더한 문항만 새 id). 검사: `check`·`explain-check`·`note-check`·`dup-check` → `build.mjs vol order` → 빌드 → `page-check` → 한글 파일 → `hwpx-check`.
