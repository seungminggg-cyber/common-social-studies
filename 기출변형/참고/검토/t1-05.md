# t1-05 자연환경과 인간 생활 — 강사 확인할 점 (1차)
- 기후 그래프·편차 그래프·산점도·표의 숫자는 모두 실제 기후 특징을 단순화한 **가상 자료**(그래프 아래 표시). 도시 이름은 쓰지 않음.
- t1-05-1-025 사과 재배 적지 비율 꺾은선 그래프는 경향(남부 감소·강원 증가)만 살린 가상 자료.
- t1-05-1-021 ㄹ: 순천만 일대 = 2021 세계 자연 유산 '한국의 갯벌'(서천·고창·신안·보성-순천)에 포함 → 맞음으로 처리.
- t1-05-1-030 질문 C '진행 속도가 빨라 짧은 기간에 피해가 집중되는가?'에 태풍을 '예'로 둠(가뭄과 대비). 태풍도 예보로 미리 대비한다는 점에서 이견이 있으면 문장 조정.
- t1-05-1-005 표의 D(최난월 5.5℃, 연 240mm)는 한대로 판단하도록 '강수량과 관계없이 한대'라는 단서를 붙임.
- (검산) t1-05-1-017 (나) 연 강수량이 492mm로 개념서 기준(500mm 미만 건조)에 걸려 스텝으로 볼 여지 → 여름 강수량을 늘려 약 560mm로 고침. t1-05-1-018 C(연 150mm, 최난월 4℃)도 건조 기후로 볼 여지 → 표 아래에 '최난월 10℃ 미만이면 강수량과 관계없이 한대' 단서 추가(005와 같은 방식).
