# 정조준 시리즈 표지·간지 디자인 — 진행 기록 (사용량 한도 뒤 이어 가기용)

브랜치 `claude/workbook-design`. 끝난 단계에 [x]. 결과물은 `out/cover/`(커밋하지 않음).

## 파일 (`기출변형/cover/`)
- `tokens.js` 디자인 값: 색(대단원 5색·무채색), 권별 바탕(paper·gray·ink), 어두운 바탕용 밝힌 색(`lift`), 글꼴, 글자 크기, 도련 3mm·안전 여백 10mm, 모서리 자름 18%
- `series.js` 데이터: 권 목록 8권(01은 통합사회1·2 두 권), 앞 단어·부제·과목·바탕, 브랜드 문구. [ ]는 자리 표시
- `target.js` 과녁(모서리 자른 네모 겹침, 선/면), `sheet.js` 낱장 틀(도련 포함 216×303mm, 재단선 기준 mm 배치), `front.js` 앞표지 안 A·B·C
- `build-cover.mjs` 빌드: `node cover/build-cover.mjs fronts` (기출변형 폴더에서)
- `otf2ttf.py` 글꼴 변환: 크롬이 OTF(CFF)를 PDF에 Type 3으로 넣어서 인쇄소에서 문제 될 수 있음 → TrueType 윤곽으로 바꿔 `out/cover/fonts/`에 둠(1분 남짓, `pip install fonttools`). 바꾼 뒤 PDF 글꼴은 CID TrueType·임베드 확인(pdffonts).

## 단계
- [x] 0. 저장소 확인: KoPub 돋움·바탕 Light/Medium/Bold 6개 모두 있음(글꼴 요청 필요 없음). 문항 수 1·2차 각 500(중단원별 수는 content에서 계산), 문항 번호는 중단원마다 01부터.
- [x] 1. 앞표지 다듬은 안 3가지(02권) + 바탕별 비교(02 종이·03 회색·06 먹) → 강사에게 보냄
  - A 가운데 정돈(시안 4를 다듬음: 과녁 108mm, 제목 묶음을 아래쪽에 모음, 짧은 선으로 위계 정리)
  - B 비대칭 격자(큰 과녁 오른쪽 위, 글자 왼쪽 아래, 권 번호 크게)
  - C 색면 과녁(다섯 색을 면으로, 사이 바탕색 틈)
  - 먹 바탕: 선 과녁은 색을 40% 밝히고 선을 굵게, 가운데 네모·앞 단어 상자는 밝은 색으로 반전
- [x] 1-b. 강사 답(원래 세션이 전달, 2026-11-06): 제목 글꼴은 KoPub만 고집하지 않아도 됨(인쇄 무료·임베드 가능한 것만, 후보 2~3개), 재단선 표시는 나중에(도련 3mm 유지), 쪽수는 저장소로 계산·용지는 가정값.
  - 제목 글꼴 후보 3개를 안 A·B·C에 적용해 보냄: `node cover/build-cover.mjs fonts`. 본문·작은 글자는 KoPub 유지.
  - 쪽수: 합본 단원별 146쪽(`node build.mjs 1 units`) → 02권 약 204쪽(간지·빈 쪽·모의고사 포함, 해설 별책 가정). 책등 = 204/2×0.1 + 0.25×2 ≈ **10.7mm**(가정: 모조 80g 0.1mm/장, 표지 250g 0.25mm). `series.js`의 PAPER·PAGES.
- [x] 1-c. 강사 의견(2026-11-06): "A나 C가 낫지만 더 수정. 회색 바탕 별로. 일타강사 교재처럼 시선을 사로잡게. 글꼴은 ①KoPub 바탕이 가장 낫고 ③본명조도 괜찮음. 기존 틀 안 따라도 됨, frontend-design 스킬 사용." 인쇄 규격·책 두께는 나중에, 엄지 색인·과목 간지·뒷표지 글자는 디자인을 끝까지 만든 뒤 정함.
  - frontend-design 지침(공개 원본 SKILL.md)대로: 1차의 크림색 바탕+가는 명조는 '생성형 기본값'에 가까워 버림 → **흰 종이 + 한 가지만 강하게(과녁)**, 아주 큰 제목(150pt), 아래 먹 띠.
  - 2차 시안 3가지(`cover/v2.js`, `node cover/build-cover.mjs v2 [noto]`): **A2 선 과녁 · C2 색면 과녁 · F 과녁 액자(표지 전체가 과녁, 가운데 흰 판에 제목)**. 안마다 앞표지·뒷표지(간단/설명 포함)·펼침면(책등 10.7mm)·대단원 간지 10·과목 간지 2·06권(먹) 앞표지, KoPub과 본명조 두 벌.
  - 권별 바탕: 01~05 흰 종이, 06·07 먹(회색 종이 안 씀) — `series.js`.
  - 간지 데이터 `cover/book-data.js`(중단원·문항 수·번호 범위를 content에서 계산, 기출 포인트는 POINTS에 넣으면 됨). 엄지 색인 10자리(위 39.7mm + k×21.7mm, 폭 12.7·높이 20.6mm).
  - 검사: 글자 안전 여백 10mm 자동 검사(build-cover.mjs, 책등은 위아래만), 글꼴 임베드(pdffonts), 펼침면 크기 1237.9×859pt = (420+10.7+6)×303mm.
- [ ] 2. 강사 선택: 2차 안(A2·C2·F)·글꼴(KoPub·본명조), 엄지 색인 10칸, 과목 간지, 뒷표지(간단/설명 포함), 해설 별책 여부, 용지
- [ ] 3. 뒷표지·책등·펼침면
- [ ] 4. 대단원 간지 10장 (+ 과목 간지 2장, 강사가 원하면)
- [ ] 5. 나머지 권 앞표지
- [ ] 6. 합본 빌드(build.mjs)에 표지·간지 넣기, `npm run build` 확인, main 합치기(강사 확인 뒤)

## 글꼴 라이선스 근거
- KoPub World 돋움·바탕: 한국출판인회의 배포, 출판물 사용 무료(서체 판매만 금지). npm `font-kopubworld@1.0.3`.
- 함렛(Hahmlet): SIL Open Font License 1.1 — Copyright 2020 The Hahmlet Project Authors (github.com/hyper-type/hahmlet). 원본 google/fonts `ofl/hahmlet/Hahmlet[wght].ttf`를 굵기 900으로 고정(OFL은 수정본 배포 시 이름 'Hahmlet' 사용 제한이 있으나, PDF 안에 일부 글자만 넣는 것은 '글꼴 배포'가 아니라 문서 사용이라 문제없음. 고정 글꼴 파일 자체는 저장소에 올리지 않음).
- 본명조(Noto Serif KR): SIL OFL 1.1 — Google·Adobe. npm `@fontsource/noto-serif-kr`(Black 900).
- 검은고딕(Black Han Sans): SIL OFL 1.1 — Copyright 2015 The Black Han Sans Project Authors (github.com/zesstype/Black-Han-Sans). npm `@fontsource/black-han-sans@5.3.0`(textbook/package.json에 추가).
- OFL 1.1: 인쇄물·PDF에 넣어 판매해도 됨, 글꼴 파일만 따로 판매 금지. PDF에는 쓴 글자만 임베드(CID TrueType)된 것을 pdffonts로 확인.

## 메모
- 엄지 색인: 지금 문제집 안쪽 쪽은 개념서와 같은 5자리(Ⅰ~Ⅴ: 위 38·68·98·128·158mm, 통합사회1·2가 같은 자리). 합본에서 10자리(150+k×82px)로 바꾸면 안쪽 쪽도 함께 바꿔야 간지와 맞음 → 강사에게 물음.
- 대단원 이름은 저장소(개념서 목차)를 따름: 통합사회2 Ⅰ "인권 보장과 헌법"(띄어 씀).
- 크롬 PDF 쪽 크기가 215.9×303.0mm로 0.1mm 차이 → 최종본에서 MediaBox를 216×303mm로 맞추고 TrimBox·BleedBox를 넣을 것.
