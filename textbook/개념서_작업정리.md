## 2. 출제 빈도와 문제 유형

- 근거 자료: `참고/기출분류.json`, `참고/기출분석.md` — 2028 수능 예시문항 + 2025~2026 고1·고2 학력평가 8회(9회, 200문항).
- 별점: ★★★ 최다 빈출(9회 중 3번 이상) / ★★ 빈출(1~2번) / ★ 기본 개념(직접 출제 없음). 한 문항이 개념의 주제·정답·판단해야 할 <보기>이면 센다. 오답 선지로 한 번 섞인 것은 세지 않는다.
- 문제 유형 이름(문제 머리에 씀): 개념 이해, 사례 적용, 자료 해석, 그래프 해석, 지도 해석, 사상가 입장, 사상가 비교, 입장 비교, 글 해석, 질문 분류표, 계산.
- 난이도: 문제마다 상·중·하(글자로 표시).

## 3. 용어·표기

- 쉬운 말, 짧은 문장. 맞춤법은 국립국어원 기준(띄어쓰기: '문화 상대주의', '사회 계층', '지속가능발전'은 교육과정 표기대로 붙여 씀).
- 사상가 이름은 교과서 표기(예: 아리스토텔레스, 에피쿠로스, 벤담, 롤스, 노직, 갈퉁). 표기가 갈리는 이름은 함께 적는다(예: 카렐 바작(바사크)).
- 원전 읽기는 고전 원문을 새로 옮긴 문장. 현대 사상가(싱어·슈바이처·테일러·샌델 등)는 원문 대신 "[주장 요약]".
- 숫자: 출처를 확인한 값만 실제 값으로 쓰고, 나머지는 "개념도 / 가상 자료 / 근삿값 / 교재 재인용"을 밝힌다.
- 바뀐 제도 주의: 예금자 보호 한도 1억 원(2025-09-01부터), 2026년 최저 임금 10,320원, 대구 군위(2023 편입), 지도는 우리나라 정부 시각 국경.
- 교재(개념풀 등)와 다르게 쓴 곳과 이유는 `참고/검토할점.md`에 있다(예: 불가리아의 끄덕임, 독일 로봇 밀도 397대).

## 4. 파일 구조

```
textbook/
  build.mjs            단원 하나 빌드: node build.mjs <책> [h] [student|teacher|both] [png]
  build-book.mjs       통합본: node build-book.mjs [t2] [student|teacher|answers] [png]
  hwpx_build.py        한글 파일(.hwpx)
  content/<책>.js      책(대단원) — 단원 파일을 모으고 withCC로 개념 계획을 붙임
  content/_<책>/uNN.js 중단원 내용(본문 블록, 개념 확인, 수능형 문제)
  content/_cc/         개념 계획(시안 H) — apply.js, <책>.js
  content/_book/       통합본 앞뒤(표지, 차례, 진도표)
  lib/                 render(HTML), paginate(쪽 나눔), figures·maps·diagrams·photos(그림)
  themes/              시안 a~h. 확정 = h(h.css + h-book.css)
  assets/              사진(자유 라이선스 + credits.json), 지형 타일, 출처 자료
  참고/                기출분석·기출분류.json·검토할점·저작권점검
  tools/               cc-outline.mjs(단원 개요), photos/(사진 찾기·점검)
```

## 6. 저작권 (꼭 지킴)

- 교과서·문제집·시험 문장을 그대로 옮기지 않는다. 문항은 소재·구조를 바꾸고 문장을 새로 쓴다.
- **저장소는 공개(GitHub Pages)**: 시험·문제집 PDF, 드라이브에서 받은 자료는 저장소에 올리지 않는다(scratchpad 등 저장소 밖에 둠).
- 사진은 자유 라이선스(CC BY, CC BY-SA, CC0, 퍼블릭 도메인)만, 사진 아래와 책 끝 '사진·자료 출처'에 저작자·라이선스 표시. 근거가 약하면 쓰지 않는다(`참고/저작권점검.md`).

## 7. 검사 방법

- 빌드 후 PNG로 쪽마다 눈으로 확인(잘린 그림, 겹친 글자, 빈 공간).
- 넘침·그림 밖 글자·글자 겹침·대체 글꼴·문제 머리 줄바꿈을 스크립트로 확인(작업 세션의 scratchpad 도구).
- 개념이 맞는지는 개념풀·수능풀 해설, 학평 해설과 대조. 판단이 갈리는 곳은 고치지 않고 `참고/검토할점.md`에 남긴다.
