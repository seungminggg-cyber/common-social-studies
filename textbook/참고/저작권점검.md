# 사진·그림 저작권 점검 (2026-11-05)

교재에 쓴 사진 82장과 지도·통계·아이콘 자료의 이용 조건을 하나씩 다시 확인한 기록입니다.
위키미디어 공용(Wikimedia Commons)의 파일 정보(라이선스, 저작자, 퍼블릭 도메인 근거, 삭제 요청 여부, 플리커 라이선스 검증, VRT 허락 기록)를 API로 다시 조회해 대조했습니다.

## 결론
- **문제 없음**: 82장 모두 자유 이용 허락(CC BY, CC BY-SA, CC0) 또는 퍼블릭 도메인. 비영리(NC)·변경 금지(ND) 사진은 없음. 삭제 요청·저작권 침해 신고가 걸린 파일도 없음. 라이선스가 처음 받을 때와 바뀐 파일 없음.
- **이번에 바꾸거나 뺀 것**
  - 레오폴드 초상: 1944년 사진관 초상을 2023년에 올린 사람이 "직접 찍었다"고 신고한 파일 → 근거가 맞지 않아 **뺌**(근거가 확실한 1908년 사진은 너무 흐려서 초상 없이 둠)
  - 슘페터 초상: 색을 입힌 사본(원본 사진의 권리 근거 없음) → **1945년 원본 사진**(미국에서 저작권 갱신이 없어 퍼블릭 도메인)으로 바꿈
  - 혼일강리역대국도지도: 현대에 교수가 손으로 옮겨 그린 채색본 → **1402년 무렵 원본(일본 혼코지 소장본)** 사진으로 바꿈
  - 싱가포르 '수퍼트리'(2012년 조형물이 사진의 주인공): 우리 저작권법 제35조 제2항은 공공장소의 미술 작품이라도 "판매 목적의 복제"는 예외로 두므로, 교재를 판매할 경우를 생각해 **뺌**
- **출처 표시 보강**
  - 저작자가 표기 문구를 따로 정해 둔 사진 10장은 **그 문구 그대로** 표기(예: "© Martin Thurnherr / cc-by-sa-4.0 / Commons.wikimedia.org")하고 저작자 페이지 주소도 적음
  - 출처 쪽에 "크기 조정·자르기·밝기 조정을 했다", "고쳐 실은 사진도 같은 라이선스를 따른다", "저작자가 이 책을 보증한다는 뜻이 아니다"를 적음(CC 라이선스 조건)
  - 지도·통계·아이콘 자료 출처를 같은 쪽에 추가: AWS 고도 타일(요구하는 원문 출처 문구 전체), 판의 경계(Ahlenius·Nordpil·Bird, ODC-By), 통계청 시·도 경계, Our World in Data·세계은행(CC BY 4.0), Tabler Icons(MIT 라이선스 전문), Pretendard(OFL)
  - 한글 파일 끝에도 같은 '사진·자료 출처' 쪽을 넣음

## 지켜야 할 점 (인쇄·배포할 때)
1. 사진 아래 작은 출처 글씨와 책 끝 '사진·자료 출처' 쪽을 **지우지 않는다**. CC BY·CC BY-SA 사진은 이것이 이용 조건이다.
2. 사진을 따로 잘라서 다른 자료(프린트, 슬라이드)에 쓸 때도 사진 아래 출처를 함께 옮긴다.
3. CC BY-SA 사진을 고쳐서 쓴 경우, 고친 사진도 같은 CC BY-SA로 표시한다. 교재 전체를 CC BY-SA로 바꿀 필요는 없다(사진은 교재 안에 "함께 실린" 것).
4. 인물 사진은 설명 그대로(사상가 소개)만 쓰고, 광고·홍보 문구와 함께 쓰지 않는다(초상권·퍼블리시티권).
5. 새 사진을 넣을 때는 `tools/photos/`의 점검 스크립트(`audit.py`)로 라이선스·근거를 확인한 것만 쓴다. 저작자 표기가 정해진 사진은 `assets/photos/credits.json`의 `attribution`에 그대로 적는다.

## 퍼블릭 도메인 근거 메모
- 오래된 그림·조각·문서(보호 기간이 끝난 것): 저작자 사후 70년이 지난 작품을 평면 그대로 찍은 사진은 새 저작물이 아니다.
- 미국 저작물: 미국에서 저작권 표시가 없거나 갱신하지 않아 보호가 끝난 사진은 우리나라에서도 보호하지 않는다(**저작권법 제3조 제4항**: 외국인의 저작물이 그 나라에서 보호 기간이 끝났으면 우리나라 보호 기간도 인정하지 않음).
- 미국 정부 기관(NASA, 해군, 국립 문서 기록 관리청 등)이 만든 사진은 퍼블릭 도메인이다.
